트럭 자체를 우리집으로 사용하고 별도 집 건물을 없앴습니다. 생산 시설 위에는 실제 생산품 그림과 수량·상태가 나타나며 눌러서 생산하거나 받을 수 있습니다. 건설 시 반려동물은 안전한 자리로 이동합니다. 저장과 공통 2배 속도를 유지합니다. 네이티브 8–25 앱은 원래 공개 키로 인증한 콘텐츠를 받아 APK 재설치 없이 패치합니다. 0.7 이하 앱은 최신 APK를 한 번 설치해야 합니다. iPhone 웹 앱은 실행·복귀할 때 버전을 확인하고 작업이 안전하게 끝난 뒤 적용합니다.

과거 APK는 현재 트리 또는 검증된 고정 커밋 주소에 보존합니다. 이번 버전에서는 v0.12·v0.13 APK·체크섬만 고정 주소 보관으로 옮깁니다. 캐시된 과거 HTML의 자산과 Git 이력을 유지합니다. 브라우저 검증은 실제 iPhone·Android 설치 검증과 구분하며 웹·홈 화면 앱·Android 앱 사이의 저장 공유를 보장하지 않습니다.
