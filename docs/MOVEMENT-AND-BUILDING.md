# 이동 중 우회와 건설 망치질

## 장애물이 생겼을 때

주인공의 일반 이동과 농사·채집·건설·동물에게 다가가는 이동은 실제 몸 반경과 현재 장애물을 기준으로 경로를 찾습니다. 이동 중 동물이 길을 막으면 잠깐 기다린 다음 빈 길을 다시 찾습니다. 동물이 비켜주기를 요청하는 처리와 주인공의 우회 처리를 함께 사용합니다.

원래 도착하려던 밭·나무·건물·동물은 유지합니다. 필요한 경우 같은 대상의 다른 작업 위치로 접근하며, 이미 끝낸 작업 진행량을 중복 보상으로 만들지 않습니다. 우회 경로가 바뀌어도 현재 발 위치에서 출발하고 계단·경사로는 실제 연결을 따라갑니다.

몸이 이미 조금 겹친 상태에서는 서로 멀어지는 방향으로 빠져나올 수 있습니다. 더 깊이 겹치거나 동물을 관통하는 방향은 계속 막습니다. 트럭과 건물의 바닥 영역도 함께 피합니다. 코끼리·기린에 타고 있을 때는 탑승 동물의 큰 몸 반경을 사용하며 지상에서만 이동합니다.

통로 전체가 닫혀 우회할 곳이 없으면 충돌을 무시하거나 순간이동하지 않습니다. 안전하게 멈추며, 작업을 계속할 수 없는 경우 빈 통로를 마련하도록 안내합니다.

## 건물 건설과 개선

시설을 새로 짓거나 레벨을 올리면 주인공이 시설의 작업 위치까지 걸어가 망치질합니다. 이동 중에는 작업 모션을 재생하지 않습니다.

작업 구간에는 발을 고정하고 망치를 머리 위로 들기 → 빠르게 내려치기 → 접촉 유지 → 복귀를 세 차례 반복합니다. 사각 철제 망치 머리와 나무 손잡이를 사용하고, 실제 망치 머리가 닿는 순간에 작은 먼지와 타격 효과를 표시합니다. 남녀 캐릭터와 장착한 의상을 유지합니다.

작업이 끝나면 그 자리에 머물며 다음 행동을 이어갑니다. 전체 게임 속도 배율과 생산 대기 시간은 바꾸지 않습니다.

## 구현 위치

- 실제 충돌·겹침 해소·장애물 경계: `src/scene-navigation.ts`
- 경로 재탐색·작업 진행량·탑승 반경: `src/scene.ts`
- 세 차례 망치질의 동작과 접촉 위치: `src/construction-motion.ts`, `src/actors.ts`
- 화면의 이동·망치질 안내: `src/main.ts`
