# v0.49 미니어처 그래픽과 공간 구조

사용자가 승인한 따뜻한 입체풍 시안을 실제 게임용 원화로 나누어 적용했습니다. 올리브색 철물·아이보리 천·목재·황동 조명과 같은 광원을 사용합니다. 정적인 시안 한 장으로 플레이 화면을 덮는 대신, 움직이는 트럭 구조와 자유 배치 시설·밭·주민·채집물을 각각 그립니다.

## 화면과 원화

- 트럭 운전석·바퀴·재질은 `haven-truck-miniature.png`를 사용합니다. 차체는 얇은 올리브색 프레임과 바퀴 아치·짝차축, 데크는 작은 참나무 판재·가는 난간·작은 조명으로 다시 구성합니다. 차체 그림과 지상 충돌은 같은 순수 좌표 모델을 사용합니다.
- 사람과 동물은 하나의 짧은 ㄱ자 목재 계단을 공유합니다. 여덟 개의 수평 발판과 수직 단차, 평평한 모서리 참, 얇은 난간과 지상 지지대를 그립니다. 동물 통행을 조절하는 작은 문은 출입구에 붙으며 별도의 경사판을 만들지 않습니다. 문을 닫을 때의 작업 대기점은 올라오는 동물의 출구에서 떨어진 데크 안쪽에 있습니다.
- 지면은 `haven-ground-landscape.png`, 채집물은 `haven-ground-props.png`로 분리합니다. 배경에 트럭·동물·시설·채집할 나무를 미리 그려 넣지 않습니다. 아홉 구역에 나무 25그루·고철 군집 12곳·씨앗 풀 13곳·큰 연못 하나를 배치합니다. 이전 나무·고철·씨앗의 기록은 유지하고 흩어진 물 채집 기록은 연못으로 합칩니다.
- 시설 6종은 개방형 작업대·주방·정수소·온실·전망대·동료 쉼터입니다. 실제 받침대 중심을 설치 좌표에 붙이고 유료 점유 격자의 88% 이내에 맞춥니다. 회전별 그림 경계를 선택·생산 말풍선·카메라에도 공유합니다.
- 밭은 흙과 목재 벽의 단차를 더하고, 시설·밭·주인공·동물은 바닥에 닿는 위치 순서로 그려 서로 앞뒤에서 가려지도록 합니다. 기본 홈 구도는 먼 채집지 대신 트럭 실루엣에 맞추고 과다한 하단 여백을 줄입니다. 명시적으로 전체 보기를 선택하면 먼 구역까지 표시합니다.
- 작물 6종은 새싹·성장 중·성숙 단계의 새 그림을 사용합니다. 씨앗과 수확물도 해당 품종의 별도 아이콘을 사용합니다.
- 남녀 캐릭터의 게임 그림·초상화·의상 미리보기는 새 WebP 원화를 공유합니다. 걷기에는 팔·다리 관절과 발 디딤을 연결하고, 농사·채집·망치질·쓰다듬기·탑승 자세를 유지합니다.
- 동물 11종의 44개 포즈 원화를 교체했습니다. 기존 동물의 발 접점·종별 보행·쓰다듬기·탑승 움직임에 새 그림을 연결합니다.

이 버전은 새 입체풍 렌더 이미지와 기존 Canvas 관절·투영을 결합합니다. 실시간 3D 메시나 카메라 회전 기능을 도입한 버전은 아닙니다. 시안의 시설 배치와 개수는 플레이어가 건설·확장하며 꾸미는 결과이므로, 기존 마을을 시안의 배치로 덮어쓰지 않습니다.

## 큰 연못과 고철 군집

연못은 300×180 세계 좌표의 불규칙한 해안선과 같은 충돌 다각형을 사용합니다. 풀과 흙이 배경에 옅게 이어지고, 얕은 물·갈대·드문 돌·작은 물결을 따로 그립니다. 주인공과 동물은 물을 가로지르지 않고 물가를 돌아갑니다.

열 번의 성공한 채집 후 물과 수변 소품을 숨기며 옅은 마른 바닥 흔적만 남깁니다. 실제 180초가 지나면 물과 열 번의 채집 횟수가 돌아옵니다. 시계를 읽거나 저장을 불러오는 행동은 물자를 주지 않습니다. 기존 v1의 28·52·62개 저장 목록을 v2로 이어받고, 물 채집 방문 합계와 가장 늦은 재생 시점을 보존합니다. 다른 활동이나 재실행으로 연못의 남은 횟수가 초기화되지 않습니다.

고철은 같은 더미 그림을 다섯 번 복사하지 않고 원화에서 분리한 철판·패널·타이어·엔진과 휘어진 파이프를 한 군집으로 구성합니다. 군집마다 간격·회전·방향을 바꾸며, 80×54×축척의 물리 바닥과 그림 선택 영역을 함께 적용합니다. 군집당 보상·기력·재생 주기는 기존과 같습니다.

## 조작

하단 주요 메뉴는 **건설 · 농사 · 탐험 · 상점**입니다. 창고는 상단의 자원줄을 누르면 열립니다. 상단 중앙의 **이동**을 펼치면 전체 보기·도로 걷기·채집 장소·트럭 복귀·동물 문을 선택합니다. 지도 확대·축소는 오른쪽에 작게 두고, 작업 패널이 열리면 접습니다. 접이식 채집 도구와 마을 운영은 왼쪽 아래에 있습니다.

## 제작과 배포 범위

새 원화는 이 프로젝트를 위해 생성했으며 원본 생성 파일은 작업 환경의 `generated_images`에 보존했습니다. 게임 자산은 `src/assets/haven-*`에서 번들에 포함됩니다. 이 안내는 변경 내용에 대한 문서이며 플레이 테스트 기록은 아닙니다. 이번 작업에서는 사용자 요청에 따라 별도의 단위·브라우저·플레이 테스트를 실행하지 않고 배포에 필요한 컴파일·번들·APK 제작과 서명을 수행합니다.
