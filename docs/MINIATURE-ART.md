# v0.47 미니어처 그래픽

사용자가 승인한 따뜻한 입체풍 시안을 실제 게임용 원화로 나누어 적용했습니다. 올리브색 철물·아이보리 천·목재·황동 조명과 같은 광원을 사용합니다. 정적인 시안 한 장으로 플레이 화면을 덮는 대신, 움직이는 트럭 구조와 자유 배치 시설·밭·주민·채집물을 각각 그립니다.

## 화면과 원화

- 트럭 운전석·바퀴·난간과 데크 재질은 `haven-truck-miniature.png`를 사용합니다. 트럭 확장과 층 선택은 기존의 실제 투영 구조를 유지합니다.
- 사람 계단과 동물 통로에는 나무 발판·수직 디딤판·올리브색 난간·지상 지지대를 그립니다. 문과 실제 통행 경로는 같은 끝점을 사용합니다.
- 지면은 `haven-ground-landscape.png`, 채집물은 `haven-ground-props.png`로 분리합니다. 배경에 트럭·동물·시설·채집할 나무를 미리 그려 넣지 않습니다. 각 채집물은 기존 위치에서 개별 상호작용과 재생을 이어갑니다.
- 시설 6종은 개방형 작업대·주방·정수소·온실·전망대·동료 쉼터입니다. 배치 방향과 레벨별 장식은 실제 배치 정보를 따릅니다.
- 작물 6종은 새싹·성장 중·성숙 단계의 새 그림을 사용합니다. 씨앗과 수확물도 해당 품종의 별도 아이콘을 사용합니다.
- 남녀 캐릭터의 게임 그림·초상화·의상 미리보기는 새 WebP 원화를 공유합니다. 걷기에는 팔·다리 관절과 발 디딤을 연결하고, 농사·채집·망치질·쓰다듬기·탑승 자세를 유지합니다.
- 동물 11종의 44개 포즈 원화를 교체했습니다. 기존 동물의 발 접점·종별 보행·쓰다듬기·탑승 움직임에 새 그림을 연결합니다.

이 버전은 새 입체풍 렌더 이미지와 기존 Canvas 관절·투영을 결합합니다. 실시간 3D 메시나 카메라 회전 기능을 도입한 버전은 아닙니다. 시안의 시설 배치와 개수는 플레이어가 건설·확장하며 꾸미는 결과이므로, 기존 마을을 시안의 배치로 덮어쓰지 않습니다.

## 조작

하단 주요 메뉴는 **건설 · 농사 · 탐험 · 상점**입니다. 창고는 상단의 자원줄을 누르면 열립니다. 트럭 복귀와 기본 화면은 상단 도로 도구에서 선택하며, 작은 가로 화면에서는 **더 보기**를 누르면 채집 장소·트럭 복귀·동물 문을 펼칩니다. 접이식 채집 도구와 마을 운영은 왼쪽 아래에 있습니다.

## 제작과 배포 범위

새 원화는 이 프로젝트를 위해 생성했으며 원본 생성 파일은 작업 환경의 `generated_images`에 보존했습니다. 게임 자산은 `src/assets/haven-*`에서 번들에 포함됩니다. 이 안내는 변경 내용에 대한 문서이며 플레이 테스트 기록은 아닙니다. 이번 작업에서는 사용자 요청에 따라 별도의 단위·브라우저·플레이 테스트를 실행하지 않고 배포에 필요한 컴파일·번들·APK 제작과 서명을 수행합니다.
