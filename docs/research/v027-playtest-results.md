# v0.27 — 작물 납품과 트럭 아래 생활

작물 선택에 실제 목적을 주도록 여섯 종류 수확물 재고와 작물별 이웃 납품을 추가했습니다. 당근·감자·토마토·옥수수·딸기·호박을 실제 수확할 때 해당 작물 수량을 기록합니다. 이 재고는 기존 식량에 포함되며 별도의 중복 식량이 아닙니다. 휴식·판매·생산·날짜 변경·영양 주기로 식량을 쓰면 일반 식량부터, 부족하면 표시된 작물 순서대로 사용합니다. 과거 저장의 식량을 특정 작물로 추정하거나 업데이트 보너스로 수확물을 지급하지 않습니다.

현재 요청한 작물을 준비해 명시적으로 납품하면 코인·경험치·목재와 일부 고철을 받습니다. 요청은 여섯 종류를 순환하며 현재 요청 ID만 한 번 사용할 수 있습니다. 첫 당근3개 요청은 코인14·경험치12·목재2를 지급합니다. 받은 코인은 씨앗·동료·의상에, 재료는 시설과 공간 확장에 사용할 수 있습니다. 기존 성장 목표를 유지하면서 지금 요청한 작물을 심고 돌보고 수확하는 행동으로 안내합니다.

자라는 밭에 식량1·기력2로 한 번 영양을 주면 해당 수확량이2개 늘어납니다. 실제 캐릭터가 밭에 가서0.9초 작업하고 돌아온 뒤 비용과 결과를 반영합니다. 영양은 현재 심은 작물의 정확한 ID·품종·심은 시각에 연결되며 수확 후 없어집니다. 완료된 작물·빈 밭·중복 영양은 거절합니다. 기존 성장 시각·공통2배 속도를 바꾸지 않습니다.

도로 바깥 경계는 기존275×180에서 초기1,200×520으로 넓히고 트럭 확장에 맞춰 커집니다. 주인공과 동물의 전체 몸체가 경계·나무·물자 더미를 통과하지 않도록 유지했습니다. 도로는 생활 데크와 분리된 지상 표면으로, 도로에 내려가면 트럭 아래를 눌러도 지상으로 걷습니다. 겹치는 트럭은 반투명으로 보여 캐릭터를 찾을 수 있습니다. 실제 사다리로 내려가고 돌아오며 도로의 움직임을 카메라가 따라갑니다. 빈 도로를 터치해 방향을 바꾸거나 화면을 끌어 넓은 주변으로 갈 수 있습니다.

벌목장·고철 수거장·씨앗 풀밭·샘터에서 필요한 물자를 고릅니다. 각각 목재18·고철9·한 품종 씨앗3·물12를 얻고 기력10·10·8·8을 사용합니다. 채집은 실제 이동·작업·원래 자리 복귀가 끝난 후 지급하며 실패한 경로는 물자나 비용을 지급하지 않습니다. 각각45·30·30·20초 후 다시 준비됩니다. 기존 빠른 활동과 씨앗 인벤토리의 보급 버튼도 실제 장소로 연결해 안내한 물자와 결과가 일치합니다. 기존 탐색 퀘스트 보상은 실제 채집 기록을 기준으로 한 번 지급합니다.

비교 게임의 실제 확인 범위는 [공식 자료 조사와 설계](v027-gameplay-design.md)에 기록했습니다. 발행자의 소개와 화면을 읽고 보았으며 직접 설치 플레이·동영상·비공개 개발 문서를 확인했다고 주장하지 않습니다. 기존 PNG17개를 유지하며 참고 게임 그림을 제품으로 가져오지 않았습니다.

TypeScript 검사가 통과했습니다. 실제 입력 해시를 기록한 전체 단위 검사354개가 통과했습니다. 새 검사에는 여섯 작물의 실제 심기·물 주기·수확·납품, 영양의 한 번 사용과 실제 추가 수량, 다섯 식량 소비 경로의 재고 보존, 저장 손상·한도·중복 지급 거절, 네 채집 장소의 자원·시간·씨앗 순환·기존 퀘스트 보상, 모든 데크 단계와 큰 동물의 도로 경로·사다리·충돌·복귀가 포함됩니다.

모바일 검수는 Chromium 모바일 화면과 실제 터치 입력·자연 프레임·타이머를 사용합니다. 실물 Android 설치·자동 패치 또는 iPhone/Safari 설치 검수는 아닙니다. 새 게임은 기본 생성 자원을 사용하며 코인이나 수확물을 주입하지 않습니다. 기존3층 저장은 과거에 검증한 검사 준비 상태이며 이번 플레이에서 그 진행을 획득했다고 주장하지 않습니다.

개발 검수의 실제 화면에서 지상 캐릭터가 트럭의 여러 반투명 그림에 덮여 보이지 않는 문제를 찾았습니다. 이동·그림 좌표 기록만 통과한 결과는 최종 증거로 사용하지 않고 원래 기록과 사진을 보관했습니다. 반투명 트럭을 먼저 그리고 지상 동물·캐릭터를 뒤에 그리도록 수정했으며, 발밑 표시와 ‘지상’ 문구로 위치를 구별합니다. 수정 후344px 실제 화면에서 캐릭터가 선명하게 보이는 것을 독립적으로 확인하고, 수정된 소스 입력으로354개 단위 검사를 다시 통과시켰습니다. 실제 그리기 순서 기록은 가시성 보장이라고 주장하지 않으며 사진 검수와 함께 사용합니다.

수정 후 안정된 실제 개발 서버에서344×740·360×800·390×844·844×390의 전체 검수19,124개가 통과했습니다. 새 게임 기본 자원으로 직접 심기·물 주기·유료 영양·자연 성장·6개 당근 수확을 진행하고, 당근3개 납품으로 실제 코인14·목재2·경험치12를 받았습니다. 받은 코인으로 당근 씨앗을 구매해 코인12가 남는 결과를 확인했습니다. 이전 식량을 특정 작물로 주입하거나 코인을 검사 준비로 지급하지 않았습니다.

네 채집 장소에서 실제 이동·작업·원래 자리 복귀와 한 번 지급, 재채집 대기 중 비용·보상 거절을 확인했습니다. 네 화면에서 사다리 내려가기·트럭 아래 지상 이동·예전 경계 밖 이동·사다리 복귀 총16회, 실제 화면 이동14회와 기존3층 저장·생산 시각·동물 체력·경험치의 저장·재실행을 확인했습니다. 사진26장을 서로 다른 이름으로 보관하고 모든 해시를 확인했습니다. 수정 후 지상 캐릭터와 농사·납품·채집 결과 화면을 직접 확인했습니다. 콘솔 오류·실패한 자산 요청은 없었습니다.

검수의 숨겨진 모달에도 남아 있던 도로 버튼 때문에 처음 선택자가 중복되던 준비는 실제 화면의 도로 HUD로 범위를 한정해 수정했습니다. 전체44px·실제 터치·충돌·자연 타이머 검사를 유지했으며 이 수정과 실제 가시성 수정은 모두 최종 빌드 전에 완료했습니다. 개발 검수 수는 이후 최종 불변 배포 검수에 합산하지 않습니다.

고정한 제품 소스107개·테스트55개에서 원래 Android·콘텐츠 서명으로 APK와 자동 패치를 한 번 만들었습니다. 네이티브 소스9개와 원래 PNG17개를 유지했습니다. 기존 JVM19개 결과는 재사용하고 이번 콘텐츠의 서명·압축 해제·파일 해시는 새로 검증했습니다. 콘텐츠27은 기존 네이티브 엔진8–27과 호환됩니다.

APK61,134,699바이트의 SHA-256은 `b1b26fdc6800fe16250301755b5e28f5dd788720d64a2ff968ef9a1424e36647`, 콘텐츠 ZIP52,761,414바이트의 SHA-256은 `ca1c6cd42b66d0814527f263305323223b2867f13e06ae2c0cb88b0d23f2fc32`입니다.

고정한 소스107개·테스트55개와 불변 배포 사본57개에서 같은 모바일 검수 파일을 실행했습니다. 최종 검수19,620개가 통과했고 실제57개 HTTP 응답의 전체 바이트·해시가 고정 파일과 같았습니다. 네 화면의 이동·저장·재실행, 실제 심기·물 주기·영양·자연 성장·수확·납품·구매, 네 곳의 채집과 대기 중 중복 지급 거절을 확인했습니다. 최종 사진26장은 서로 다른 파일이며 해시가 모두 일치합니다. 불변 파일에서도 트럭 아래 캐릭터가 선명하게 보이는 것을 직접 확인했습니다. 콘솔 오류나 실패한 자산 요청은 없었고 소스·테스트는 빌드 후 변경하지 않았습니다. 개발·과거 검수 수를 이 최종 결과에 합산하지 않습니다.
