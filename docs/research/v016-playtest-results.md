# v0.16 동물 전투 검증

강아지 보리와 고양이 나비가 각자의 체력·레벨로 싸우는 전투를 배포용 파일에서 검증했다. 제품 소스 69개를 동결하고 만든 웹·APK·콘텐츠·단일 HTML을 기준으로 사용했다. Chromium 모바일 터치와 자연 브라우저 시간을 사용했으며 실물 Android 검증은 아니다.

## 직접 확인한 전투

새 플레이어의 실제 이름 선택 → 동물 편성 → 3웨이브·좀비 8마리 승리 → 귀환 → 동물 경험치 저장을 확인했다. 동물별 공격 주체·그림·피격·기술과 HP를 관찰했다. 보리의 돌진·보호, 나비의 광역 발톱, 살아 있는 동료마다 실제 HP 29를 회복하는 기술이 각각 연결된다. 사람의 공격 그림은 전투에 나오지 않는다.

한 동물만 건강한 출전, 한 동료가 지친 뒤 다른 동료의 계속 공격, 낮은 체력에서 자연 패배, 식량·물 1개씩 사용하는 체력 비율 +35 휴식과 물자가 없는 +10 휴식을 확인했다. 주인공 체력 3이어도 건강한 동료와 기력 16이면 출전한다. 출전 동료의 승리 경험치는 단계별 20·25·30이며 패배·철수·재시작 귀환은 경험치를 지급하지 않는다. 경험치 경계 승리와 재로드 후 개별 레벨·체력 저장도 확인했다.

신규 전투 검사만 544개 검증·7개 시나리오·6회 자연 전투다. 실제 프레임의 중앙값 속도는 약 3배이며 초 단위 경과·대기 시간을 유지한다. 수동 일시정지는 실제 조작이며 document.hidden 처리 검사는 명시적으로 숨김 이벤트를 모의한 별도 경로다. 이를 실제 Android 백그라운드 검증으로 주장하지 않는다.

HP·XP 경계나 무료 휴식 등 일부 조건은 명시된 유효 저장 fixture다. 신규 플레이에서 획득한 상태라고 주장하지 않는다. 실제 엔진 결과 18개를 도메인 종료·저장·재로드에 연결한 별도 검사도 통과했다. 잘못된 현대 전투 결과는 보상 없이 원래 상태를 유지한다. 구형 v8·v15 코드가 읽고 다시 저장한 동물 기록도 보존됐다.

## 파일·패치·배포 검증

APK는 기존 패키지 ID·서명을 유지하며 버전 코드는 16이다. 네이티브 소스 9개는 v15와 바이트가 같고 기존 네이티브 단위 결과는 재실행 없이 재사용했다. 새 서명 매니페스트와 ZIP은 네이티브 코드의 공개 키로 별도 JVM 검사를 새로 실행하여 인증·24개 파일·해시·안전한 추출을 확인했다. 콘텐츠는 네이티브 8–16과 호환된다. 신규 고양이 그림 1개를 포함하며 기존 15개 PNG는 보존했다.

최종 QA 폴더는 `/tmp/road-haven-qa-v016-r1`이며 `/House/` 웹·네이티브 준비 화면·단일 HTML의 50개 파일 모두 실제 HTTP 응답과 SHA-256이 같았다. 배포 준비 트리는 972,745,616B로 1GB 미만이며 기존 APK와 v15 웹 캐시 의존 파일을 보존했다. 과거 v10·v11 콘텐츠는 이전 불변 커밋 주소로 보관하며 새 패치 주소는 고정 배포 브랜치를 사용한다.

브라우저의 시작 패치 검사는 실제 UI와 타이머에 개인 Capacitor 브리지·매니페스트 fixture를 연결한 것이다. 실제 휴대폰에서 APK 설치·WebView 실행·자동 패치를 실행한 증거는 아니다. 공개 원본 저장소의 파일 검증은 별도 릴리스 영수증에 기록하며 Pages 직접 호스트는 이 클라우드의 네트워크 정책으로 확인하지 못했다.

단일 HTML은 실제 최종 HTTP 문서를 불러온 뒤 오프라인으로 전투·동료 저장까지 확인했다. 대형 문서의 오프라인 HTTP 재로드는 브라우저 캐시에 없어 실패했고, `file://` 시작은 관리 브라우저 정책으로 차단되어 검증하지 못했다. 실행 중 오프라인 플레이와 오프라인 첫 시작을 구별한다. 네이티브 APK에는 모든 게임 자산이 들어 있다.
