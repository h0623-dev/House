# v0.30 지상 이동 검수

2026년 10월 14일(대한민국 기준), 지상에서 트럭 차체 아래로 들어가 시야가 반투명해지는 문제를 수정했습니다. 트럭 밖 도로의 자유 이동, 사람 사다리, 동물 전용 경사로와 현장 채집은 이어집니다.

## 변경한 동작

지상 이동은 데크·실제 두 차체 상자·운전석·바퀴 그림의 외곽을 하나의 장애물로 사용합니다. 차체 내부를 터치하면 이동 목표를 만들지 않으며, 양쪽 지점이 차체 밖이어도 이동 선분이 차체를 통과하면 바깥으로 우회합니다. 화면 사각형의 빈 모서리는 실제 도로로 남깁니다. 트럭을 반투명하게 그리던 처리는 제거했습니다.

8개 확장 단계에 맞춰 사다리와 동물길의 지상 출입구, 네 채집 장소와 나무를 차체 밖으로 배치합니다. 벌목 그림·터치 범위·효과·작업 경로는 같은 위치를 사용합니다. 동물길의 난간 입구도 실제 문 위치에 맞춥니다. 확장 도중 통로에 있던 동물은 원래 경로를 유지하고 안전한 바깥 지상으로 이어갑니다.

확장된 트럭의 출구에서는 먼저 내려온 동물을 피해 지나갈 도로 폭을 확보했습니다. 최대 동물 발 범위 30.8과 기존 통로 폭을 그대로 사용하며, 경계에 걸친 경로 후보도 전체 원과 이동 선분의 충돌 검사를 통과해야 합니다. 기본 1단계 도로 범위는 유지합니다. 공통 2배 속도, 실제 1분당 기력 3 회복, 기존 저장·생산·비용·보상은 유지합니다.

## 빌드와 실행 연결

게임 소스 113개와 최초 테스트 67개를 고정해 APK·서명 콘텐츠·정적 웹·단일 HTML을 한 번 빌드했습니다. 수정하지 않은 QA 사본 `v030-r1`의 **57개 파일**을 실제 `http://127.0.0.1:4297/House/`에서 HTTP 응답·바이트·해시·worker JavaScript MIME으로 확인했습니다. 최종 플레이도 이 사본에서 실행했습니다.

첫 개발 검수에서 출구 옆 도로가 좁아 고양이가 대기하는 실제 문제를 발견해 수정하고, 그 소스의 전체 412개 검사와 개발 3개 화면을 다시 통과했습니다. 최초 최종 검사에서는 고양이가 정상 속도로 이동하는 동안 직선거리로 계산한 검사 시간이 먼저 끝났습니다. 보존된 실제 남은 데크 경로는 약 53.729초의 검사 시간을 필요로 했고, 원래 직선거리 계산은 약 43.108초였습니다. 실제 처음 허용된 경로를 한 번 계산하고 최초 검사 시각에 고정하는 **테스트 한 파일의 수정**을 승인했습니다. 속도 44와 기존 대기 여유 12초, 충돌·화면·경제 검사는 유지합니다.
