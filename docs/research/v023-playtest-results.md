# v0.23 — 로딩 화면과 건설 시 동물 자리 이동

기존 손그림 자산으로 트럭·집·나무·강아지·고양이를 구성하고 도로 배경, 게임 제목, 진행 안내 패널을 새로 배치했습니다. 360·390 세로 화면과 844 가로 화면을 확인했습니다. 실제 확인·다운로드·검증·적용 단계와 진행률을 사용하며 기존 12초 이어하기, 오프라인 시작과 동작 줄이기 설정을 유지합니다.

건설·집 및 시설 재배치가 성공하면 새 건물과 겹치는 동물만 가까운 안전한 데크로 순간이동합니다. 다음 배치 상태의 전체 건물·난간·주인공·다른 동물과 실제 몸 크기를 확인해 모든 이동을 계획한 뒤 한 번에 적용합니다. 안전한 공간이 없으면 동물이나 자원을 일부만 바꾸지 않습니다. 일반 보행의 충돌 규칙·2배 속도와 동료 체력·경험치는 유지합니다.

전체 단위 검사 289개가 통과했습니다. 새 9개 검사는 실제 Scene의 배치 준비·상태 반영·보행 재개, 집과 시설 이동, 진행 중 생산 시각, 상층의 큰 동물과 공간 부족 시 원자적 거절을 확인합니다. 원래 Android 소스와 서명을 유지하고 코드23·콘텐츠 호환8–23 APK와 서명된 콘텐츠를 만들었습니다. 기존 JVM19개 결과는 재사용했고 새 콘텐츠의 서명·추출·파일 해시는 다시 검증했습니다.

최종 모바일 검수는 같은 불변 빌드에서 실제 Chromium 터치와 자연 프레임·타이머로 21,903개 검사를 통과했습니다. 두 동물이 겹친 새 마을, 실제 편성 조작으로 한 동물만 겹친 명시적 Lv2 저장, 걷는 동물이 있는 확인 순간의 설치와 같은 Scene의 보행 재개 등 3개 설치를 완료했습니다. 주인공과 기존 건물이 있는 자리의 거절도 확인했습니다. 로딩은 4화면 조건의 16단계 화면, 실제 12초 이어하기와 오프라인 시작을 포함하며 총25장 사진을 보관했습니다. 최종 로딩 사진을 직접 열어 SVG 속 실제 원화가 그려지는 것도 확인했습니다. DOM의 img 검사만으로 SVG 이미지 디코딩을 증명했다고 주장하지 않습니다.

검수 준비의 가정을 보완한 과정은 원본과 분리해 기록했습니다. 원래 동결한 테스트와 빌드 캡처를 보존하고, 정확한 승인·패치·실제 실행 SHA를 연결해 집중 검사 한 파일만 수정했습니다. 실제 실패4회(15,680개 부분 검사)와 별도 정상 동물 입력 진단14,074개는 최종21,903에 합산하지 않습니다. 제품93개·나머지 테스트45개·불변 HTTP57개·빌드 산출물은 바뀌지 않았습니다. 수정은 올바른 Lv2 저장 조건, 실제 편성·일시정지 및 저장 조작, 움직임 확인 후 지연 없이 실제 터치를 전달하는 준비에 한정합니다. 물리 크기·속도·확인 순간의 움직임·자원·전체 저장 비교는 완화하지 않습니다.

검수의 Android 업데이트 브리지는 브라우저용 시험 환경입니다. 실물 Android 설치·자동 콘텐츠 적용이나 iPhone/Safari 기기 실행을 검증했다고 주장하지 않습니다. 공개 배포 이후 APK·콘텐츠 전체 바이트와 서명, 웹 파일·서비스 워커 MIME·이전 캐시 파일, 과거 APK 접근을 별도 HTTPS 절차로 확인합니다. 이전 배포와 Git 기록은 보존합니다.
