# v0.14 실제 플레이 비교 결과

출시 후보가 동결된 뒤 `http://127.0.0.1:4235/House/`의 v0.14 r2를 실제 모바일 터치 입력으로 확인했다. 390×844, 360×740 Chromium 모바일 환경이다. 실물 Android를 실행한 결과가 아니다. 기준점은 `current-playtest-v014.md`에 기록된 공개 v0.13 r2다. 수정 중인 5202에서 얻은 중간 결과는 아래 최종 수치에 사용하지 않았다.

최종 r3는 이후 시작 패치 직전의 부재 성장 보존만 보완했다. 게임 모델·장면·아트·CSS 등 54개 제품 파일과 `main.ts`의 시작 함수 외 부분은 r2와 바이트가 같다. r3에서는 시작 패치 248개 검증과 마을·의뢰·저장 복귀 420개 검증을 다시 통과했다. 아래 화면·일상 플레이 수치는 r2의 실제 촬영 기록이며, r3의 실물 Android 촬영이라고 표현하지 않는다.

## 화면에서 달라진 수치

HUD 면적은 투명한 flex 행을 제외한 패널·버튼 사각형 합집합의 4px 격자 근사다. 인접 밭 간격은 캔버스에 실제 표시된 중심 간의 유클리드 거리다.

| 같은 화면 상태 | v0.13 | v0.14 r2 |
|---|---:|---:|
| 기본 화면의 보이는 버튼 | 25개 | 11개 |
| 360×740 기본 화면의 HUD 면적 | 26.1% | 12.8% |
| 360×740 농사 화면의 버튼 | 34개 | 22개 |
| 360×740 농사 화면의 HUD 면적 | 37.5% | 32.7% |
| 360×740 후기 전체 마을 배율 | 0.236 | 0.514 |
| 360×740 후기 전체 마을의 밭 간격 | 19.0px | 41.5px |
| 390×844 후기 전체 마을 배율 | 0.257 | 0.557 |
| 390×844 후기 전체 마을의 밭 간격 | 20.7px | 44.9px |

후기 마을은 기준점과 동일한 데크 6·밭 18·시설 12의 **선언된 저장 fixture**다. 새 플레이에서 얻은 상태라고 주장하지 않았다. v0.14에서는 전체 트럭을 한 화면에 넣기 위해 축소하지 않는다. 밭 18개는 기본 화면에서 모두 닿고 시설 중심 12개 중 7개는 보인다. 오른쪽 구역은 수평 드래그로 접근한다. 실제로 맨 끝 12번 시설의 생산 버튼까지 이동하고 눌러 생산 시작 기록이 1회 늘어나는 것을 확인했다. 상시 시설 이름표가 없어져 각 시설의 그림이 보이고, 생산 상태는 해당 시설 위에 나타난다.

최종 화면 증거는 `artifacts/audit-v014-final/`의 `01-fresh-home-390.png`, `13-fresh-home-360.png`, `16-declared-late-home-390.png`, `18-horizontal-pan-far-facilities.png`, `20-declared-late-farm-360.png`에 있다.

## 실제 진행에서 확인한 수정

- **같은 목표 칩으로 진행과 보상:** 첫 탐색을 1번 터치로 시작하고, 완료 후 같은 위치에서 1번 터치로 보상을 받았다. 수확·시설 상세창을 열어도 칩이 남는다. 수확과 물 주기 도중 칩을 눌러 성장 목표 상세를 읽을 수 있었다.
- **주인공이 일하는 동안 메뉴를 읽기:** 실제 도로 탐색 중 마을 메뉴와 설정을 열었다. 씨앗 두 밭을 예약하고 창고를 열었을 때, 두 밭 모두 완료됐으며 창고는 닫히지 않았다. 물 주기 예약이 끝날 때도 읽던 성장 목표 상세창이 유지됐다.
- **생산 시간의 연속성:** 45초로 표시된 정수소 생산 중 실제 도로 탐색을 수행했다. 카운트다운은 작업 중에도 줄고, 탐색 완료 때 갑자기 건너뛰지 않았다. 기록된 시작 이후 **44.116초**에 준비 상태가 됐다. 클릭 기록과 전역 1초 틱의 시작 위치 때문에 45초와 약 0.9초 차이가 있다. 수정 전 개발 중 관찰된 27초 완료 결과는 최종 동결 빌드에서 재현되지 않았다.
- **지도에서 생산품 바로 받기:** 정수소의 준비된 생산품을 지도에서 1번 눌렀다. 물이 정확히 4 늘고 생산품 수령 기록이 정확히 1 늘었다. 시설 상세창을 먼저 여는 2단계 조작이 필요하지 않았다.
- **유료 물자 교환과 다음 의뢰:** 작업 중에는 의뢰를 읽을 수 있지만 납품 버튼은 잠겼다. 작업 완료 후 실제 물 3을 보내 목재 8·고철 3·경험치 12를 받았다. 보상만 얻거나 재료를 쓰지 않은 진행이 아니며, 다음 식량 의뢰로 바뀌었다.
- **생산에서 마을 확장까지:** 위 과정과 실제 씨앗 심기·물 주기·부엌 건설을 이어 성장 목표를 진행했다. 실제 목재 24·고철 12를 사용해 데크 2와 네 번째 밭을 얻었다. 이어 목재 12·고철 6을 추가로 사용해 다섯 번째 밭을 만들었다. 시설과 기존 작물은 유지됐다.
- **캐릭터와 밭의 터치 구분:** 별도 신규 360 화면에서 익은 밭 중심을 실제로 눌렀다. 캐릭터 변경창이 열리는 대신 수확이 실행됐다. 전체 판정이 모든 위치·모든 포즈에서 검증됐다는 뜻은 아니다.

생산품 수령, 의뢰 지급, 농사 예약, 데크·밭 확장은 모두 UI와 실제 터치로 실행했으며 게임 함수를 직접 호출하지 않았다. 후기 화면의 추가 시설과 18칸 상태만 명시된 fixture를 사용했다.

## 증거와 검사 한계

최종 기록은 `artifacts/audit-v014-final/records.json`, 통과 요약은 `summary.json`, 실제 화면 영상은 `gameplay-v014-r2.mp4`에 있다. 브라우저 실행 오류와 실패한 그림·폰트·스크립트 요청은 없었다.

촬영 스크립트가 숨겨진 이전 지도 버튼을 먼저 찾는 선택자 실수로 한 번 멈췄다. 선택자를 열린 메뉴 내부로 한정하고, 이미 실제 플레이로 얻은 데크 2 저장 상태에서 촬영을 이어갔다. 제품 코드나 동결 빌드는 이 재개 과정에서 수정하지 않았다. 전체 기록에 이 경위와 원래의 timeout도 남겼다. 최종 영상은 이 두 촬영 구간을 연결했다.

이 검사는 화면 밀도, 가독성, 현재 목표 동선, 작업 중 탐색, 실제 생산 시간, 물자 교환과 확장을 확인한다. 실물 Android 설치·실물 터치 성능·실제 앱 패치 설치를 검증한 것으로 확대하지 않는다. 네 참고 게임의 모든 콘텐츠나 전투 파티·길드·경쟁 시스템이 같아졌다는 의미도 아니다. 전투 구조 등 이번 변경 범위 밖에 남는 차이는 참고 자료 비교 보고서에서 별도로 설명한다.
