# v0.27 게임플레이 조사와 설계

조사일: 2026-10-13, 한국 시간. 비교 기준은 v0.26 소스 커밋 `f6d8663`이다. 사용자의 ‘각수’는 쿠키런: 킹덤·아쿠아랜드: 크레이지 서바이벌·룰더스카이·클래시 오브 클랜이며, 이번 조사에는 레알팜을 함께 포함한다. 사용자가 앞서 선택한 중심 재미인 **마을 건설과 성장**을 기준으로 변경을 제안한다.

발행자가 게시한 화면 26장을 새로 HTTP200으로 받아 각각 열어 보았다. 쿠키런 11장·클래시 4장·아쿠아랜드 7장·룰더스카이 4장이다. 일부는 같은 구도의 반복 화면 또는 광고 합성 이미지다. 이를 서로 다른 26회 플레이 기록이라고 취급하지 않는다. 레알팜은 같은 날 v0.26 조사에서 받아 보존한 화면 4·6·8번을 다시 열고 원본 SHA-256이 일치함을 확인했다.

- **쿠키런 화면 7·21:** 하단 다섯 동료 카드, 체력, 기술, 전투 시간, 자동·속도 버튼이 있는 전투 화면이다. 19번은 자원 HUD와 여러 시설·테마 장식이 있는 왕국 전경이다. 정지화면에서 실제 조작 순서나 해금 비용을 측정하지 않았다.
- **클래시 화면 2·4:** 등각 마을 지도가 보이는 상태에서 초록 배치 영역, 시설 그림, 확정·취소 조작을 보여 준다. 건설·배치 선택이 마을 전경과 이어진다. 화면 1은 유닛 카드와 자원이 보이는 전투, 화면 3은 클랜전 지도다.
- **아쿠아랜드 화면 3·4·5:** 뗏목 생활 공간, 낚시와 식량 공급, 주방의 식량 분배, 부유 농장 경작을 설명하는 광고 합성 화면이다. 이 광고만으로 실제 수확량·일꾼 속도·분배 규칙을 확정하지 않는다. 6·7번은 심해 탐색 광고다.
- **룰더스카이 화면 1·2:** 넓은 빈 잔디와 작은 시작 시설에서 여러 시설·장식을 놓은 섬으로 바뀌는 모습을 보여 준다. 3번은 배치 스케치북, 4번은 친구 프로필이 포함된 마을 화면이며 소개의 꾸미기·소셜 설명과 일치한다.
- **레알팜 화면 4·6·8:** 밭의 모종 심기·거름 주기·수확·밭 갈기 행동, 밭 사이의 여러 동물, 단출한 시작 농장에서 확장·꾸민 농장으로의 변화를 보여 준다.

원문 HTML·읽은 텍스트·HTTP 기록·그림의 URL과 SHA-256은 Git에서 제외된 `artifacts/research-v027/`에 보존했다. 전체 기록은 `primary-gameplay-research.json`이다. 참고 게임 그림을 제품 자산으로 가져오지 않는다.

이번 확인은 **공식 소개와 발행자 정지화면 조사**다. 다섯 게임을 설치해서 직접 플레이하거나 영상을 재생·시청한 결과가 아니며, 비공개 개발 문서를 확보하지 않았다. 실제 첫 10분 동선, 최신 생산 대기열 규칙, 서버 시간, 과금 가격과 경제 균형을 측정한 것으로 표현하지 않는다. 이전 레알팜 가이드·고객센터의 CONNECT403은 그대로 기록하며 우회 접속하지 않았다.

## 현재 플레이에서 확인한 차이

v0.26에는 이미 반복 농사 대기열, 작물 여섯 종, 동물 편성과 전투, 마을 성장 목표, 건물 개선·이동·회전, 데크·상층 증축, 상점과 실제 의상 착용이 있다. 생산품 직접 수령과 ‘받고 다시 생산’, 짧은 부재 동안 기존 작물·시설 시간을 진행하는 기능도 존재한다. 이를 이번 새 기능이라고 다시 소개하지 않는다.

## 구현 우선순위: 행동이 서로 이어지게 한다

### 1. 트럭 밖에도 실제 생활 동선을 만든다

주인공이 밟을 수 있는 도로를 넓힌다. 트럭의 데크와 도로는 같은 평면으로 취급하지 않고 기존 사다리로 연결한다. 트럭·바퀴·나무 등의 실제 장애물은 몸 전체의 충돌 범위로 피하고, 보이는 빈 도로는 이동할 수 있게 한다. ‘트럭 밑’ 요청은 트럭에서 내려와 주변 도로를 걷는 것과 배경에 보이는 하부 공간을 실제로 사용할 수 있게 하는 것으로 해석한다. 불투명한 차체 내부나 바퀴를 관통하는 이동은 자유 이동으로 간주하지 않는다.

도로 채집 대상은 눌렀을 때 그 자리로 걸어가 작업하고 물자를 받는 방식으로 연결한다. 단순히 넓어진 곳을 클릭해서 보상이 즉시 생기게 하지 않는다. 모은 자원은 씨앗 구입·이웃 납품·새 시설·트럭 확장에 실제 사용한다. 이동 표식과 채집 표식, 드래그로 화면 이동하는 행동이 구별되어야 한다. 상층만 보는 동안 아래 도로의 숨은 대상을 잘못 누르지 않아야 한다.

### 2. 씨앗 선택에 목적을 만든다

현재 저장의 공통 식량을 유지하면서 업데이트 이후 실제 수확한 작물의 종류를 기록하는 방식을 선택했다. 품종별 수확물은 전체 식량 안에 포함되며 두 번째 식량 잔고가 아니다. 납품할 때 해당 품종과 전체 식량을 같은 수량만큼 한 번 사용한다. 일반 식량을 쓰는 휴식·판매·영양 주기는 품종 미분류 식량을 먼저 사용하고, 부족하면 보관함의 당근→감자→토마토→옥수수→딸기→호박 순서로 사용한다.

이전 저장에 품종 기록이 없으면 새 품종 보유량은 0부터 시작하고 이미 모은 식량·씨앗·밭·성장 기록은 그대로 둔다. 저장을 읽거나 의뢰를 여는 것만으로 새 작물이나 보상을 만들지 않는다. 무엇을 심을지 고를 때 씨앗 재고·성장 초·물 필요량·의뢰 대상 여부를 함께 읽을 수 있어야 한다.

현재 심기의 영양 돌봄은 자라는 동안 한 번 식량 1·기력 2를 사용해 수확량을 2 늘린다. 이는 물 주기와 별개며 성장 속도·심은 시점·물 주기·완료 시점을 변경하지 않는다. 수확 후 같은 밭에 새 씨앗을 심으면 영양도 새로 결정한다. 아래는 참고 게임에서 가져온 수치가 아닌 로드헤이븐의 독자적인 납품 균형이다.

### 3. 농사·도로 채집·마을 투자에 다음 목적을 붙인다

사용자의 목표는 마을 성장이다. ‘요청 확인 → 씨앗 선택 → 심기·물 주기·수확 → 요청 완료 → 재료·코인 → 다음 시설·밭·데크’가 연결되게 만든다. 작업 중 창을 다시 열어 같은 선택을 반복하게 하지 않고, 기존 연속 농사와 작업 대기열을 유지한다. 의뢰 완료는 비용 또는 실제 작업 실적을 확인한 후 한 번만 보상하며, 이후 주문이 현재 주문을 덮어써 오지급하지 않도록 고유한 순서 번호로 구별한다.

도로 활동도 같은 성장 목적에 연결한다. 채집으로 목재·고철·물·씨앗을 모았을 때 그 자원으로 할 수 있는 다음 투자를 알려 준다. 기존 동물의 사냥은 마을로 돌아올 이유가 되는 건설 재료와 동료 성장을 이어간다. 전투의 모든 규칙을 이번 한 번에 다른 게임 규모로 복제한다고 주장하지 않는다.

### 4. 확장 전후와 배치 결과를 지도에서 읽게 한다

클래시의 공개 배치 화면과 룰더스카이·레알팜의 성장 전후 화면에서 참고하는 핵심은 새 창의 수가 아니라 **바뀐 공간과 사용처가 보이는 것**이다. 건설할 때 초록 발자국·가능 여부·확정·취소가 실제 지도 위에서 읽혀야 한다. 데크·밭·층을 늘리기 전 현재와 다음의 사용할 자리와 효과를 보여 주고 완료 뒤 그 공간을 찾아 사용할 수 있게 한다. 확장 효과를 설명하는 숫자와 실제로 열린 자리는 반드시 같아야 한다.

## 실제 검수에서 확인할 항목

- 작은 세로 화면에서 트럭 주변의 새 도로를 눌러 실제로 내려가고 도착하는가. 몸 전체가 차체·바퀴·나무·다른 동물을 관통하지 않는가.
- 도로 목적지 이동과 도로 대상 채집, 지도 드래그·핀치가 서로 잘못 실행되지 않는가. 현재 표시한 층의 대상만 상호작용하는가.
- 작물별 요청이 실제 새 심기·물 주기·수확 또는 정직한 보유량에만 반응하는가. 주문 시작 전 실적을 이후 주문에 반복 지급하지 않는가.
- 보상·판매·구매·씨앗 소비를 동시에 누르거나 다시 불러왔을 때 한 번만 반영되는가. 기존 저장의 식량·시설·층·동물·의상이 이어지는가.
- 농사를 이어서 하는 중에 남은 초·씨앗·물·대기 순서를 읽고, 기다리는 동안 가능한 마을 활동을 찾을 수 있는가.
- 건설·확장 안내가 실제 열린 자리·밭·층과 일치하는가. 작업 속도는 사용자가 선택한 공통 2배를 유지하는가.

이 문서는 공식 자료에서 실제 확인한 내용과 변경 설계의 근거다. v0.27의 구현 완료 범위·테스트 수·APK·콘텐츠 서명·공개 배포 결과는 별도 릴리스 검수 기록에서 확정한다.
