# v0.33 한 번 터치 채집과 현장 표식

나무·고철·씨앗 풀·샘물의 그림이나 표식을 누르면 주인공이 직접 걸어가 작업합니다. 개별 채집 상세창과 두 번째 확인 버튼을 없앴습니다. 명시적으로 여는 채집 구역 목록에서도 대상을 고르면 곧바로 작업하며, 기력 부족·재생 대기는 작은 알림으로 안내합니다. 건설 선택·배치 창은 유지합니다.

현장 표식에는 자원 그림과 한국어 이름, 준비된 개수 또는 남은 초를 표시합니다. 같은 종류는 한 표식으로 묶어 최대 네 개만 보이게 하고, 실제 나무와 소품 그림은 각각 독립적으로 누를 수 있습니다. 표식은 68×34 CSS픽셀, 터치 영역은 68×44 CSS픽셀입니다. 실제 HUD 버튼과 여백을 두며, 짧은 가로 전체 보기에서는 지도 옆에 배치하고 작업 중 주인공을 피합니다. 지도 배율·기존 카메라·이동 경로를 표식에 맞춰 바꾸지 않습니다.

## 검증

전체 단위 검사 465개가 통과했습니다. 표식은 모든 배율에서 종류별 최대 네 개를 유지하고 모든 원래 자원 ID를 보존합니다. 실제 수관과 숲길을 사용한 좁은 화면, 자원 선택 우선순위, 작업 중 주인공 여백, 그림 접점과 별개인 44px 터치 영역을 검사합니다.

개발 브라우저는 Chromium 모바일 에뮬레이션 390×844·344×740·844×390에서 38,132개 검증과 실제 채집 11건을 통과했습니다. 네 자원의 그림·표식 터치와 목록 선택, 중복 입력, 완료 후 정확한 한 번의 보상·비용 반영을 확인했습니다. 재생 대기 알림 6회와 기력 부족 알림 1회, 재접속 4회, 기존 건설 창 3개를 확인하고 원본 캔버스 23개를 포함한 화면 73개를 보존했습니다. 실제 신뢰된 모바일 입력의 최종 대상이 Canvas인지 확인하며, DOM 메뉴에 가려지거나 다른 수관 뒤로 완전히 가려진 점을 억지로 터치하지 않습니다. 시계·기력·보유량·위치·경로를 실행 중 주입하지 않았습니다.

재생·경제·기력 회복의 핵심 소스는 v0.32와 같습니다. 실제 180초 독립 재생은 원본 v0.32 불변 검수의 바이트·소스 해시를 함께 확인해 재사용합니다. 이번에 새 3분 실험이나 별도의 20초 유휴 회복 실험을 수행한 것으로 표현하지 않습니다. 이번 실제 채집 중 관측한 기력 회복은 거래 재현에서 확인합니다.
