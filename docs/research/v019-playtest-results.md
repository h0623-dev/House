# v0.19 — 공통 게임 속도 2배

사용자 피드백에 따라 공통 배율을 3에서 2로 낮췄습니다. 걷기·사다리·농사·채집·시설 작업·생산·작물 성장·전투가 직전 버전보다 약 1.5배의 시간을 사용합니다. 시설 마무리 작업의 고정 시간도 공통 배율로 환산했습니다. 카메라·터치·메뉴·네트워크 재시도 시간은 별도로 유지합니다.

| 항목 | v0.19 실제 시간·속도 |
| --- | --- |
| 보행 / 사다리 | 400 / 240 논리픽셀/초 |
| 채집 / 벌목 현장 작업 | 1.2 / 1.275초 |
| 씨앗 심기 / 물 주기 / 수확 | 0.75 / 0.75 / 0.825초 |
| 시설 건설·개선 마무리 | 0.825초 |
| Lv.1 정수소 생산 / 물을 준 당근 성장 | 11.25 / 45초 |
| 전투 기술 대기 표시: sweep / dash / heal | 6 / 5 / 12초 |
| 마을 시계 / 부재 반영 상한 | 초당 4게임분 / 실제 105초, 최대 420게임분 |

저장 형식·자원·비용·보상과 생산의 `startedAt`·`readyAt`은 유지합니다. 남은 76게임분은 새 속도에서 19초로 표시하며, 소수 단위 완료 시점과 화면의 올림 표시는 구분해서 검사했습니다.

## 최종 빌드 검증

수정하지 않는 `v019-r1` 사본에서 검증했습니다. 제품 소스 80개와 웹 30개·네이티브 26개·단일 HTML을 포함한 57개 파일의 SHA-256, 실제 로컬 HTTP 응답의 전체 바이트를 대조했습니다.

| 검사 | 통과 |
| --- | ---: |
| 게임 단위 테스트 | 206 |
| 전체 플레이·구형 저장·전투·화면 회귀 | 576 |
| 실제 모바일 터치·자연 시간·29개 작업 | 857 |
| 생산·씨앗·전투의 초 표시와 자연 완료 | 203 |
| 실제 v0.18 → v0.19 자동 패치 | 483 |

자동 패치 검사는 수정하지 않은 두 버전과 실제 Service Worker를 같은 로컬 주소에서 순서대로 제공했습니다. 각 버전의 30개 파일과 실제 캐시 28개를 대조했고, 농사 완료 후 홈에서 한 번 자동 재시작했습니다. 이전 전투에서 얻은 강아지·고양이 경험치와 부상, 자원·밭·진행 중인 정수소 생산 종료 시점이 보존됐으며 마을 시계는 실제 초당 6게임분에서 4게임분으로 바뀌었습니다. 새 버전의 완전한 오프라인 재실행도 통과했습니다.

APK는 원래 서명·앱 ID로 버전 코드 19를 빌드했습니다. 새 콘텐츠 ZIP의 원래 공개 키 서명과 전체 파일을 호스트 JVM에서 새로 검증했고, 바이트가 같은 네이티브 소스 9개의 기존 Java 테스트 19개는 재실행 없이 재사용했습니다. 콘텐츠는 네이티브 엔진 8–19와 호환됩니다.

검사 범위는 Chromium의 모바일 화면·실제 터치·브라우저 타이머와 Service Worker입니다. 전체 화면 회귀에는 가상 시계와 명시한 구형 저장 경계 사례를 사용했습니다. 물리 iPhone/Safari 설치나 Android 기기 설치·자동 패치 실행은 확인하지 않았습니다. 공개 호스트는 배포 후 정상 HTTPS 응답의 전체 바이트·해시·서명으로 별도 검증합니다. 이전 검사와 실패 진단 자료는 덮어쓰지 않고 보관합니다.
