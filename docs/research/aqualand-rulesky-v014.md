## 이번 수정에 우선 권고하는 5개

아래는 **현 게임 관찰에 따른 설계 제안**이다. 아직 확인하지 못한 참고 게임의 기능을 그대로 구현한다고 주장하지 않는다.

1. **지도에서 바로 수령:** 완료된 시설의 자원 아이콘을 누르면 즉시 정확히 한 번 수령한다. 일반 건물을 누르면 시설 시트를 열되, 수령을 누른 의도는 추가 창을 거치지 않는다. 받을 수 없는 상태·재료 부족·지도 이동 모드에서도 오작동하지 않아야 한다.
2. **시설 상태를 지도에 표시:** 생산 가능·생산 중·수령 가능·재료 부족을 서로 다른 아이콘과 짧은 숫자로 표시한다. 완료 버블은 자원 종류를 보여 주고, 진행 표시는 선택한 시설에서만 자세히 보인다. 유휴 시설의 시작도 직접 접근할 수 있게 한다.
3. **현재 목표를 한 곳으로 모으기:** 성장 목표 버튼과 큰 목표 카드의 중복을 줄이고, 지도 위에는 현재 행동 한 줄·진행 숫자·단일 행동 버튼만 남긴다. 완료 시 그 자리에서 수령하며 다음 목표를 바로 보여 준다. 전체 목표·상세 보상은 필요할 때 연다.
4. **확장 결과를 지도에 연결:** 지도에서 다음 확장 영역과 새로 열릴 밭·시설 자리 수를 확인한 후 확정한다. 확장 직후 새 영역을 밝히고 카메라가 보여 주는 크기를 유지해 넓어진 결과를 읽을 수 있게 한다. 허용 구역·재료 부족은 막연한 토스트가 아니라 선택한 영역에서 안내한다.
5. **밭을 중심으로 농사 조작:** 빈 밭을 누르면 씨앗 선택, 물이 필요한 밭을 누르면 물 주기, 익은 밭을 누르면 수확으로 이어지는 작은 컨텍스트 UI를 제공한다. 씨앗 선택 후 반복 심기와 화면 이동은 유지하며, 선택한 밭을 찾기 위해 순환 버튼·트레이·인벤토리를 번갈아 여는 횟수를 줄인다.

오프라인 생산·여러 일꾼·자동 반복·소셜은 주기·경제·기존 저장·네이티브 엔진 호환에 영향을 준다. 참고 게임 원문을 읽지 못한 상황에서 즉석 복제 기능으로 넣지 않고, 별도 사양과 실제 검증을 전제로 후속 판단한다. 이번 UI 동작 수정의 검수는 작은 세로 화면에서 지도 점유, 터치 회수, 정확히 한 번의 비용·보상, 드래그와 행동 충돌, 기존 마을 저장의 연속성에 집중한다.
