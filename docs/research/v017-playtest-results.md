# v0.17 출시 검수 기록

기준 버전: v0.17.0, Android 코드17, 네이티브 콘텐츠 호환8–17. 이전 공개 소스는 `9adce100b52370bf2d68a621cf6768b3968ce08f`이다.

## 구현과 확인 범위

동물6종·최대3마리 편성, 각 역할의 기술과 출전별 HP/XP 저장, 시설Lv.5·실제 생산시간 개선·전투 지원 효과, 빠른 현장 작업, 데크8/시설16자리/밭24칸, 맵이 보이는 하단 건설 목록과 확장 미리 보기를 검수한다. 기존24개 목표 뒤에8개 목표를 추가하며, 개선한 시설을 교체하거나 팀을 줄인 뒤에도 수령한 기록을 보존한다.

공식 스토어·홍보 이미지13장·Clash 공개 UI 개편 설명·공략·쿠키런 공개 개발자료는 [비교 조사](../V0.17-SYSTEMS-COMPARISON.md)에 원문과 날짜를 기록했다. 영상 시청과 비공개 개발 문서 열람은 하지 못했다.

## 단위와 화면 검증

최종 제품 소스의 TypeScript 검사와 단위 테스트181개가 통과했다. 실제 시설생산6종×Lv.1–5의 완료 직전/정확 경계, 옛 생산시각 보존, 동물 역할/대상/치유/피해/정확한 결과 적용, 원정 중단 복구와 기존 저장을 확인한다. 시설Lv.5 교체와3인→2인 편성 이후 납품·저장·재로드에서도 최고시설레벨/최고편성규모/모든 동물진행을 보존하는 회귀 검사를 포함한다.

독립 Scene 화면검사는3화면크기·데크1–8·건설/배치/확장의69조합에서 실제시설발판과높이·추가공간을 가리지 않는지 확인했다. 이 수치는 통합 게임의 최종 브라우저 검사와 합산하지 않는다. 실제 가로780×390 통합 화면에서 배치맵 높이가86px로 줄어드는 문제를 발견하고, 짧은 왼쪽건설바 영역만 예약하여400×204px 지도 공간을 제공하도록 수정했다. 가로화면11개 추가검사와 실제지도자리터치도 통과했다.

최종 배포 파일을 복사한 별도 불변 HTTP 스냅샷 `v017-r1`에서 모바일 조작·실시간 작업·저장·전투·패치 준비 흐름을 검증했다. 제품 소스72개는 빌드 시작 때의 SHA-256과 같으며, 웹26개·네이티브25개·단일HTML1개의 총52개 파일은 스냅샷과 실제 HTTP 응답 바이트가 모두 같다. 개발서버 사전진단과 실패한 검사 기록은 최종 성공 수에 포함하지 않는다.

모든 성공 기록은 같은 최종 스냅샷을 사용하며 실행 오류·실패한 자산 요청이 없다. 여섯 시스템 검사는360×720/390×844/780×390에서24개 실제시간 행동과두 편성의 자연승리를 확인한다. 토끼의 실제치유31HP, 여우3연타, 멧돼지보호·도발, 부엉이범위피해·적이동감속을 관찰했다. 단일HTML에서는 실제터치로 토끼·여우·부엉이를 편성해3웨이브/8마리 승리와참가자만20XP저장까지 확인했다. 고레벨·체력·자원 경계는 명시한 유효 저장 fixture이며, 신규플레이에서 모두 획득했다는 증거로 취급하지 않는다.

사전 실패는 구형숨김메뉴·순간카운트다운·공개동작명/그림프레임명 혼동·열린카메라버튼으로전달된모바일터치 등의 검사경로를 실제UI/타이머/프레임에 맞춘 뒤 전체검사를 재실행했다. 원래 검사 의미를 제거하지 않았고 최종 제품 파일을 변경하지 않았다. 실패 진단은 별도 보관한다.

## Android와 배포 경계

원래 Android 서명 키와 고정 콘텐츠 공개 키를 재사용한다. APK·서명된 콘텐츠 ZIP·정적 웹·단일 HTML의 바이트/파일해시를 비교하며, 새 압축의 서명·경로·파일목록 검증은 JVM에서 실행한다. 연결된 Android 기기나 에뮬레이터가 없어 실제휴대폰설치·OTA 적용은 별도로 검증하지 못했다. 브라우저 네이티브 브리지 모의 검사는 실제기기 OTA 성공과 구별한다.

APK57,878,580B·콘텐츠ZIP49,434,259B·단일HTML84,120,075B를 검증했다. 네이티브Java9파일은v0.16과 같아서 기존JUnit19개 결과는 재실행 없이 재사용했으며, 새 서명ZIP 인증·안전추출·25파일해시 검증은 새로 실행했다. 배포 준비 트리는72파일989,295,338B이며 기존APK14개와체크섬, v0.15/v0.16캐시의존파일을 보존한다. v0.12/v0.13콘텐츠4파일은 삭제 전에 이전불변커밋에서 전체HTTP해시를 확인하고 보관 링크를 기록했다.

최종 성공 원본은 `artifacts/*-v0.17.0-verification.json`, `qa-snapshot-v017-r1.json`, `qa-http-identity-v0.17.0.json`, `native-v017-build-source-snapshot.json`에 있다. 공개원본의 응답·서명·전체해시 검증은 `public-v0.17.0-verification.json`과 `public-raw-web-v0.17.0-verification.json`에 별도로 기록하며, 공개Pages호스트 접근과실물Android실행의 검증 범위를 구별한다.

단일 HTML의 오프라인 검증은 HTTP로 문서를 로드한 뒤 네트워크를 끊고 플레이하는 범위다. 관리 브라우저의 파일주소 접근 제한을 우회하지 않으며, 오프라인 최초실행/재로딩의 성공으로 기록하지 않는다.
