# v0.43 플레이 경험 검토

조사일: 2026-10-16, 한국 시간. 사용자가 이번에 직접 플레이와 참고 게임 조사를 요청하여 진행했다.

현재의 가장 큰 문제는 기능 수보다 **작업 대상을 읽는 화면, 반복 이동, 행동과 보상의 연결**이었다. 첫 화면에 모든 채집 구역을 넣으면서 트럭과 밭이 지나치게 작아졌고, 지상에서 시작한 농사는 매 밭마다 원래 지상 위치로 돌아갔다. 생산 안내도 버튼의 명령과 실제 실행이 달랐다. v0.43은 이 조작 기반부터 수정했다. 마을 성장의 장기적인 목적까지 완성됐다고 보지는 않는다.

## 무엇을 직접 확인했는가

로드헤이븐은 별도의 새 저장으로 Chromium 모바일 터치 에뮬레이션에서 실제 UI를 조작했다. v0.42에서 채집·수확·씨앗 선택·연속 심기·급수·시설 배치·생산·수령·동물 전투·마을 귀환을 진행하고, 수정한 v0.43에서 문제가 있던 행동을 다시 수행했다. 저장 자원이나 진행 카운터를 임의로 바꿔 성공을 만들지 않았다. 아래 수치는 해당 화면·계정·표본의 관찰값이며 모든 기기의 성능 수치는 아니다.

| 문제 | v0.42에서 본 결과 | v0.43에서 다시 확인한 결과 |
| --- | --- | --- |
| 첫 진입 | 짧은 가로 화면에서 시작 조작을 찾으려 스크롤이 필요했다 | 844×390, 720×360 두 화면에서 캐릭터·이름·시작 버튼이 보였다 |
| 기본 지도 | 전체 지상 경계를 한 번에 맞춰 축척 약0.085, 시작 밭은 약9×5 CSS px로 작았다 | 기본은 트럭과 가까운 도로의 생활뷰 약0.265. 명시적 전체 보기는 약0.085로7개 구역을 유지했다 |
| 매 작업 왕복 | 첫 채집 후 지상에 남은 주인공이 농사·시설 작업마다 지상으로 복귀했다. 두 밭 파종을 예약해도 두 번째 작업이 약30초 후 이동 중인 장면을 관찰했다 | 첫 수확 후 실제 발 위치가 데크에 남았다. 두 밭을 실제로 선택한 파종이2.91초에 완료됐고, 기록한 중간 표본 모두 데크였으며 파종 실적이2로 늘었다 |
| 생산 안내 | ‘생산 시작’·‘물자 받기’를 누르면 시설 패널이 먼저 열려 추가 실행이 필요했다 | 상단 안내를 한 번 눌러 생산 실적0→1. 자연 대기 후 준비된 수령 안내를 한 번 눌러 물17→21, 수령 실적0→1을 확인했다 |
| 도로 이동 중 시야 | 기본 화면과 작업 화면의 크기가 크게 달라져 현재 조작 범위를 읽기 어려웠다 | 직접 확대한1.25배·pan `[-301.98, -45.297]`·축척0.331이 계단→도로 이동의8개 표본에서 그대로 유지됐다 |

생산이 아직 남았을 때의 안내는 ‘생산 확인’이었고 미완성품을 지급하지 않았다. 완료 이후 실제 수령을 확인한 결과와 구분한다. 채집지 안내는 해당 현장을 보여주되 작은 고철 하나에 지나치게 확대되는 것도 이번 플레이에서 발견하여 자동 확대 상한을 조정했다. 사용자가 직접 고른 확대는 별도다.

v0.42의1구역 전투는 강아지·고양이와 수동 기술 조작으로 실제 승리했다. 결과는 적8마리,37초, 식량8·목재2·고철2·플레이어 경험치30이었고 마을로 귀환했다. v0.43은 전투 규칙을 바꾸지 않았으며 이 전투를 다시 플레이했다고 보고하지 않는다.

## 코드에서 확인한 원인

- **왕복:** 개별 채집은 `stayAtTarget`로 현장 종료했지만 농사·시설 방문에는 출발점까지 돌아가는 시간을 붙였다. 농사 큐는 귀환까지 기다리고 다음 밭을 시작했다. 이제 실제로 도착해 작업한 자리에 머물고 다음 작업은 그 발 위치에서 출발한다. 수동 ‘트럭으로’ 이동, 충돌 판정과 중단 시 안전한 발 위치는 유지한다. 관련 파일: `src/scene.ts`, `src/scene-navigation.ts`, `src/main.ts`.
- **카메라:** 기본1층 경계가 트럭·전체 도로·동물 통로·7개 채집 지역을 모두 합쳤다. 이 전체 영역을 짧은 화면 안에 맞춘 결과가 축소였다. 기본 생활뷰와 명시적 전체지도를 구분하고, 수동 확대·이동을 유지한다. 관련 파일: `src/player-camera.ts`, `src/scene.ts`.
- **안내:** 마을 목표의 시설 목적지는 생산/수령 명령을 갖고도 시설 선택만 실행했다. 바로 실행할 수 있는 생산·수령은 안내에서 직접 수행하도록 연결했다. 시설의 레벨·재배치 같은 상세 관리도 계속 접근할 수 있다. 관련 파일: `src/village-guide.ts`, `src/main.ts`.

이 원인 분석은 실제 UI 관찰을 코드로 설명한 것이다. 카운터가 올랐다는 이유만으로 아트·동물 이동·모든 기기 조작이 완성됐다고 판단하지 않는다.

## ‘각수’에서 실제로 참고한 부분

쿠키런: 킹덤, 아쿠아랜드: 크레이지 서바이벌, 룰더스카이(사용자가 부른 ‘롤더스카이’), 클래시 오브 클랜의 **공식 소개·개발 글·게시 이미지를 읽고 보았다**. 네 상용 앱을 설치하여 직접 플레이하지는 못했다. 홍보 합성 이미지를 신규 계정의 실제 UI나 정확한 시간·탭 수로 취급하지 않았다.

영상 접근에는 한계가 있었다. YouTube 및 일부 공식 스토어 동영상 호스트는 정상 HTTPS 경로에서 CONNECT403으로 재생하지 못했다. 접근 가능한 Devsisters의45.27초짜리 **점핑 플랫폼 미니게임 개발 소개 영상**에서는 실제12·24·36초 프레임을 보았다. 조작과 지표를 같은 위치에 유지하고 행동 결과를 화면 안에 드러내는 점을 참고했다. 이것은 킹덤 본편 건설·전투 영상이나 네 게임의 첫10분을 시청한 근거가 아니다. 비공개 개발 문서를 확보했다고 주장하지 않는다.

## 아직 남은 우선순위

1. **첫10분의 성장 동선과 기력 소비를 함께 조정한다.** 회복은 사용자 요구대로 실제1분당3을 유지한다. 현재 코드의 농사 한 밭은 심기4+급수3+수확4=11기력이고 회복에220초가 든다. 직렬 성장목표의 첫 전투는15번째이며 그 전에8회 수확을 요구한다. 초기85와10분 회복30을 합친115기력에 비해 그 경로의 최소 소비는146이다. 이것은 코드 산술이며 실제 클리어 시간을 측정한 결과가 아니다. 전투 메뉴 자체는 처음부터 열려 있다. 입문 목표의 순서·필요 반복·소비를 조정하여 첫 확장과 첫 원정이 자연스럽게 이어져야 한다.
2. **전투 준비에서 중요한 선택과 입장을 먼저 읽게 한다.** 실제 전투 준비 화면은11종 전체 편성과 아래쪽 입장 버튼을 찾아 스크롤하는 부담이 있었다. 처음부터 각1마리씩인11종은 유지하고, 기본 편성·역할·현재 체력·출발을 먼저 보여주며 나머지 동료 선택을 펼치는 방식이 적절하다. 큰 동물의 지상 생활과 데크 성장 후 승선도 유지한다.
3. **보상 수령 직후 ‘무엇을 지을 수 있는지’를 더 선명하게 잇는다.** 생산·원정 보상이 일반 물자 증가로 끝나지 않고 다음 시설·데크의 실제 변화로 이어져야 한다. 준비된 안내의 한 번 실행은 이번에 고쳤지만, 의미 있는 건설 선택과 시각적 성장 장면은 계속 보완해야 한다.
4. **다음 맵으로 가는 이유를 만든다.** 현재7개 채집 지역과3개 전투 구역은 있지만, 특정 도로를 확보하고 트럭으로 새 지도에 도착하는 진행 고리는 아직 없다. 여행 준비→외부 모험→새 생활 재료/설계도→트럭 개선으로 연결하는 것이 원래 기획 의도에 가깝다. 신규 콘텐츠 제안이며 이번에 구현됐다는 뜻은 아니다.
5. **공간과 생활의 조화를 계속 다듬는다.** 디스토피아는 배경의 위험이고 트럭은 따뜻한 집이다. 화면을 어둡게 하거나 큰 UI를 늘리는 방식보다 바닥·길·그림자·크기·동물의 생활 동작을 일관되게 만든다. 예전 혼합 탐색 보상이나 동물 해금 설명처럼 현재 규칙과 어긋나는 안내도 정리해야 한다.

## 확인 범위와 남은 검사

수정에 집중한 기존 카메라 행동 검사는 **5/5 통과**했다. 실제 Scene에서 가용 영역 안의 트럭/착지점, 생활뷰와 전체뷰의 크기 차이, 수동 pan/zoom 유지, 전체보기와 기본 복귀를 확인한다. 모바일 에뮬레이션 플레이 중 수집한 페이지 오류 목록은 비어 있었다. Android 실기에서 설치·플레이하거나 iPhone 실기로 조작한 결과는 아니다.

별도로 선택 실행한 기존 경로·동물 통로 검사에서는 실패6개를 확인했다. 외부 계단을 옛 `climb`으로 기대하는2개와 고정 동물 통로/착지점/큰 발 통과 공간을 기대하는4개다. 해당 검사들은 이번에 바뀐 Scene 파일을 가져오지 않으며 대상 물리·통로 소스도 이번 범위에서 수정하지 않았다. 기존 불일치로 분리 기록했으며, 이 작업에서 고쳤거나 전체 검사가 통과했다고 보고하지 않는다. 전체 지형·동물 이동의 완전한 검증은 남아 있다.

로컬 관찰 근거는 `artifacts/player-audit-v042/`와 `artifacts/player-audit-v043/`에 보관했다. 특히 `two-plot-live-play.json`, `production-one-tap.json`, `collection-one-tap.json`, `world-and-home.json`, `manual-road-camera.json`이 수정 후 행동의 근거다. 초기 코드 수치와 출처별 접근 범위는 `growth-loop-code.md`, `references-kingdom-clash.md`, `references-aqua-sky.md`에 구분해 기록했다. 이 임시 자료가 제품에 포함되거나 배포됐다는 뜻은 아니다.
