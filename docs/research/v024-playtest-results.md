# v0.24 — 배치 정렬·방향 변경·선택 층 작업

트럭 데크의 서로 다른 두 투영 축에 집과 시설의 바닥 그림을 맞췄습니다. 벽의 수직선을 유지하며, 보정한 지붕은 기존 그림 영역에 들어오도록 조절했습니다. 이 때문에 건물 그림이 직전 버전보다 약간 좁습니다. 밭은 데크 좌표로 나무 테두리와 흙을 그리며, 작물 그림은 똑바로 세워 둡니다.

집의 선택 창, 시설의 하단 작업 창, 선택한 밭의 농사 도구에 방향 버튼을 추가했습니다. 집과 시설은 두 방향을 전환하고 밭은 고랑 방향을 바꿉니다. 무료로 바꾸며 건물 자리·충돌 범위·자원·작물·물 주기·생산 시각을 변경하지 않습니다. 실제 대상 ID를 검증하고 저장합니다. 기존 저장에는 원래 방향을 적용하며 잘못된 새 방향 정보는 저장 검증에서 거절합니다.

층간 간격을 176에서 264로 늘렸습니다. 선택한 층의 데크·난간·계단 입구만 그리며 다른 층의 바닥과 기둥, 1층 차체가 상층 작업을 가리지 않습니다. 실제 이동 세계에는 세 층과 연결 계단을 유지합니다. 동물 양보 경로는 모든 안전한 후보의 실제 이동시간을 비교합니다. 기존 2배 속도, 몸 크기와 작업 정체 제한은 유지합니다.

빌드 전 개발 서버 검수에서 실제 Chromium 터치와 자연 프레임으로 390×844와 844×390 화면을 확인했습니다. 방향 변경 18회, 층 보기 7회, 실제 1층→3층 계단 이동, 기존 저장의 전체 진행 정보와 방향을 저장 후 재실행하는 동작을 검증했습니다. 방향별 실제 그림 변환의 두 바닥 축, 밭의 테두리와 고랑도 데크 투영과 비교했습니다. 화면 사진을 직접 확인했습니다. 이 개발 서버 결과는 최종 불변 빌드 검증과 별개입니다.

검수는 명시적으로 준비한 기존 유료 3층 저장을 사용합니다. 재료와 후반 진행을 플레이로 획득했다고 주장하지 않습니다. Chromium의 모바일 화면·터치 검수이며 실물 Android 설치나 iPhone/Safari 실행 검수가 아닙니다. Android 엔진과 원래 서명 키를 유지하고 콘텐츠 버전24, 네이티브 호환8–24로 배포합니다.

전체 단위 검사 301개가 통과했습니다. 기존 Android 네이티브 소스·서명을 유지하며 JVM19개 결과는 재사용했고, 이번 콘텐츠의 서명과 압축 해제·파일 해시는 새로 검증했습니다. APK는 61,106,167바이트, SHA-256 `729e7c3b5a37d8a608606d340dc926d9b4d497e4a89b4d02161e9824195670a0`입니다. 콘텐츠 ZIP은 52,738,033바이트, SHA-256 `b37386bb5bec2ff4f333f9ecb39dc63b7aaf85db77da0e268658dc0c6c044d25`입니다.

최종 빌드의 소스96개·테스트49개를 고정하고 동일한 검사 파일로 불변 HTTP 사본57개를 검증했습니다. 최종 터치 검수는 1,637개 검사를 통과했고 방향 변경18회·층 보기7회·두 계단을 이용하는 실제 상층 이동을 완료했습니다. 화면 사진26장을 보관했으며 콘솔 오류나 실패한 그림·글꼴 요청은 없었습니다. 개발 서버 진단과 이전 버전의 검사 수는 이 최종 결과에 합산하지 않습니다.
