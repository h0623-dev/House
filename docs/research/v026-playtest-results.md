# v0.26 — 트럭 상점과 의상

사용자가 표시한 데크 장식 상자와 도로의 장식 상자를 제거했습니다. 그림뿐 아니라 도로 상자의 물리 장애물도 제거해 빈자리를 지날 수 있습니다. 남은 나무와 건물의 충돌은 유지합니다.

하단 상점에서 씨앗·애완동물·의상·판매를 이용합니다. 식량·목재·고철을 판매해 코인을 얻으며, 씨앗은 여섯 종류를 1·5·10개씩 구매합니다. 구매한 씨앗은 기존 인벤토리에서 선택해 연속 심기에 사용합니다. 기존 동료는 보유 상태를 유지하고, 아직 만나지 않은 토끼·여우·멧돼지·부엉이를 먼저 만날 수 있습니다. 구매한 동물은 동료 편성에서 선택해 전투에 사용합니다.

의상 세 종류는 남녀 공용으로 소유하고 착용 상태는 남녀별로 저장합니다. 모자·앞치마·스카프·배낭은 기존 캐릭터의 자세에 맞춰 실제 화면과 초상화에 그립니다. 캐릭터와 환경의 기존 PNG 17개는 변경하지 않았습니다. 상점 거래는 확인 화면에서 수량·가격·거래 후 코인을 확인하고 확정합니다. 코인이 부족하거나 구매를 취소하면 저장이 바뀌지 않습니다. 기존 저장을 열어도 코인이나 구매 기록을 지급하지 않습니다.

레알팜 참고 범위와 우리 가격·거래 설계는 [조사 문서](v026-realfarm-shop-design.md)에 기록했습니다. 공식 소개와 게시된 화면을 확인했으며 직접 설치 플레이·동영상·비공개 개발 문서를 확인했다고 주장하지 않습니다.

TypeScript 검사가 통과했고, 실제 빌드 입력을 기록한 전체 단위 검사319개가 통과했습니다. 수확→판매→구매, 여섯 종류 씨앗의 재고와 총 씨앗 수, 남녀별 의상, 기존 동물 보유와 신규 동물 편성·전투·재실행, 중복 구매·자원 부족·손상된 저장 거절을 검사했습니다. 상자가 사라진 자리를 주인공·동물의 전체 몸체로 통과하고 남은 나무는 막히는 검사도 포함합니다.

모바일 검수는 Chromium 터치 화면 에뮬레이션입니다. 실물 Android 설치·자동 패치 또는 iPhone/Safari 실행 검수는 아닙니다. 새 저장과 기존에 검증한 유료3층 저장을 실제 저장 검증에 통과시켰으며, 식량1000은 검수용 지급이라고 명시합니다. 코인은 주입하지 않고 화면에서 식량을 판매해 얻습니다. 과거3층 진행이나 검수용 식량을 이번 플레이에서 획득했다고 주장하지 않습니다.

빌드 전 실제 개발 서버에서344×740·360×800·390×844·844×390 검수1120개가 통과했습니다. 화면에서 실행한 거래26건, 코인0·기존 동물·취소 검증4건, 의상 실제 그리기와 초상화6회, 데크1에서 구매한 토끼와 강아지·고양이의 실제 전투 참여를 확인했습니다. 여섯 종류 씨앗 목록을 검사하고 각 화면에서 옥수수5개를 구매했습니다. 실제 구매한 옥수수를 기존 농사 흐름으로 심었습니다. 여섯 품종을 브라우저에서 각각 구매했다고 주장하지 않습니다.

검수 중 일반 모션의 모달 등장 애니메이션이 끝나기 전에 터치 크기를 재던 준비와 같은 이름으로 저장하던 화면 사진 경로를 수정했습니다. 최종 빌드 전에 유한한 애니메이션이 자연스럽게 끝나기를 기다리고 사진마다 다른 이름을 쓰도록 고정했습니다. 실제44px 검증·자연 타이머·터치 입력을 유지했습니다. 안정된 개발 검수의 사진20장은 서로 다른 파일이며 각 파일의 해시를 확인했습니다. 제품과 테스트 입력은 그 뒤 고정했습니다.

원래 Android·콘텐츠 서명으로 APK61,119,345바이트와 콘텐츠 ZIP52,749,042바이트를 만들었습니다. APK의 SHA-256은 `f6b655c08ae61906b6683cd445a9a3ab0a0321ff1817cd90b8d00546bd6b9572`, 콘텐츠 ZIP은 `2bfacbd09e0ff12c1e629736981bafc69dde6a210086d47afe34f71ff73c1bef`입니다. 콘텐츠26은 기존 네이티브 엔진8–26과 호환됩니다. 네이티브 소스9개를 유지해 기존 JVM19개 결과는 재사용했고, 이번 콘텐츠의 서명·압축 해제·전체 파일 해시는 새로 검증했습니다.

고정한 제품 소스101개·테스트52개와 불변 배포 사본57개에서 같은 검수 파일을 다시 실행했습니다. 최종 검수1236개가 통과했고, 모든57개 실제 HTTP 응답의 전체 바이트·해시가 고정 파일과 일치했습니다. 실제 거래26건, 부족한 코인·취소·기존 동물의 검증4건, 의상 그리기와 초상화6회, 신규 토끼의 실제3마리 편성·전투 참여,4개 화면에서 기존 저장·재실행을 확인했습니다. 사진20장의 이름과 해시를 각각 확인했고 콘솔 오류·실패한 자산 요청은 없었습니다. 제품과 테스트는 빌드 후 수정하지 않았으며 과거 검수나 개발 검수 수를 이 최종 결과에 합산하지 않습니다.
