# v0.31 지상 숲과 개별 채집

트럭에 붙어 움직이던 채집 장소를 고정된 지상 구역으로 바꿨습니다. 숲길 양쪽에 나무 16그루, 고철·씨앗·샘물 구역에 각각 4개를 배치합니다. 트럭을 최대 8단계로 확장해도 자원 위치는 바뀌지 않으며, 실제 나무 그림과 접근 위치도 차체 바깥에 놓입니다.

## 게임에서 사용하는 방법

채집 장소 → 원하는 구역 → 크게 보기로 숲길을 둘러봅니다. 원하는 나무나 채집물을 직접 누르거나 목록에서 선택하고 채집합니다. 개별 상세의 ‘이 채집물 크게 보기’는 해당 대상을 중심에 보여 줍니다. 짧은 가로 화면에서는 숲 입구부터 보여 주고 지도 드래그로 안쪽을 살핍니다. 평소 전체 보기와 지상 걷기는 자동 확대되지 않습니다.

주인공은 장애물을 피해 실제로 이동하고 작업을 마친 뒤 그곳에 머뭅니다. 트럭으로 돌아가기 버튼은 사다리를 사용합니다. 채집 보상·기력 비용·경험치·퀘스트·채집 횟수는 완료한 대상 하나에만 함께 반영하며, 중복 터치나 미완료 작업에는 보상을 주지 않습니다.

모든 지상 채집물은 완료 시각부터 실제 180초 뒤 각각 재생됩니다. 게임의 2배 속도, 일시정지, 재실행과 별개입니다. 나무는 그루터기, 다른 채집물은 비어 있는 모양으로 표시합니다. 상세 화면과 목록에는 남은 초와 구역별 준비된 개수를 표시합니다. 씨앗은 노드와 채집 횟수에 따라 여섯 품종을 순환하며 총 씨앗 수와 품종별 보관량이 일치합니다.

이전 저장은 자원을 지급하지 않고 이어집니다. 예전 네 장소의 방문 횟수와 실제 남은 대기는 각 대표 대상에만 옮기고 이전 기록도 보존합니다. 모든 새 자원은 별도의 대상입니다. 원래 생산·농사·상점·퀘스트 비용과 보상, 실제 1분당 기력 3 회복은 유지합니다.

## 검증

TypeScript와 전체 단위 테스트 446개가 통과했습니다. 8개 트럭 확장 단계, 모든 자원 접근점, 주인공 반경 7과 최대 동물 반경 30.8에서 실제 왕복 경로와 이동 중 원 전체의 충돌을 검사했습니다. 숲길 폭은 132이며, 저속 프레임·움직이지 않는 동물·미완료 작업 종료·기본 보기와 수동 시점 유지도 확인합니다.

개발 버전에서는 Chromium 모바일 에뮬레이션 390×844, 344×740, 844×390에서 31,426개 검증과 7회 실제 채집을 완료했습니다. 첫 나무는 작업 완료 후 180,629ms에 준비됐고, 둘째 나무는 당시 172,896ms로 8초가 남았습니다. 두 나무의 실제 재생, 재채집, 저장 재진입과 같은 마을의 샘물 채집 중 독립 타이머 유지를 확인했습니다. 이전에 재료를 사용해 확장한 저장과 정상 새 게임을 사용하고 실행 중 시계·기력·보유 자원·경로를 주입하지 않았습니다.

불변 배포 빌드의 같은 세 화면에서도 **31,553개 검증·7회 실제 채집·4회 재실행·3회 트럭 내부 터치 거부**를 통과했습니다. 첫 나무는 180,618ms, 둘째는 173,685ms였고 둘째가 7초 대기 중인 구간을 실제로 관찰했습니다. 최종 빌드에서 349개 물리 샘플·2,064개 자연 RAF·20,010개 도로 장애물 이동 선분을 다시 계산했습니다. HTTP 사본 57개와 스크린샷 44개도 바이트·해시가 일치합니다. 최종 실행 중 제품과 테스트 파일을 수정하지 않았습니다.

## 배포 파일

제품 입력 115개, 테스트 입력 70개를 고정한 v031-r1을 한 번 빌드했습니다. APK·서명 콘텐츠·정적 웹·단일 HTML의 실제 바이트와 원래 APK 서명·콘텐츠 공개 키를 확인했습니다. 불변 QA 사본 57개를 HTTP로 읽어 파일 해시와 worker JavaScript MIME도 확인했습니다.

APK는 Android 코드 31이고, 서명된 콘텐츠는 기존 네이티브 엔진 8–31에서 적용할 수 있습니다. 기존 네이티브 코드와 테스트 9개 파일이 같아 과거 19개 JVM 단위 결과를 재사용했으며, 이번 ZIP의 서명·각 파일 해시는 호스트 JVM에서 새로 검증했습니다. 실제 Android 기기에 설치하거나 OTA를 실행한 검사, 실제 iPhone 설치 검사는 이번 클라우드 작업에서 수행하지 않았습니다.
