# v0.21 — 안전한 집 배치와 2·3층 트럭 마을

집의 바닥 전체를 데크 난간 안쪽으로 옮겼습니다. 우리집·완성된 시설은 무료 재배치할 수 있으며 미리 보기 후 확정합니다. 이동 중인 캐릭터나 동물과 겹치는 배치는 자원을 쓰기 전에 거절합니다. 시설 ID·레벨·생산 시작과 완료 시각은 위치가 바뀌어도 유지합니다. 상층 시설을 먼저 채운 뒤 1층으로 옮기고 빈 상층에 다시 지어도 남은 ID를 안전하게 사용해 최대48개를 저장합니다.

데크 Lv.4에서 목재100·고철50으로 2층, Lv.7에서 목재160·고철80으로 3층을 순서대로 증축합니다. 층 버튼은 보이는 지도만 선택하고 캐릭터와 동물은 실제 연결 계단으로 이동합니다. 층마다 현재 데크 단계에 따라 시설 자리가 열리며 최대16자리, 세 층을 합쳐 최대48자리입니다. 밭은 1층에서 계속 가꿉니다. 상층에서 농사 메뉴나 도구를 선택하면 1층 밭 화면으로 안내하며, 캐릭터의 실제 위치는 바꾸지 않습니다. 공통 속도는 기존 2배입니다.

캐릭터의 발과 동물의 몸·착지 발 크기를 기준으로 건물·밭·난간과 서로의 몸을 피합니다. 잠시 막히면 현재 발 위치에서 같은 목적지로 우회하며, 길을 막은 건강한 동물은 가까운 안전한 자리로 비켜줍니다. 짧게 비킬 자리가 없으면 더 먼 빈자리까지 안전한 경로를 찾습니다. 계단은 한 인물씩 통과하며, 입구에서 막힌 동물은 계단을 사용하는 동물이 내려오기 전에 먼저 비켜줍니다. 이미 지은 층간 계단은 데크를 더 넓혀도 같은 자리에 유지합니다. 하늘의 새8마리는 서로 다른 방향·깊이·속도로 날갯짓하고 활공합니다. 밤에는 밝기를 낮추고 동작 줄이기 설정을 따릅니다.

새는 배경에 그려지므로 트럭·나무·조작창에 가려질 수 있습니다. 360×740의 짧은 세로 화면과 844×390의 가로 화면에서는 기본 시점을 기록한 뒤 실제 지도 축소·이동 버튼과 드래그로 하늘을 드러내 검수합니다. 가로 화면에서는 마을 메뉴 → 벌목장 → 벌목장 둘러보기로 넓은 도로 시점을 연 뒤 지도를 움직입니다. 390×844는 기본 시점에서 검수합니다. 모든 시점에서 다섯 마리가 동시에 보인다는 뜻은 아닙니다.

집을 누르거나 건설 목록의 ‘우리집’에서 재배치를 시작합니다. 완성된 시설은 선택 창의 ‘재배치’를 누릅니다. 새 자리를 선택하고 미리 보기를 확인한 뒤 확정하며, 층 버튼으로 다른 층의 자리를 선택할 수도 있습니다. 지도 위 ‘증축’에서 다음 층의 해금 조건과 비용을 확인합니다. 층 버튼만 누르면 자원을 쓰거나 인물의 위치를 바꾸지 않습니다.

## 저장 형식과 구버전 범위

추가 층·집 위치·기존 시설의 위치 덮어쓰기·새 시설은 최상위 `truckLayout`에 저장합니다. 기존 `settlement`와 시설 성장 이력에는 구버전에서 유효한 ID·자리만 남깁니다. 원본 v0.8·v0.20 코드를 실제로 읽기→휴식→저장→새 코드로 불러오는 30개 상태 검사를 수행했습니다. 구버전에서 유효한 기본 밭·데크 단계·시설 사례의 추가 정보가 저장 왕복을 통과했습니다.

이는 모든 최신 저장을 v0.8 게임 코드로 읽을 수 있다는 뜻은 아닙니다. v0.8 자체의 데크 최대6단계, 기본 밭 개수, 시설 최대3레벨과 생산 시간 검증 한계는 그대로입니다. 데크7·8단계, 구매한 추가 밭, 시설4·5레벨, 빨라진 진행 중 생산은 구버전 복구 범위를 넘어설 수 있습니다. 최신 콘텐츠 실행 호환성과 옛 콘텐츠로의 저장 복구는 별도로 검증합니다.

## 최종 빌드 검수

최종 검수는 다시 빌드하지 않은 동일한 `v021-r5` 배포 파일로 수행했습니다. 제품 소스87개와 웹·네이티브 테스트용 파일57개의 SHA-256을 실행 전후 확인했습니다. APK는 기존 서명을 유지하고, 콘텐츠 ZIP은 기존 공개 키로 검증했습니다.

브라우저 확인 개수에는 이동 중 자연 프레임마다 반복하는 몸·발·경로 검사가 포함됩니다. 서로 다른 기능이나 실물 기기의 개수가 아닙니다. 360×740·390×844·844×390에서 실제 터치·드래그와 자연 RAF를 사용했으며, 최종 844×390의 3층→1층 이동은 약8.93초에 완료했습니다. 새 검수는 배경을 가리는 실제 그림과 조작창을 보수적으로 제외한 전체 실루엣 관찰이며 픽셀의 알파값을 직접 검사한 결과는 아닙니다.

자동 패치는 이동·층간 계단·집 배치·층 증축 확인·시설 배치의 다섯 상태에서 적용을 보류하고, 조작을 정상적으로 마친 뒤 한 번 재실행하는 것을 확인했습니다. 이전 콘텐츠에서 실제 휴식·채집을 하고 돌아와도 3층과 전체 저장을 유지했습니다. 새 콘텐츠의 캐시30개 파일을 바이트 단위로 확인하고 오프라인 재실행도 검증했습니다.

상층 검사는 이전 버전의 실제 플레이 저장에 시험용 데크 단계와 자원을 초기 설정한 뒤 수행했습니다. 이 초기 상태는 자연 성장 보상과 구분해 기록하며, 증축 비용 지출과 이후 이동·작업·저장·자동 패치는 실제 게임 조작으로 검증했습니다. 이전 버전으로의 전환 검사는 localhost에서만 수행했습니다.

이전 부분 진단·실패·수정 전 결과는 별도로 보존하며 위 최종 수에 합산하지 않았습니다. 자유 이동 검사에서 빈 건설 자리 선택을 바로잡았고, 자동 패치 검사에서는 이미 적용 중인 화면에 추가로 메뉴를 누르려던 검사 조작을 제거했습니다. 제품·최종 배포 파일은 바꾸지 않고 전체 검사를 다시 수행했습니다.

검수 환경은 Chromium 모바일 화면과 실제 Service Worker입니다. 실물 Android 설치·자동 패치와 iPhone/Safari 설치는 별도로 확인해야 합니다. 스크린샷만으로 움직임·충돌이 증명되지는 않으며, 세 층의 외관이 한 화면에 모두 보이는 경우까지 검수한 것은 아닙니다. 공개 주소의 최신 응답은 게시 후 배포 검증으로 확인합니다.
