# v0.22 — 마을 건설과 성장 중심 개편

사용자가 ‘각수’로 부르는 쿠키런: 킹덤·아쿠아랜드: 크레이지 서바이벌·룰더스카이·클래시 오브 클랜의 공통 흐름 중 마을 건설과 성장을 중심으로 조정했습니다. 미래 대한민국의 좀비 도로, 큰 트럭 위 생활, 남녀 생존자와 동물 동료를 이어 갑니다.

## 확인한 차이와 구현

기존 [공식 소개·공략·공개 개발자료 비교](../V0.17-SYSTEMS-COMPARISON.md)와 보관한 홍보 이미지13장을 다시 확인했습니다. 새로 네 게임의 영상을 시청하거나 내부 개발 문서를 확보한 것은 아닙니다. 참고 게임 자산과 코드는 제품에 넣지 않았습니다. v0.21의 실제 모바일 화면을 세로·가로에서 눌러 기록하고 새 화면과 비교했습니다.

| 확인한 차이 | 이번 변화 |
| --- | --- |
| 집·밭보다 도로 배경과 상시 관리 버튼의 비중이 큼 | 실제 생활 공간 경계에 맞춘 기본 카메라, 별도 전체 보기, 짧은 목표와 작은 층 선택 |
| 생산품 수령 후 다시 시작하는 조작이 반복됨 | 받기와 명시적 ‘받고 다시 생산’을 구별. 한 묶음 수령 후 다음 원가를 한 번 사용 |
| 목표가 막히면 필요한 준비 행동을 찾기 어려움 | 현재 저장을 읽어 물 주기·심기·수령·생산·재료 공급원을 먼저 안내 |
| 납품과 건설·개선이 별도 메뉴로 느껴짐 | 납품 보상에서 실제 다음 투자와 부족한 재료로 연결 |
| 건물 Lv.1–3이 동일한 외형 | Lv.2 보급함, Lv.3 설비·천막, Lv.4 화단, Lv.5 완성 문장. 지도와 UI가 같은 추가 형태를 사용 |

새 운영판은 시설이 있으면 생산량·재료·남은 초·받기/다시 생산을 먼저 보여 주고, 목표와 다음 투자는 아래에서 펼칩니다. 작은 활동 버튼은 짧은 행동명과 그림을 사용하며 주요 버튼은44px 이상의 실제 터치 영역을 유지합니다. 건설·농사·시설 선택 중에는 활동 도크를 접어 지도와 작업 자리를 확보합니다.

## 성장과 저장 보존

기존32개 목표의 ID·순서·기준과 이미 받은 보상을 그대로 유지합니다. 새 안내는 저장에서 계산한 정보입니다. 층 증축·밭 확장·다음 시설 투자는 실제 비용·현재 층수·빈 자리를 읽습니다. 부족한 자원의 공급원을 먼저 찾으므로 목재가 부족한 의뢰에서 정수소를 먼저 열던 안내도 수정했습니다.

‘받고 다시 생산’은 이용자가 누른 이후 한 번만 수행합니다. 현재 묶음이 완성되기 전에는 수령하지 않습니다. 다음 재료가 부족하면 받은 생산품은 유지하고 다음 생산은 시작하지 않습니다. 기존 생산의 시작·완료 시각을 다시 쓰거나 과거 생산품을 소급 지급하지 않습니다.

시설 ID·레벨·배치·3층, 씨앗 재고와 선호 씨앗, 동료 HP·XP, 기존 저장과 공통2배 속도를 보존합니다. 배치·물리 충돌·펫 통행·계단의 동작은 기존 규칙을 이어 갑니다. 네이티브8–22는 기존 공개 키로 서명된 콘텐츠를 검증하고, 아이폰·웹은 기존 Service Worker 패치 흐름을 이용합니다. APK는 기존 서명의 새 설치용 버전 코드22입니다.

## 검수 범위

개발 화면에서 실제 터치로 채집→첫 시설 건설→생산 수령·다시 생산→이웃 납품을 완료하고 재료·지급량·통계를 확인했습니다. 수확·씨앗 선택·작은 화면 조작·층 이동·저장과 자동 패치는 같은 최종 배포 빌드에서 별도로 검수합니다. 개발 중 기록과 이전 버전 결과를 최종 통과 수에 합산하지 않습니다.

최종 r3의 완료 결과는 단위280, 기본 화면577, 실제 터치·작업857(29개 작업), 자유 이동13,959(23개 이동·13개 제스처·3개 작업), 마을 운영229,678, 자동 패치4,105입니다. 최종 브라우저 검사5개의 합계는249,176이며 단위 검사와 재사용한 네이티브 검사는 별도로 셉니다. 마을 검수는 신규3화면·기존3층 저장2화면·실제 계단6회·스크린샷29장을 포함합니다. 공개 배포 검증은 업로드 이후 실제 HTTPS 파일·체크섬·콘텐츠 서명·Service Worker 응답·이전 APK 접근을 확인하는 별도 절차입니다.

자동 패치는 실제 v0.21에서 v0.22로 한 번 전환되며 전체 저장을 유지했습니다. 기존 생산품의 수령과 명시적 재생산, 오프라인 실행도 확인했습니다. 이동·계단·집 재배치·층 증축·시설 재배치·마을 운영의6개 조건에서는 적용을 보류하고 정상 종료한 후 전환했습니다. 패치 검수 도구의 터치 중심점과 카메라 준비를 수정한 과정 및 실제 실패 원본은 따로 보존했습니다. 제품92개·동결된 테스트44개·검수 HTTP 파일57개는 최종 빌드 이후 그대로이며, 도구 변경 승인과 각 실제 실행의 입력 SHA를 연결해 기록했습니다.

첫 검수 사본 r1에서는 자유 이동 검사가 가까워진 기본 시점에서 도로 지점을 찾지 못했고, 패치 검사는 기존 v0.21 건설 확인 때 강아지가 자리를 점유해 거절됐습니다. 실패 원본과 실제 화면을 보존했습니다. 검수 준비는 실제 전체 보기 조작과 제한 시간 내 빈 건설 자리 선택으로 보완하며, 이동·충돌·작업 시간과 지급량의 검증 조건은 유지합니다. r2의 350ms 지연 프레임 검사는 벌목 복귀가 강아지에 막혀 원래16초 제한 뒤 취소되는 실제 제품 문제를 발견했습니다. 실패854개 검사·원본 프레임·화면을 보존하고, 주인공과 반려동물을 같은 실제 경과 시간의100ms 이하 물리 단계로 처리하도록 수정했습니다. 실제 Scene 소스를 사용하는4개 회귀 검사와 전체280개 단위 검사가 통과했고, 최종 r3의350ms 지연 프레임 벌목도7.426초에 완료됐습니다. 이 단위 회귀 검사의 DOM·이미지·그리기는 대체 환경을 사용하며, 실제 브라우저의350ms 검사는 별도로 실행했습니다. 보상·작업 속도·충돌 반경·계단 점유·제한 시간을 완화하지 않습니다. 브라우저 검수는 Chromium 모바일 화면과 실제 Service Worker이며, 실물 Android 설치·자동 패치 및 iPhone/Safari 설치와 구별합니다. 상층 검수에 쓰는 이전 버전의 유료 증축 저장과 시험용 초기 상태는 자연 성장 보상과 구분해 기록합니다.

실제 r1 스크린샷 29장을 따로 확인했습니다. 짧은 가로 화면에서는 상하단 UI 때문에 마을이 작게 보이고, 짧은 알림이 지도나 의뢰 보조 문구를 잠시 가립니다. 3층의 첫 빈 건설 표식과 생산 말풍선은 일부 겹칩니다. 선택한 시설을 확대하면 다른 집과 인물 일부가 잘릴 수 있습니다. 이 기록에서 직접 확인한 단계별 건물 사진은 Lv.1과 Lv.2입니다.

최종 r3에서는 같은 제품92개·테스트44개·HTTP57개 파일의 SHA를 검수마다 확인했습니다. 기존 네이티브9개 소스는 바뀌지 않아 JVM19개 검사는 기존 결과를 재사용했으며, 새 콘텐츠 서명은 원래 공개 키로 새로 검증했습니다. 실제 r3 대표 스크린샷5장도 별도 검수했습니다.
