# v0.28 — 주인공 시점과 동물 통로

지상 이동을 넓어진 도로 전체에 맞춰 축소하던 카메라를 주인공의 실제 위치를 따라가는 시점으로 바꿨습니다. 데크·사다리·지상·채집과 복귀에서 같은 기본 배율을 사용하며, 사용자가 선택한 확대율도 유지합니다. ‘주인공’ 버튼은 화면을 옮겨 둘러본 뒤 현재 캐릭터를 다시 따라봅니다. 건설 배치와 마을 전체 보기는 별도의 명시적 화면입니다.

동물은 사람의 지상 사다리 대신 전용 경사로를 걸어서 오갑니다. ‘동물 문’ 또는 지도 위 문에서 조작을 선택하면 주인공이 문까지 걸어가 손으로 조작합니다. 닫기 시작부터 새 통행을 제한하고, 이미 건너는 동물은 같은 경로를 끝까지 지나간 뒤 문을 닫습니다. 닫힌 동안 동물은 현재 있는 쪽에서 산책합니다. 문 상태만 저장하며 재료·기력·경험치를 바꾸지 않습니다. 이전 저장에 문 상태가 없으면 닫힌 상태로 시작합니다.

TypeScript 형 검사와 전체 단위 검사 383개가 통과했습니다. `tests/pet-passage-traffic.test.ts`는 실제로 막혔던 동물 위치와 이동 경로를 재현해, 출구를 비켜 주고 가까운 곳에서 차례를 기다리며 원래 속도·충돌 반경으로 통과하는지 확인합니다.

소스 110개와 검수 파일 61개를 고정한 `v028-r1` 빌드에서 같은 모바일 검수를 다시 실행했습니다. 344×740, 360×800, 390×844, 844×390 화면의 검수가 모두 통과했고, 실제 단언 133,617개·문 조작 14회·카메라 기록 65개·동물 이동 기록 18개를 남겼습니다. 7,173개 관찰 프레임에서 공유 공간의 몸체 간격 11,165개를 검사했습니다. 걷는 중 목적지 변경과 카메라 복귀는 실제 터치 이벤트의 처리 전후에 이동 경로를 관찰했습니다. 게임 시간·애니메이션·이동 속도·경로를 검사 코드로 대체하지 않았습니다.

390px 화면에서는 지상 샘물 채집과 복귀·보상 적용, 통행 중 문 닫기와 기존 동물의 안전한 통과를 확인했습니다. 가로 화면에서는 이전에 검증한 3층 저장을 변경 없이 불러와, 3층 보기에서 현재 주인공이 있는 1층으로 실제 위치·확대율·경제 상태를 유지하며 복귀하는지 확인했습니다. 이 저장은 이번 검수에서 새로 성장시킨 결과로 계산하지 않았습니다.

최종 고정 파일 57개의 HTTP 바이트 일치와 스크린샷 40개를 기록했습니다. APK는 원래 서명을 유지한 Android 코드 28이고, 새 콘텐츠는 네이티브 8–28과 호환됩니다. 정확한 콘텐츠 ZIP의 인증을 새로 실행했으며, 네이티브 소스 9개가 이전 버전과 동일한 것을 확인했습니다. 이전 호스트 JVM 검사 19개는 재사용 결과로 구분합니다.

브라우저 검수는 Chromium 모바일 에뮬레이션입니다. 실제 Android·iPhone 기기에 설치하거나 Android 앱에서 OTA를 실행한 결과로 표시하지 않습니다. 최종 기록은 `artifacts/gameplay-player-pet-v0.28.0-verification.json`과 `artifacts/release-v0.28.0-preflight.json`이며, 공개 주소의 파일·서명·서비스 워커 MIME·과거 APK 접근 검증은 배포 후 `artifacts/release-v0.28.0-final.json`에 별도로 집계합니다.
