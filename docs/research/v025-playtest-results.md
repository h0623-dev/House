# v0.25 — 트럭 생활과 생산품 표시

트럭을 생활 공간으로 삼고 별도 주인공 집의 그림·클릭 영역·재배치 메뉴·물리 장애물을 제거했습니다. 로딩 화면에서도 별도 집 그림을 제거했습니다. 휴식과 공간 확장은 트럭 생활 메뉴로 연결하며, 시설·밭의 방향 변경과 선택한 층만 보는 기능은 유지합니다.

과거 집 위치와 방향은 저장 호환용으로 남깁니다. 기존 저장을 열거나 생산·개선할 때 이 기록을 바꾸지 않습니다. 새 시설 건설·이동이 과거 집 위치와 겹치는 경우에만 호환용 위치를 같은 층의 안전한 옛 자리로 바꿉니다. 실제 화면에 집이 생기거나 비용이 추가되지 않으며, 구버전의 위치 검증도 만족합니다. 집이 없어진 영역은 실제 보행과 건설에 사용할 수 있습니다.

시설 위의 생산 대기·진행·완료 표시에 원래 자원 그림을 사용합니다. 생산 중에는 남은 초와 진행률을, 완료 상태에는 받을 수량을 표시합니다. 물품을 누르면 생산을 시작하거나 한 묶음을 수령하고, 진행 중인 물품을 누르면 해당 시설을 엽니다. 시설 작업 창과 마을 활동의 생산품 버튼도 실제 생산하는 자원 그림으로 통일했습니다.

화면 크기와 줌에 관계없이 생산품 터치 영역은 최소44px입니다. 좁은 화면에서는 겹치는 표시에 간격을 두고 해당 시설로 연결선을 그립니다. 확대하거나 화면을 이동하면 자연스러운 건물 위 위치를 유지합니다. 16개 시설과 640×112의 좁은 화면을 포함해 지붕·개별 버튼 전체 영역과 분리된 배치를 검사했습니다.

전체 단위 검사305개가 통과했습니다. 집 제거로 바뀐 기본 순찰 위치 때문에 과거 검사에서 동물을 서로 겹치게 배치하던 준비를 실제 시작 좌표와 전체 몸체 검증으로 수정했습니다. 제품의 몸 크기·2배 속도·충돌 검사·16초 정체 취소는 변경하지 않았습니다.

모바일 검수는 기존 유료3층 저장과 직전 버전에서 저장한 방향·생산 기록을 실제 저장 검증에 통과시켜 사용합니다. 후반 진행을 이 검사에서 플레이로 획득했다고 주장하지 않습니다. Chromium의 실제 터치 입력과 자연 프레임·타이머를 사용하는 모바일 화면 검수이며, 실물 Android 설치나 iPhone/Safari 실행 검수는 아닙니다.

빌드 전 실제 개발 화면에서 360×800·390×844·844×390의 전체 검수988개가 통과했습니다. 층별 보기9회, 실제 물품 터치12회, 정확한 한 묶음 생산·수령9회, 이전 집 영역까지의 자연스러운 계단 이동과 저장·재실행을 확인했습니다. 마을 활동 버튼의 실제 물품 SVG도 검사했습니다. 화면 사진22장을 보관하고 직접 확인했습니다.

개발 중 검수의 화면 재시작과 숨겨진 시간 버튼 가정을 수정한 기록은 별도로 보관했습니다. 44px 검사에는 반올림된 지도 배율을 곱하지 않고 실제 그림 사각형의 정확한 화면 좌표를 사용합니다. 제품의 터치 크기를 임의로 보고하거나 검사를 약하게 만들지 않았으며, 이 준비는 최종 빌드 전에 완료했습니다.

APK와 자동 패치 파일은 원래 Android·콘텐츠 서명으로 만들었습니다. Android 소스를 유지해 JVM19개 결과는 재사용하고 이번 콘텐츠 서명·추출·파일 해시는 새로 검증했습니다. APK61,105,819바이트의 SHA-256은 `a21f72a1e6bf111eac4e1a281ff2bdd7a50b56f3ff4e896063c3082adaee19c8`, 콘텐츠 ZIP52,737,739바이트의 SHA-256은 `fe8282b3ef76dc0214e6f898c45c58cb3c11cc019615552e3a7fa39371c75b6d`입니다. 콘텐츠25는 기존 네이티브 엔진8–25와 호환됩니다.

최종 소스97개·테스트50개와 배포 파일을 고정한 불변 HTTP 사본57개에서 같은 모바일 검수 파일을 실행했습니다. 최종1,104개 검사가 통과했으며 생산품 터치12회·생산 및 수령9회·층 보기9회·이전 집 영역까지 이동을 완료했습니다. 그림33회와 마을 활동의 실제 물품 SVG6회, 사진22장을 확인했습니다. 콘솔 오류나 실패한 자산 요청은 없었고, 테스트와 제품 소스는 빌드 후 수정하지 않았습니다. 개발 서버와 과거 버전 검사 수는 최종 결과에 합산하지 않습니다.
