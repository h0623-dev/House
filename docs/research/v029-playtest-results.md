# v0.29 — 자동 기력 회복과 전체 지도

기력은 실제 시간 20초마다 1씩, 1분에 3씩 자동 회복하며 최대 100입니다. 공통 2배 게임 속도·마을 시계와 별도로 계산하고, 전투·일시정지·오프라인에서도 같은 회복 기록을 사용합니다. 상단 기력 표시에서 다음 회복까지의 남은 초를 확인합니다. 휴식·쓰다듬기의 기존 체력·기분 효과는 유지하며 기력을 즉시 지급하지 않습니다. 과거 저장에 회복 기록이 없으면 처음 적용한 시각부터 시작합니다.

기본 시점은 전체 보기입니다. 1층에서 트럭과 지상 도로·채집 장소·동물길을 함께 보여 주고, 2·3층에서는 선택한 층만 화면에 맞춥니다. 이동·사다리·채집·문 조작 중에도 같은 배율을 유지합니다. 직접 확대하거나 드래그한 화면은 유지하며, ‘전체 보기’로 기본 배율과 위치를 복원합니다.

동물길은 트럭 바깥쪽의 세 지점을 연결하는 짧은 동선으로 줄였습니다. 동물의 실제 몸체 크기와 원래 속도를 유지하면서 통로와 주인공 계단을 트럭의 목재·녹색 금속 색상에 맞춥니다. 계단 그림은 실제 이동 경로의 끝점과 일치합니다. 주인공이 문에 가서 조작한 뒤 상태를 저장하며, 문을 닫기 시작하면 새 통행을 막고 이미 통로에 들어간 동물의 이동을 먼저 마칩니다.

TypeScript 형 검사와 전체 단위 검사 394개가 통과했습니다. 회복 기록의 저장·복구와 실제 20·60초 계산, 오프라인·전투·최대 기력·시계 역행, 기존 진행 보존을 검사합니다. 실제 Scene을 사용하는 검사는 선택한 층의 전체 보기, 수동 배율·이동 경로 보존, 원래 몸체 간격과 동물 통행을 확인합니다.

기력 갱신 때 채집 창을 다시 만들어 실제 터치 대상을 교체하던 문제도 수정했습니다. 고정된 채집 비용과 창 구성은 유지하고 준비 상태·남은 초만 갱신합니다. 브라우저 검수는 실제 샘터 창을 열어 자연 회복 중에도 같은 채집 버튼이 연결되어 있고 정상 터치 영역을 유지하는지 확인합니다.

실제 고정 HTTP 게임의 344×740, 360×800, 390×844, 844×390 화면 검수가 모두 통과했습니다. 현재 실행의 단언 64,948개, 실제 문 조작 14회와 이동 24회, 몸체 간격 검사 5,592개, 카메라 검사 26,718개와 스크린샷 45개를 기록했습니다. 실제 20,218밀리초 관찰에서 기력이 86→87로 회복했고, 191개 자연 관찰 프레임 동안 같은 샘터 채집 버튼이 유지됐습니다. 게임 시간·애니메이션·경로·몸체 크기·이동 속도를 검사 코드로 대체하지 않았습니다.

390px 화면은 실제 샘터 채집·복귀·물 보상과 통행 중 문 닫기를 확인합니다. 가로 화면은 이전에 검증한 최대 확장·3층 저장을 변경 없이 불러오며, 이번 실행에서 새로 성장시킨 결과로 계산하지 않습니다. 전체 지도와 실제 터치 영역을 사용해 빈 도로로 이동하고, 직접 선택한 125% 배율·화면 위치를 유지한 뒤 100% 전체 보기로 돌아왔습니다. 층 선택은 실제 주인공의 위치와 경제 상태를 바꾸지 않습니다.

소스 112개와 검수 파일 64개를 고정한 단일 빌드 `v029-r1`을 사용합니다. APK는 61,144,088바이트, Android 코드 29이며 원래 APK 서명을 유지합니다. 콘텐츠 ZIP은 52,769,113바이트이고 네이티브 8–29와 호환됩니다. 새 ZIP의 서명·정확한 파일 목록·전체 해시 인증을 새로 실행했습니다. 네이티브 소스 9개는 이전 버전과 바이트가 같으며 기존 호스트 JVM 검사 19개는 재사용 결과로 구분합니다.

브라우저 검수는 Chromium 모바일 에뮬레이션입니다. 실제 Android·iPhone 기기에 설치하거나 Android 앱에서 OTA를 실행한 결과로 표시하지 않습니다. 최종 APK·콘텐츠·정적 웹·단일 HTML을 담은 고정 사본 57개는 실제 HTTP 응답과 바이트가 일치합니다. 공개 주소 검증은 게시 후 별도로 집계합니다.

최종 검수 기록은 `artifacts/gameplay-v029-v0.29.0-verification.json`, 빌드·단위·HTTP·보존 검증의 집계는 `artifacts/release-v0.29.0-preflight.json`입니다. 공개 파일·서명·서비스 워커 MIME·과거 APK 접근 결과는 게시 후 `artifacts/release-v0.29.0-final.json`에 집계합니다. 이전 버전·개발 진단·실패한 시도의 검사 수는 이번 최종 실행 수에 합산하지 않습니다.
