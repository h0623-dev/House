# v0.18 iPhone·웹 자동 패치 검수

기준은 v0.18.0, Android 코드18, 네이티브 콘텐츠 호환8–18이다. 이전 공개 소스는 `db242ea489f4e9ffc7aaefb6d10a211e205de5b6`이다. [iPhone 설치 안내](../IOS.md)는 Safari 공유 → 홈 화면에 추가로 실행하는 웹 앱을 설명한다.

## 구현과 저장

같은 사이트·scope를 유지하며 실행·복귀·재연결 때 업데이트를 확인한다. 새 릴리스 전체 파일의 크기·SHA-256을 검사해 캐시에 준비하고, 안전한 홈에서 저장한 뒤 새 화면을 불러온다. 변경 없는 그림·폰트는 이전의 검증된 캐시에서 재사용한다. 농사·전투·건설·열린 창·다른 탭의 활동 중에는 적용을 기다린다. 여러 탭이 준비되면 시작한 탭만 최종 저장하고 다른 탭은 오래된 메모리로 공용 저장을 덮어쓰지 않는다. 저장에 실패하면 적용을 취소하며 현재 마을을 유지한다.

처음 이름·성별을 정하기 전에는 닫기·배경·Escape로 환영창을 건너뛰거나 Safari 공유 때문에 기본 캐릭터를 저장하지 않는다. 설치 안내는 환영창 안에서 펼쳐 읽고 이름을 그대로 확정할 수 있다. iPhone의 작은 화면·가로 화면과 안전 영역을 고려하며 이름 입력 글자 크기는16px이다. Android 네이티브와 단일HTML에는 웹 worker·manifest·설치 태그를 제외한다.

## 실제 브라우저 검증

TypeScript 검사와 단위 테스트206개가 통과했다. 게임181개에 웹 업데이터25개를 추가한다. 마지막 승인에서 교체할 worker만 조회하도록 수정하여, 퇴장 중인 이전 worker를 깨워 활성화가 멈추는 문제를 재발 검사한다. 첫 설치의 임의 재시작, 작업 중 적용, 다중 탭 경합, 저장 실패도 검사한다.

제품 소스80개는 빌드 시작과 모든 산출 후의 SHA-256이 같다. 최종 정적 웹30개·Android 내장 웹26개·단일HTML1개의 총57개 파일을 불변 사본 `v018-r2`에 보관했고, 실제 로컬HTTP 응답 전체와 바이트가 같음을 확인했다. 아래 결과는 모두 그 사본을 사용하며 사전 진단과 실패한 r1 결과는 합산하지 않는다.

웹 검사는 실제 Service Worker를 등록한다. 최초 캐시, 독립된 세 첫 실행, 완전 오프라인 재로드, 농사 중 대기와 홈 복귀 후 자동 교체, 자연스러운 동물3웨이브 승리 후 보상 보존을 확인했다. 향후 릴리스 fixture6개는 출하 worker의 실행 코드 바이트를 그대로 사용하고 manifest·실제 파일·릴리스 식별자만 변경한다. 실제 캐시 증거5개에서 모든 파일의 크기·SHA-256이 선언과 일치했다. 손상·누락된 응답은 실제 설치에 실패하며, 이전 캐시로 오프라인 재실행할 수 있다.

두 탭에서 이름·성별·획득한 진행이 다른 실제 상태를 만들고, 바쁜 탭의 거부·모두 준비된 후 시작 탭의 최종 저장·대기 탭의 무저장·새 버전 재로드를 확인했다. 최종 저장에서만 저장소 오류를 주입한 경우 COMMIT 없이 실제 ABORT가 발생하며, 이미 저장한 진행과 기존 부팅을 보존하고 저장소 회복 후 적용했다. 합성 worker 승인·추가 skipWaiting 호출·브라우저 시간 조작·고급 게임 저장 fixture는 웹 패치 증거에 사용하지 않았다.

Safari 사용자 에이전트의390×664, 홈 화면 조건의390×844, 작은320×568, 가로844×390에서 설치 안내·조작 영역·첫 환영창을 확인했다. 실제Capacitor iOS/Android 분기를 모의한 경우 웹 worker 등록이0이며, 실제 단일HTML의HTTP 실행에서도 worker·외부 파일 요청이0이다. 이는 물리적인 iPhone 설치 검증과 구별한다.

## Android·공개 배포 경계

APK는61,175,402B, 서명된 콘텐츠ZIP은52,699,032B이며 원래 앱 ID와 APK 서명을 유지한다. 네이티브Java9파일은 v0.17과 같으므로 JUnit19개 결과는 재실행 없이 재사용했다. 새ZIP의 서명·안전한 경로·26개 실제파일 검증은 원래 공개 키의 호스트JVM에서 새로 실행했다. Android 시작 흐름의257개 브라우저 검사는 private Capacitor bridge를 사용하며 실물OTA 검증으로 표현하지 않는다.

게시 준비는76파일·966,242,739B로 decimal1GB 미만이다. 기존 APK15개와 새APK를 포함해16개, v0.17콘텐츠와 이전HTML의 모든 해시된 코드·그림·폰트를 유지한다. v0.14–v0.16 콘텐츠6파일은 기존 불변 공개 커밋에서 전체HTTP 바이트·SHA-256을 확인한 보관 링크를 제공한다. Git 이력을 삭제하거나 다시 쓰지 않는다.

실제 iPhone·WebKit·Android 기기·에뮬레이터는 이 환경에 없어 직접 설치와 기기에서의 자동 패치는 미검증이다. HTTPS 공개 게시의 응답·전체해시 확인은 `public-v0.18.0-verification.json`, `public-raw-web-v0.18.0-verification.json`, `public-pages-host-v018-verification.json`에 별도로 기록한다. 공개 원격브라우저 상호작용은 검증하지 않는다. 최종 집계는 `release-v0.18.0-preflight.json`과 `release-v0.18.0-verification.json`, 원본 성공은 `artifacts/*-v0.18.0-verification.json`에 보관한다.

진행은 각기기의 저장 영역에 남으며 Safari 탭·홈 화면 앱·Android·다른 기기로 자동 동기화하지 않는다. iOS의 사이트데이터 정리 후에는 파일 재다운로드가 필요하다. 단일HTML은HTTP로 로드한 뒤 오프라인으로 플레이한 범위이며, 파일주소 최초실행 성공으로 기록하지 않는다.
