## 실제 첫 진행

1. 이름 선택과 시작 버튼을 눌렀다. 기본 화면에는 25개 버튼과 건설·성장 목표의 중복 진입점이 나타났다.
2. 아래 현재 목표를 눌러 첫 보급품 목표를 열고 `하러 가기`를 눌렀다. 실제 탐색 후 목재·고철·물·씨앗이 한 번만 증가했다. 보상 준비 표시와 `!`가 나타났다.
3. 목표를 다시 열어 보상을 받았다. 다음 목표에서 `하러 가기`를 누르자 첫 밭 수확을 시작했다. 수확은 정상 완료했으나 농사 모드는 계속 남고 아래 목표 버튼은 사라졌다. 오른쪽의 별도 성장 목표 버튼을 찾아 다음 보상을 받았다.
4. 정수소 목표에서 건설 목록으로 이동하고 정수소 선택 → 빈 자리 선택 → 건설 확정을 눌렀다. 자원 사용과 시설 생성은 정상이다. 건설 직후 시설 상세창이 열려 생산을 눌렀다.
5. 정수소 생산은 `45초`로 표시되었고 실제 활동 중 시간 흐름으로 준비 상태가 되었다. 첫 측정 스크립트의 hidden 검사 실수 때문에 이 사이클의 정확한 완료 타임스탬프는 기록하지 않았다. 완료 후 물 +4를 정상 수령했다.
6. 첫 생산 보상을 받고 `두 밭에 새 씨앗` 목표로 이동했다. 당근을 선택하고 빈 밭 1과 3을 실제 터치로 연속 예약했다.
7. 첫 심기 중 아래 `건설`을 눌렀다. 3.834초 뒤 현재 한 칸을 끝내고 건설 목록이 열렸다. 아직 시작하지 않은 3번 밭 예약은 취소되었다. 현재 작업을 안전하게 끝내는 것은 작동하지만 예약 취소 결과를 메뉴 선택 전에 알기 어렵다.
8. 탐험에서 전투 입장을 눌렀다. 주인공과 보리가 자동 기본 공격을 하고 세 기술·AUTO·일시정지·철수 UI가 나타났다. 실제 5초를 관찰한 후 철수와 확인을 누르고 귀환했다. 승리·전투 보상·후속 스테이지 해금까지 검증한 것으로 주장하지 않는다.
9. 두 번째 도로 탐색 중 설정을 눌렀다. 여섯 하단 메뉴가 모두 disabled였다. 설정은 탐색 중에도 완료 후에도 열리지 않았다. 전체 탐색 이동·작업·귀환을 마치는 데 **18.152초** 걸렸다.

## 우선순위 5개와 수정 전후

### P0 — 진행할수록 마을이 작아지는 전체 보기

현재는 트럭을 전부 넣기 위해 배율을 낮춰 후기 밭 간격이 19~21px가 된다. 시설마다 항상 표시되는 이름·레벨 표지가 더 커 보이는 상황이다. 확장은 공간과 성장의 성취감보다 알아보기 어려운 미니어처로 느껴진다.

수정 방향: 전체 트럭 맞춤보다 시설·밭의 최소 가독성 배율을 우선하고, 넓어진 부분은 드래그·핀치로 보게 한다. 시설 상시 이름표는 줄이고 선택된 시설과 준비된 생산품만 명확히 표시한다. 홈/농장 전환 시 카메라를 매번 과하게 재설정하지 않는다. 확장 직후 새 데크 구역을 보여 주고 새 건설 가능 수와 밭 수가 증가한 사실을 화면에 연결한다.

증거: `19-declared-late-home-390.png`, `16-declared-late-home-360.png`, `20-declared-late-farm-tray-390.png`.

### P0 — 플레이와 메뉴 탐색이 작업 애니메이션 때문에 정지

현재 도로 탐색은 18초 정도이고, 이동/작업/귀환 내내 모든 하단 메뉴가 비활성이다. 시설 선택·건설 미리 보기·보상 확인까지 함께 막힌다. 기다리는 동안 다음 계획을 세우는 흐름이 없다. 농사 중 메뉴 이동은 지원하지만 현재 한 칸이 끝날 때까지 지연되고 나머지 예약은 없어지는 별도 규칙이다.

수정 방향: 주인공의 일은 계속 보이되 메뉴, 목표 확인, 생산 상태 확인 등 자원을 변경하지 않는 행동은 즉시 허용한다. 자원을 쓰는 행동은 명확한 예약·보류 표시를 둔다. 농사 예약을 취소하는 메뉴 이동에는 `현재 1칸 완료 후 이동 · 예약 1칸 취소`를 즉시 표시하고 플레이어가 취소할 수 있어야 한다.

증거: `27-gather-menu-blocked-390.png`, steps의 두 번째 탐색 및 중간 건설 기록.

### P1 — 현재 목표가 가장 필요한 때 다른 위치로 사라짐

첫 목표는 아래 카드에서 열지만 수확을 진행하면 농사 도구가 그 카드를 숨긴다. 시설을 선택하면 또 시설 상세창이 그 자리를 차지한다. 보상을 받으려면 최초 진입점과 다른 오른쪽 깃발을 찾아야 한다. `하러 가기`는 실제 필요한 일로 이동한다는 장점이 있다.

수정 방향: 현재 목표 1개의 제목·진행·보상 상태를 작은 고정 칩으로 유지한다. 보상 완료 시 같은 자리에서 1번 터치로 받고, 다음 목표와 새 해금 내용을 바로 보여 준다. 전체 24개 목록은 이 칩에서 여는 상세 화면으로 남긴다. 농사 도구와 시설 상세를 열어도 칩을 계속 사용할 수 있게 한다.

전: 아래 목표 → 상세 → 하러 가기 → 수확 → 오른쪽 별도 깃발 찾기 → 보상.
후: 고정 현재 목표 → 필요한 밭 강조/실행 → 고정 칩에 완료 → 보상 → 다음 해금 표시.

증거: `02-first-goal-390.png`, `05b-harvest-finishes-still-farm-mode-390.png`.

### P1 — 항상 보이는 도구 수와 깊은 생산 조작

360 화면은 홈에서도 25개 버튼이다. 오른쪽 건설과 아래 건설, 오른쪽 성장 목표와 아래 목표, 지속 확대·기본 보기·축소·농사 도구가 함께 보인다. 농사 화면은 34개 버튼이다. 시설 상세창에서 생산 진행 정보 외에 레벨·옮기기·교체가 같은 비중으로 노출된다.

수정 방향: 지도와 4~5개 주요 진입점을 먼저 보여 주고 고급 편집·이동·교체는 시설의 상세/더보기로 모은다. 직접 밭 터치 후 필요한 행동과 씨앗 선택을 보여 준다. 확대/축소는 핀치가 기본이고 보조 버튼을 작은 메뉴로 넣는다. 완료된 생산품은 지도에서 바로 받는 조작을 우선한다. 관리창에서만 다음 생산을 시작하는 현재 구조를 반복 생산 선택과 묶어 반복 터치를 줄인다.

현재 실제 터치 수: 시설 건설 4회(목록 진입·종류·자리·확정); 닫힌 시설에서 완료품 수령 2회(시설·수령), 다음 생산 1회 추가; 시설 개선 3회(시설·개선·확정); 처음 씨앗 심기 3회(씨앗 버튼·씨앗 종류·빈 밭), 이후 같은 종류는 밭마다 1회.

증거: `13-fresh-farm-tray-360.png`, `15-plant-mode-tray-360.png`, `09-waterworks-producing-390.png`.

### P2 — 생산/성장/전투의 세션 규칙이 마을 게임 기대와 분리

현재 모델에서 게임 시계는 앱이 보이지 않거나 작업·전투·일시정지 중에는 멈춘다. 작업 완료 시 해당 행동의 게임 분량을 한 번에 더하므로 생산 카운트다운이 작업 동안 멈췄다가 완료 때 줄어드는 규칙이다. 실제 생산 시간이 단순한 벽시계 시간이 아니다. 앱을 닫아 둔 생산도 이어지지 않는다. 전투 세 곳은 처음부터 선택 가능하며, 이번 관찰 범위에서는 별·다음 구역 해금·파티 편성이 보이지 않았다. 주인공 레벨은 실제 공격력에 반영되므로 완전히 분리된 장식은 아니다.

수정 방향: 생산은 시간 규칙을 독립적으로 명시하거나 실제 완료 시각으로 관리하고, 마을에서 받은 자원/시설 성장이 다음 행동·구역·캐릭터 성장에 쓰이는 연결을 강조한다. 전투 입장에는 권장 성장과 해금 조건을 보여 주고 승리 후 다음 목표·마을에 필요한 보상을 연결한다. 이 항목은 저장 데이터 호환과 중복 지급 방지가 필요하므로 별도 시스템 변경 검증 없이 UI 문구만 바꾸면 안 된다.

## 그대로 보존할 기능

- 실제 성장 목표 진행과 prefix 보상 검증, 건설 비용·자리 확인, 연속 씨앗 선택과 예약, 지도 이동·줌, 실제 이동/작업 애니메이션, 전투 기본 공격/기술, 진행 저장은 존재하고 이번 흐름에서 동작했다.
- 따라서 "아무 기능도 없음"이 진단은 아니다. 다음 구현의 기준은 조작 수·가독성·기다리는 동안 가능한 행동·보상에서 다음 해금까지 이어지는 흐름이다.
