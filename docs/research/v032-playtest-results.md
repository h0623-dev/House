# v0.32 지상 풍경과 채집 소품

지상 구역을 굵은 둥근 도형으로 구분하던 표현을 없앴습니다. 도로부터 낙엽 숲길·야생화 초지·자갈 공터·바위 샘터까지 하나의 불투명한 손그림 지형으로 이어집니다. 숲에만 좁고 불규칙한 흙길과 작은 목재 표지판을 표시합니다. 고철·씨앗·샘물은 같은 줄과 열에 맞추지 않고 엇갈린 위치에 놓습니다.

나무는 세 종류의 수관을 사용하고, 고철은 버려진 타이어·금속, 씨앗은 풀과 꽃, 샘물은 바위로 둘러싸인 작은 물웅덩이로 표현합니다. 지상 소품의 실제 밑동·발 위치를 기존 충돌 좌표에 맞춥니다. 물리적인 장애물과 접근점은 그림의 수관 크기와 구별하며 동물 반경을 줄이지 않습니다.

주인공·동물·지상 채집물은 발의 앞뒤 위치로 그립니다. 앞쪽 수관이 작업하는 주인공을 덮으면 옅게 표시하고, 베인 나무는 그루터기로 남습니다. 재생 시간은 선택한 대상에만 지도 위로 표시하며 상세·목록에는 각 대상의 남은 초를 계속 표시합니다. 지형은 고정된 세계 좌표를 사용합니다. 넓은 가로 보기와 세로 화면의 바깥 배경도 고정 반사 타일로 덮고, 실제 화면에 보이는 타일만 그립니다.

## 유지하는 플레이

독립된 나무 16그루와 고철·씨앗·샘물 각 4개, 모든 대상의 실제 180초 독립 재생, 채집 완료 시 보상·비용·퀘스트의 한 번 반영을 유지합니다. 트럭 아래 진입 제한, 실제 사다리·동물 경사로, 최대 반경 30.8의 동물 이동, 전체 지도 기본 시점, 공통 2배 속도와 실제 1분당 기력 3 회복은 이어집니다. 기존 저장·상점·농사·건설·업그레이드·전투 데이터는 같은 규칙을 사용합니다.

## 검증

전체 단위 검사 457개가 통과했습니다. 실제 아트 프레임·밑동 접점·수관·그루터기·채집 후 잔여물, 8개 트럭 확장 단계와 최대 동물 원, 고정 배경의 반사 경계·실제 캔버스 역행렬·가로/세로 범위를 확인합니다.

개발 버전은 Chromium 모바일 에뮬레이션 390×844·344×740·844×390에서 39,730개 검증, 7회 실제 채집과 4회 재실행을 통과했습니다. 먼저 벤 나무는 180,620ms에 준비되었고 둘째는 173,887ms로 7초가 남았습니다. 실제 재생 후 재채집과 다른 자원의 독립 타이머를 확인했습니다. 365개 물리 샘플·2,088개 자연 RAF·20,793개 도로 장애물 이동 선분을 검사하고, 실제 게임 화면 66개 중 원본 캔버스 21개를 바이트·해시로 보존합니다. 실행 중 시계·기력·보유량·경로를 주입하지 않았고 소스와 테스트를 수정하지 않았습니다.

배포할 불변 v032-r1의 같은 세 화면에서도 38,704개 검증·7회 채집·4회 재실행을 통과했습니다. 첫 나무가 180,639ms에 재생된 동안 둘째는 174,173ms로 6초가 남았습니다. 최종 360개 물리 샘플·2,042개 자연 RAF·20,068개 이동 선분을 다시 검사했습니다. 원본 캔버스 21개와 총 화면 66개, HTTP 사본 61개를 해시와 바이트로 확인했습니다. 실행 도중 보호한 제품·테스트·배포 도구를 수정하지 않았습니다.
