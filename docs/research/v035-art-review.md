# v0.35 지면·채집물·출입 통로

## 수정 범위

같은 지면 위에 놓인 나무·풀·고철·샘물이 다른 축척과 채도로 보이는 문제를 수정한다. 기존 배경의 확대된 잎·돌과 반사 반복 대신 새 지면 원화 한 장을 사용한다. 원화 바깥은 낮은 대비의 월드 고정 흙·풀 바탕으로 채우고 가장자리를 부드럽게 섞는다. 도로와 개울을 반복해서 그리지 않는다.

새 원화는 이 게임을 위해 생성한 독자적 그림이다. `src/assets/ground-landscape.png`는 1448×1086, 3,318,489바이트이고 SHA-256은 `0535c7fdf826d03f87b519c3c59be594572a33a6c97ed6065404c9faeeb3f25a`이다. 원화 교체와 별도로 지면·소품의 팔레트를 한 번 캐시하고 각 소품의 실제 접점 아래 작은 그림자를 합성한다. 원본 소품 아틀라스와 측정한 발·윤곽은 유지한다.

동물 통로와 사람 계단은 바랜 짧은 널판·얇은 그린 금속 프레임·작은 접지 받침으로 통일한다. 동물 통로의 나뭇결은 길 전체에 확대하지 않고 길이 15 월드 px 이하의 개별 널판에 낮은 불투명도로 표시한다. 최대 동물의 발을 지지하는 폭 76, 사람 계단 폭 48, 이동 끝점과 이전 통과 경로 유지 동작은 바꾸지 않는다.

7개 지역·52개 채집물의 위치, 터치 윤곽, 작은 충돌 범위, 보상, 180초 개별 재생과 기력 회복·게임 속도·저장 형식은 변경하지 않는다. 배경 그림 속 낮은 장식은 새로운 채집물이나 이동 장애물이 아니다.

## 실제 화면 검토

기존 코드에서는 밤의 주변광을 바닥을 그린 직후에만 적용해, 나중에 그린 나무·주민·동물이 낮의 밝기로 남았다. 실제 유료 마을의 밤 화면에서 이 원인을 확인했다. 공통 조명을 모든 월드 소품·인물을 그린 뒤에 적용하도록 옮겼으며, 자원 표식과 화면 UI는 조명 이후에도 읽을 수 있게 유지한다.

첫 지면 합성 비교는 `artifacts/v035-ground-art-before-after.png`에 보존했다. 이후 전체 보기에서 원화 바깥의 반사 도로·개울이 남은 것을 발견하여 반사 루프도 제거했다. 첫 비교 화면만으로 전체 지도의 검수를 대신하지 않는다.

첫 개발 플레이의 원문과 실행 입력은 `artifacts/v035-art-development-r1-verification.json` 및 같은 이름의 `-inputs` 폴더에 보존한다. 강아지·고양이 통로 이용·문 조작·사람 계단 왕복·서쪽 벌목을 실행했지만, 새 검수기의 관찰 시계로 계산한 이동 속도 조건에서 실패했다. 다음 실행에서는 실제 게임의 프레임 시각과 관찰 시각을 함께 보존하여 이동 경로와 시계 위상 차이를 구분한다. 실패 원본은 수정하지 않는다.

검증 환경은 Chromium의 모바일 화면 및 데스크톱이며 실제 Android·iPhone 설치나 단말 자동 패치 실행을 의미하지 않는다.

타입 검사 `tsc --noEmit`는 종료 코드 0이며, 최종 소스 122개와 TS 검사 입력 43개를 실행 전후 고정한 전체 단위 검사 476개가 모두 통과했다. 실패·취소·건너뜀은 0개다. 기록은 `artifacts/unit-v035-final-r2-inputs.json`(SHA-256 `851ee6489de17233f56485ebca691b0eef7d6a64582d3cf519018f2d76a74684`) 및 `artifacts/typecheck-v035-final-r2-verification.json`에 있다.

낮·밤 공통 조명까지 적용한 개발 플레이 r5는 모바일 390×844·데스크톱 1365×900에서 326개 검증을 통과했다. 실제 보상 4건을 도메인 동작과 정확히 재생해 한 번만 지급되는 것을 확인했고, 강아지·고양이 및 강아지·멧돼지의 두 통로 이용, 문 조작, 사람 계단 왕복, 실제 화면 이동·확대, 저장 후 재실행을 확인했다. 21개 화면, 물리 표본 540개와 자연 RAF 4,276개를 보존했다. 실행 중 시계·보유량·배치·이동 위치를 주입하지 않았다. 기록은 `artifacts/v035-art-development-r5-verification.json`(SHA-256 `f789690122808f5c2496ade3e9f03bea7787de0d4d04df3239558ee754dec776`)이다.

초기 검수의 관찰 시계·HUD 옆 터치 시작점 가정 및 작은 임시 디스크를 사용하는 Chromium 실행 설정 때문에 발생한 실패는 각각 보존했다. 실제 게임의 프레임 시각으로 연속 이동을 확인하고, 화면 버튼에서 떨어진 실제 입력 경로와 충분한 공유 메모리를 쓰는 브라우저 설정으로 바로잡았다. 최종 검수에서는 게임·검수기·검증 도구를 다시 수정하지 않는다.
