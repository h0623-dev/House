# v0.15 3배 속도 실제 플레이 비교

동결된 v0.14 r3와 v0.15 r1을 같은 저장 상태·같은 경로로 실행했다. 390×844, 360×740 Chromium 모바일 환경에서 화면 좌표를 실제 터치하고 자연 벽시계 시간을 측정했다. 실물 Android 측정은 아니다. 제품 코드와 동결 빌드는 수정하지 않았다.

기준점은 `/tmp/road-haven-qa-v014-r3`의 `http://127.0.0.1:4239/House/`, 새 버전은 `/tmp/road-haven-qa-v015-r1`의 `http://127.0.0.1:4241/House/`다. 기존 4236 서버가 빈 응답을 반환해 동일한 기준점 폴더를 별도 4239 서버에서 읽었다. 각각 manifest의 48개 파일을 SHA256으로 확인하고, 실제 HTTP로 제공된 `/House/` 파일 23개도 manifest와 바이트가 같은지 확인했다. 결과는 `artifacts/audit-v015/snapshot-identity.json`에 있다.

## 이동·작업·복귀

다음은 작업 시작의 `aria-busy`부터 복귀 완료까지의 시간이다. 두 버전에 동일한 선언된 저장 fixture를 넣고, 준비 화면에서 마을 시계를 일시정지해 작물 성장과 자원 변동을 분리했다. 저장 불러오기와 일시정지 전 메뉴 이동 동안 전역 틱이 진행될 수 있으므로 저장의 시작 시각과 완료 시각 차이를 작업 시간으로 사용하지 않았다. 일시정지는 기존 동작대로 마을 성장 시계만 멈추며 진행 중인 캐릭터 작업을 취소하지 않는다. 시간 가속 API나 게임 행동 함수를 직접 호출하지 않았다.

| 행동 | 390px v0.14 → v0.15 | 360px v0.14 → v0.15 |
|---|---:|---:|
| 씨앗 심기 | 5.652 → 1.897초 | 5.651 → 1.922초 |
| 물 주기 | 4.244 → 1.454초 | 4.244 → 1.450초 |
| 수확 | 4.728 → 1.596초 | 4.676 → 1.603초 |
| 벌목 | 17.745 → 5.960초 | 17.734 → 5.951초 |
| 도로 채집 | 18.055 → 6.042초 | 18.053 → 6.081초 |
| 데크 확장 | 6.156 → 2.104초 | 6.153 → 2.066초 |
| 밭 추가 확장 | 6.215 → 2.093초 | 6.195 → 2.121초 |

14개 비교 모두 실제 완료 시간이 약 3분의 1로 줄었다. 측정된 배율은 2.918~2.988배다. 장면의 이동·작업 총시간 데이터는 반올림 오차 범위에서 정확히 3배이고, 실제 프레임과 입력 처리에는 수십 ms가 더 걸린다.

모든 행동에서 **이동 → 작업 모션 → 복귀**가 남았으며, 벌목과 도로 채집은 사다리를 내려가는 단계와 올라오는 단계를 모두 관찰했다. 자원은 복귀 완료 뒤 정확히 한 번 바뀌었다. 심기·물 주기·수확·벌목·채집·데크 확장의 완료 기록은 각각 1회, 추가 밭은 정확히 1칸 늘었다. 완료 전 보상이나 중복 자원 반영은 없었다.

두 화면 크기에서 연속 심기와 중지도 확인했다. 서로 다른 두 밭을 예약한 뒤 창고를 열었을 때 두 밭 모두 완료되고 씨앗 2개만 사용했으며 창고는 계속 열려 있었다. 같은 예약에서 중지를 눌렀을 때 진행 중인 첫 밭만 완료되고 씨앗 1개만 사용했다.

## 생산·성장·전투의 자연 시간

아래 비교는 390×844에서 마을 시계를 실제로 진행시키며 기다린 결과다. 일시정지한 구간만 측정 시간에서 뺐다. 정수소는 실제 지도 생산 버튼으로 시작하고 준비 상태가 될 때까지, 작물은 동일한 심어진 저장 상태에서 수확 버튼이 나타날 때까지 기다렸다.

| 항목 | v0.14 표시 / 실측 | v0.15 표시 / 실측 |
|---|---:|---:|
| Lv.1 빗물 정수소 생산 | 45초 / 44.301초 | 15초 / 14.251초 |
| 물 준 당근 성장 | 90초 / 89.701초 | 30초 / 29.693초 |
| 바람 가르기 스킬 대기 | 12초 / 12.038초 | 4초 / 4.060초 |

정수소와 작물의 준비 시점은 전역 1초 틱의 시작 위치 때문에 표시보다 최대 약 1초 먼저 관찰될 수 있다. 이번 측정의 차이도 그 범위다. 씨앗 인벤토리의 당근 설명도 실제로 `성장 90초`에서 `성장 30초`로 바뀌었으며 준비된 생산품을 지도에서 받자 물이 정확히 4, 수령 기록이 정확히 1 늘었다.

마을을 약 3초 일시정지했을 때 생산 잔여 초와 마을 시각은 그대로였다. 전투를 약 2.5초 일시정지했을 때 경과 초와 스킬 잔여 초도 그대로였다. 전투 재개 후 실제 1.8초 기다리는 동안 경과 표시는 두 버전 모두 1초에서 3초로 진행했다. 전투 진행과 스킬은 빨라졌지만 **경과 시간 표시는 실제 초**를 유지한다.

일시정지 상태의 숨김·복귀 처리도 확인했다. headless Chromium에서는 다른 탭을 앞으로 가져와도 `document.hidden`이 바뀌지 않아, 숨김 값을 명시적으로 설정하고 `visibilitychange` 이벤트를 발생시키는 모의 검사를 사용했다. 숨긴 2.5초와 복귀 직후에 마을 시각·생산 잔여 초가 변하거나 부재 성장 보상이 붙지 않았다. 이는 해당 이벤트 처리 경로의 검사이며 실제 Android 앱 백그라운드 검증으로 확대하지 않는다.

## 증거와 범위

비교 요약은 `artifacts/audit-v015/comparison-summary.json`이다. 두 버전의 원본 기록은 각각 `v014-baseline/`, `v015-final/`의 `motion-summary.json`, `390-motions.json`, `360-motions.json`, `timer-records.json`, `timer-summary.json`에 있다. 실제 화면은 같은 폴더의 `390-gather-start.png`, `360-gather-start.png`, `clock-ready-390.png`, `battle-ready-390.png`다. 두 버전 모두 브라우저 실행 오류와 실패한 그림·폰트·스크립트·스타일 요청은 없었다.

비교 준비용 자원·작물·시설·밭 상태는 명시된 저장 fixture다. 새 플레이로 획득한 진행이라고 주장하지 않는다. 이 검사는 일곱 일상 행동, 연속 작업·중지, 사다리, 자연 생산·성장·스킬 시간, 일시정지와 표시 단위를 확인했다. 모든 전투 적·모든 장면·실물 기기의 프레임 성능까지 측정한 결과는 아니다.
