# v0.20 — 터치 이동과 반려동물 보행

빈 바닥을 터치하면 캐릭터가 걸어가고 이동 중 다시 누르면 목적지를 바꿉니다. 밭·건물을 우회하며 트럭과 도로 사이는 실제 사다리로 오갑니다. 농사·채집·시설 작업은 현재 위치에서 출발해 돌아옵니다. 새 시설이나 밭이 그 위치를 덮었을 때는 가까운 빈 가장자리로 실제 이동하며, 일반 작업은 원래 위치로 돌아옵니다.

강아지·고양이는 실제 이동 거리로 발걸음을 계산합니다. 대각선 발을 번갈아 디디고 몸·머리·꼬리를 함께 움직이며 방향을 바꿀 때 0.30초 멈춰 돌아섭니다. 원본 그림·크기·전투 포즈는 유지합니다. 공통 속도는 2배이고 자원·보상·저장 형식도 유지합니다. 자유 이동의 위치는 실행 중 유지하며 저장 형식에 추가하지 않습니다.

자유 이동 검사는 360×740·390×844·844×390 화면에서 실제 이동 23회, 드래그·취소·핀치·화면 이동 모드 등 13회와 현재 위치 작업 3회를 수행했습니다. 밭·도로·시설 작업의 실제 출발·귀환 위치와 한 번만 지급되는 자원을 확인했고, 작업 중 유효한 바닥을 눌러도 작업을 끊지 않았습니다. 실제 장애물 우회, 사다리 중간 방향 변경, 메뉴·전투 진입 시 현재 위치에서 멈춤, 캐시로 완전히 오프라인 재실행한 뒤 이동도 통과했습니다. 가로 화면은 실제 지도 드래그로 도로를 보이게 했습니다.

자연 프레임의 착지 발 이동/몸 이동 비율 중앙값은 강아지 1.97%, 고양이 1.80%였습니다. 실제 휴대폰 크기의 걷기·멈춤·회전 그림을 검수했습니다. 렌더 후 관측 콜백 시각과 실제 프레임 시각을 구분했고, 터치는 실제 pointer-up 위치·화면 변환·가려짐을 독립적으로 확인했습니다. 화면 전환 중 이전 좌표, 숨긴 조작판, 짧은 작업 이후의 터치와 화면 경계 터치 등 검수 도구의 실패 자료는 별도로 보존했습니다. 부분 검사는 최종 결과로 합산하지 않았습니다.

## 자동 패치와 보존

실제 v0.19와 v0.20 파일·Service Worker를 같은 로컬 주소에서 순서대로 제공했습니다. 기존 농사 중에는 새 파일 준비 후 적용을 기다리고 홈에서 한 번 자동 재시작했습니다. 실제 플레이로 얻은 동물 경험치·부상, 자원·밭과 정수소 생산의 완료 시각을 보존했고 두 버전 모두 공통 2배 속도로 실행됐습니다. 새 버전의 완전한 오프라인 재실행도 통과했습니다.

새 v0.20의 걷기 적용 대기는 별도 새 브라우저에서 정확한 v0.20 → v0.19 파일을 로컬에서만 제공해 검사했습니다. 실제 걷기·목적지 변경 중에는 준비된 worker가 재시작을 보류했고, 실제 메뉴를 열어 이동을 멈춘 뒤 닫으면 한 번 적용됐습니다. 이 검사는 운영 버전을 되돌리지 않았으며 주 업데이트의 한 번 재시작 결과와 별도로 기록합니다.

APK 버전 코드 20은 원래 앱 ID·서명을 유지합니다. 새 콘텐츠 ZIP은 원래 공개 키의 서명과 전체 파일을 호스트 JVM에서 새로 검증했습니다. 바이트가 같은 네이티브 소스 9개의 기존 Java 테스트 19개는 재실행 없이 재사용했습니다. 콘텐츠는 네이티브 엔진 8–20과 호환됩니다.

게시 준비 파일은 78개·993,233,177바이트입니다. 현재 게시 용량을 1GB 미만으로 유지하기 위해 직전 콘텐츠 ZIP·체크섬과 v0.4 APK·체크섬만 검증된 고정 커밋 주소로 보관했습니다. 기존 캐시 자산·글꼴과 18개 APK 릴리스의 접근을 유지하며 Git 기록을 다시 쓰지 않습니다. 고정 주소·전체 해시는 [콘텐츠 배포 안내](../CONTENT-UPDATES.md)에 기록합니다.

검수 범위는 Chromium 모바일 화면의 실제 터치·타이머·Service Worker입니다. 전체 화면 회귀에는 가상 시계와 명시한 구형 저장 경계 사례를 사용했습니다. 물리 iPhone/Safari 설치나 Android 기기 설치·자동 패치 실행은 확인하지 않았습니다. 공개 호스트는 배포 뒤 정상 HTTPS 전체 응답·해시·서명을 별도로 검증합니다.
