# v0.26 레알팜 참고와 트럭 상점 설계

## 실제 확인한 자료

2026-10-13(한국 시간), NEOGAMES가 게시한 [레알팜 공식 Google Play 소개](https://play.google.com/store/apps/details?id=kr.neogames.realfarm&hl=ko)와 스크린샷 8장을 HTTPS HTTP200으로 받아 읽고 화면을 확인했다. 소개에 표시된 마지막 업데이트는 2026-10-01이다. 이 조사는 직접 게임을 설치해 플레이하거나 동영상을 시청한 결과가 아니다. 일반 상점의 전체 품목·가격·구매 규칙과 비공개 개발 문서는 검증하지 않았다.

소개에는 온도·영양·수분 관리, 펫, 농장 꾸미기, 장착에 따라 달라지는 커스터마이징 장비, 장비 강화, 씨앗·식물 교배와 거래가 설명돼 있다. 공개 화면에서는 가방의 물품·작물·장비·장식물·기타 탭, 장착한 캐릭터 모습, 밭 사이를 다니는 여러 펫, 성장 전후 농장 규모와 꾸미기 변화가 보인다. 꽃 교배와 시즌별 농사 행동, 다양한 조경도 보인다. 랜드마크 목록의 그림·진행 조건·잠금·가격 표시는 확인했지만 이를 일반 상점 전체 규칙이라고 해석하지 않는다.

공식 소개가 안내한 가이드 `cafe.naver.com`과 고객센터 `realfarm.zendesk.com`은 프록시 CONNECT403으로 접근할 수 없었다. 개발사 링크 `neogames.co.kr`은 HTTP403 ‘Domain forbidden’이었다. 접근을 우회하거나 다른 프록시·DNS·자격 증명을 시도하지 않았다. 원문과 8장 화면, URL·SHA-256·접근 결과는 Git에서 제외된 `artifacts/research-v026/`에 보관한다. 레알팜 그림은 제품 자산으로 사용하지 않는다.

## 우리 게임에 적용한 흐름

농사·생산·채집으로 물자를 모으고 남는 물자를 판매해 게임 코인을 얻는다. 코인으로 씨앗을 보충하고 먼저 만날 동료나 취향에 맞는 의상을 고른다. 구매한 상품은 인벤토리·동료 편성·실제 캐릭터 모습에 이어져 다음 생활에 사용할 수 있다. 상점은 씨앗·애완동물·의상·판매의 네 탭으로 구성하고 상품 그림·보유량·보유 또는 착용 상태·가격을 함께 표시한다. 구매·판매는 별도 확인 화면에서 수량과 거래 후 코인을 확인한 뒤 확정한다. 실제 돈을 받는 결제는 없다.

다음 가격은 레알팜의 가격이 아니라 로드헤이븐의 게임 밸런스다.

| 분류 | 품목과 사용 | 코인 |
| --- | --- | ---: |
| 씨앗 | 당근·감자·토마토·옥수수·딸기·호박, 1·5·10개 선택 | 1개당 2·3·4·5·7·9 |
| 판매 | 식량 묶음·목재·고철 | 1개당 3·1·2 받음 |
| 의상 | 텃밭 나들이·도로 여행자·숲속 탐험가 | 40·60·80 |
| 먼저 만날 동료 | 토끼 루루·여우 루비·멧돼지 도도·부엉이 모모 | 60·90·120·150 |

기존 수확물은 작물별 수량이 아니라 통합 식량이므로 판매 품목을 ‘식량 묶음’으로 표시한다. 과거 저장에서 없는 작물 수량을 만들어 내지 않는다. 강아지 보리·고양이 나비와 데크 성장으로 이미 해금한 동료는 보유 상태를 유지하고 다시 구매하지 않는다. 아직 해금하지 않은 동료만 코인으로 먼저 만나며, 별도 편성에서 선택해 전투에 사용한다. 구매는 기존 체력·경험치·편성을 초기화하지 않는다.

씨앗 구매는 해당 품종 보유량과 총 씨앗 수량을 함께 늘리고 기존 씨앗 선택·연속 심기를 유지한다. 의상은 한 번 구매하면 남녀 공용으로 사용할 수 있고, 남녀별 착용을 각각 저장한다. 기존 손그림 위에 자세별 모자·앞치마·스카프·배낭을 그려 실제 이동·사다리·농사·채집과 초상화에 반영한다. 옷으로 작업·성장·전투 속도를 바꾸지 않는다.

상점 기록이 없는 저장은 코인0과 구매 기록 없음, 기본 의상으로 읽는다. 상점을 열거나 업데이트를 적용하는 것만으로 코인을 지급하지 않는다. 거래는 현재 보유량과 소유권을 확인하고 자원·코인·소유권을 한 번에 반영한다. 부족한 코인·물자나 중복 구매는 저장을 바꾸지 않는다. 공통 2배 속도, 기존 마을·밭·생산 시각·층 높이264·선택한 층 표시와 실행 시 자동 패치는 이어간다.

이 문서는 조사와 설계 근거다. 새 버전의 실제 테스트·APK·공개 배포 결과는 해당 릴리스 검수 기록에 따로 기록한다.
