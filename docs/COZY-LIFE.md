# v0.51 트럭에서 함께 보내는 일상

폐허가 된 도로를 배경으로, 트럭 안에서 집과 친구를 돌보는 재미를 더합니다. 기존 농사·생산·채집·건설·전투와 저장을 이어갑니다.

## 시작하기

화면 왼쪽 아래 **일상**을 누릅니다. **오늘의 일상 · 동물 친구 · 트럭 꾸미기** 세 탭을 사용합니다. 창은 기존 상단 닫기 버튼으로 닫습니다.

## 동물 친구

11종 모두 성격·좋아하는 것·대사·친밀도가 있습니다. 동물 그림을 눌러 상세 정보를 열거나 일상의 친구 탭에서 선택합니다. 쓰다듬기·선물·부탁 전달은 주인공이 실제로 다가가 손을 움직인 뒤 성공한 행동만 반영합니다. 전달 동작은 기존 상호작용 리그를 공유합니다.

쓰다듬기는 계속 할 수 있지만 친밀도 보너스는 친구별 하루 한 번입니다. 좋아하는 선물과 작은 부탁도 친구별 하루 한 번이며 물품은 실제 보관량에서 사용합니다. 식량을 사용하면 수확 작물의 보관 기록도 같은 양만큼 정리하여 중복으로 사용할 수 없게 합니다. 부탁 보상의 게임 코인은 기존 상점의 코인입니다. 친밀도는 최대 100이며 전투 체력·경험치와 따로 저장합니다.

강아지는 함께 걷고, 고양이는 낮에 조용한 자리를 찾으며, 원숭이는 텃밭 쪽에 관심을 보입니다. 부엉이와 다른 친구들도 게임 속 시간에 맞춰 이동 범위·속도·휴식이 달라집니다. 기존 발 디딤과 관절 리그를 유지하며 새로운 눕기·앉기 원화를 추가한 것은 아닙니다. 큰 동물의 승선 조건과 공유 계단·문은 유지합니다.

## 제작하고 꾸미기

| 장식 | 격자 | 생활 공간 |
| --- | --- | --- |
| 꽃 상자 | 1×1 | 작은 꽃 화분 |
| 참나무 벤치 | 2×1 | 나무 휴식 가구 |
| 별빛 가로등 | 1×1 | 작은 황동 조명 |
| 소풍 러그 | 2×2 | 위로 걸을 수 있는 바닥 장식 |
| 새들의 물그릇 | 1×1 | 재활용 수변 소품 |
| 환영 가랜드 | 2×1 | 꽃과 작은 깃발 장식 |

재료와 코인을 보고 **만들기**를 누르면 보관함에 한 개가 생깁니다. **배치**를 눌러 데크를 터치하거나 끌고, 초록색 미리보기에서 확정합니다. 취소해도 만든 장식은 보관함에 남습니다. 장식 그림을 선택하면 **위치 옮기기 · 보관하기**를 사용할 수 있고 다시 배치할 때 재료를 쓰지 않습니다. 회전도 무료입니다.

시설·밭·난간·사람과 동물의 출입구·층계와 겹치는 설치는 막습니다. 기존 장식을 덮는 시설·밭·층 증축도 먼저 재배치하도록 안내합니다. 동물이 지나는 자리에 설치하면 가까운 안전한 위치로 옮깁니다. 러그 외의 가구는 이동 장애물로 반영합니다. 1~3층 중 열린 층에만 배치하며 선택한 층만 표시합니다. 보관과 재배치는 제작 수량을 늘리지 않습니다.

## 오늘의 작은 목표

동물 한 마리 쓰다듬기, 수확·채집 합계 세 번, 소유한 장식 한 개 배치하기의 세 목표를 제공합니다. 완료 후 **선물 받기**를 눌러야 코인·재료를 받으며 열람만으로 지급하지 않습니다. 목표는 한국 날짜의 자정에 바뀌고 게임의 빠른 하루 주기와 구분합니다. 과거 누적 채집 기록을 오늘의 성과로 지급하지 않습니다. 기록은 기기에 보관하며 서버나 기기 간 동기화를 추가한 버전은 아닙니다.

## 소리

설정의 **게임 소리**를 켜면 작은 바람·낮의 새소리·밤벌레와 실제 걷는 동안의 발소리를 사용합니다. 음소거·일시정지·창 열기·백그라운드에서는 환경음을 정리합니다. 새 음원 다운로드 없이 원본 절차 음향을 사용합니다.

## 제작 범위

기존 저장에 선택적 `cozyLife`·`cozyDecor`를 추가합니다. 이전 저장을 여는 것으로 유료 가구나 보상을 지급하지 않습니다. 원화·동물·지면은 기존 게임 자산을 이어가고 새 장식은 같은 투영의 Canvas 구조로 그립니다. 사용자 요청에 따라 별도 단위·브라우저·플레이 테스트는 실행하지 않으며 배포용 컴파일·번들·APK 제작과 서명을 수행합니다.
