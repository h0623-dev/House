# 동물과 함께 살기

v0.53은 기존 입체풍 일러스트를 관절별로 나누어 동물마다 다른 보행과 생활 상호작용을 표현합니다. 동물 11종의 기본 보유 수와 큰 동물의 데크 탑승 조건은 유지합니다.

큰 방향 전환에서는 현재 자리에서 발을 멈추고 돌아선 뒤 앞으로 출발합니다. 대각선 이동에서도 몸 방향은 실제 이동 방향을 따르며, 좌우가 뒤집힐 때 그림의 폭을 0으로 줄이지 않습니다. 코끼리·기린은 오래 감속하고 천천히 회전하며, 강아지·고양이·여우는 더 민첩하게 방향을 바꿉니다. 같은 규칙을 탑승 산책에도 적용합니다. 좌우 ¾ 방향 원화를 사용하며, 이 변경이 새로운 8방향 모델이나 3D 회전 원화를 추가하는 것은 아닙니다.

## 동물별 움직임

| 동물 | 생활 공간에서 표현하는 움직임 |
| --- | --- |
| 강아지 | 네 발을 순서대로 디디는 걷기와 꼬리 반응 |
| 고양이 | 낮은 몸통과 조용한 발 디딤, 작은 머리 움직임 |
| 토끼 | 뒷발로 밀어 몸을 보내고 앞발로 착지하는 짧은 뜀 |
| 여우 | 가벼운 네 박자 걸음과 균형을 잡는 긴 꼬리 |
| 멧돼지 | 짧은 보폭, 낮은 발 들기와 묵직한 몸통 |
| 부엉이 | 두 발로 짧게 뛰고 접힌 날개로 균형 잡기 |
| 원숭이 | 팔과 반대편 다리를 번갈아 쓰는 이동 |
| 코끼리 | 긴 지지 시간의 네 박자 걷기, 귀와 코의 관절 움직임 |
| 기린 | 긴 보폭의 측대보와 목의 작은 균형 움직임 |
| 판다 | 긴 발 지지 시간과 무거운 체중 이동 |
| 사슴 | 풀을 뜯으며 산책할 때 차분한 네 박자 걷기와 긴 다리 움직임 |

보행 위상은 실제 이동 거리와 종별 고정 보폭으로 계산합니다. 방향을 바꾸는 것만으로 걸음 위상이 바뀌지 않으며, 정지하면 다리를 계속 걷게 하지 않습니다. 전투의 공격·기술 자세와 기존 의상·일러스트는 유지합니다.

## 만나고 쓰다듬기

지도에서 동물을 누르면 작은 동물 메뉴가 열립니다. 마을 메뉴의 **동물 동료**에서도 원하는 동물 카드를 선택할 수 있습니다. 카드 선택은 동물을 보여 주는 카메라 이동이며 주인공을 순간이동시키지 않습니다.

**쓰다듬기**를 누르면 동물이 기다리는 동안 주인공이 실제 길을 따라 곁으로 갑니다. 작은 동물에게는 몸을 낮추고 큰 동물에게는 서서 손을 뻗습니다. 쓰다듬는 동안 손을 반복해 움직이고 동물의 머리·꼬리·귀·코 반응과 작은 하트를 보여 줍니다. 행동이 끝나면 행복을 3 올리고 생활 기록을 남깁니다. 기력과 물자는 사용하지 않습니다.

통로를 건너는 동물에게는 통행이 끝난 후 인사합니다. 길이 막히거나 행동이 중단되면 완료 보상을 지급하지 않습니다. 전투 편성은 동물 목록의 **전투 동료 편성하기**에서 별도로 바꿉니다.

## 코끼리와 기린에 타기

건강한 코끼리·기린이 지상에 있으면 **올라타기**가 열립니다. 주인공이 곁으로 걸어가 등을 타며, 탑승 자세는 좌석을 기준으로 무릎을 굽히고 다리를 내립니다. 동물이 방향을 바꾸고 몸을 움직일 때 주인공도 그 좌석을 따라갑니다.

탑승 후 빈 지상 길을 누르면 함께 걸어갑니다. 동물 몸집에 맞는 통행 공간으로 경로를 찾으며 트럭 밑과 좁은 계단·경사로에는 들어가지 않습니다. 큰 동물의 데크 승선 기능과는 별개의 지상 산책입니다.

왼쪽 아래 **내리기**를 누르면 주변의 안전한 빈 땅을 찾아 내려옵니다. 공간이 부족하면 넓은 공터로 이동해야 합니다. 탑승 표시의 동물 이름을 누르면 시점을 다시 맞춥니다. 손가락으로 지도를 움직이거나 확대하면 그 수동 시점을 유지합니다.

농사·건설·채집·전투·문 조작은 내려서 시작합니다. 탑승이나 인사 도중 준비된 콘텐츠 패치는 내려서 행동을 마친 뒤 적용합니다. 화면 회전 등으로 잠시 멈출 때는 이동도 멈추며, 진행 중인 인사는 취소될 수 있습니다. 탑승 상태는 현재 실행에만 유지되고 다시 실행하면 기본 생활 상태에서 시작합니다.
