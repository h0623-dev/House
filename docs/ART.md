# 로드헤이븐 일러스트 구성

0.4.0은 기존 남녀 생존자 일러스트의 잉크 선, 초록색 의상, 가죽과 금색 장식을 기준으로 세계와 인터페이스를 구성합니다. 그림은 이 게임을 위해 새로 제작했으며 다른 게임의 캐릭터나 배경 파일을 사용하지 않습니다.

| 원본 파일 | 게임에서 사용하는 그림 |
| --- | --- |
| `src/assets/survivors-anime.png`, `survivors-actions.png` | 남녀 생존자의 이동·농사·벌목·공격 포즈와 초상화 |
| `src/assets/world-road-anime.png` | 식물이 자란 미래 서울의 도로와 먼 도시 |
| `src/assets/world-atlas-anime.png` | 트럭·오두막·나무·물탱크·태양광 패널·가구·작물·목재와 금속 재질 |
| `src/assets/world-parts-anime.png` | 운전석·타이어·계단·울타리·그루터기·화분 |
| `src/assets/creatures-anime.png` | 진돗개 보리의 이동과 돌진, 일반·질주·보스 좀비 |
| `src/assets/battle-*.png` | 숲길·한강 교량·남산 검문소의 전투 배경 |
| `src/assets/items-anime.png` | 자원·생활 행동·장비·메뉴 아이콘 |
| `src/assets/skills-farm-anime.png` | 전투 기술과 텃밭 상태를 보여 주는 그림 |
| `android/app/src/main/res/drawable-nodpi/road_haven_icon.png` | 같은 생존자·보리·트럭을 그린 Android 앱 아이콘 |

투명한 그림 묶음은 런타임에 각 그림의 영역만 잘라 사용합니다. 캐릭터와 동물은 발 위치를 기준으로 그리므로 포즈가 바뀌어도 바닥에 서 있습니다. 걷기·작업·공격에는 서로 다른 그림과 움직임, 그림자와 효과를 함께 사용합니다.

확장 가능한 데크는 실제로 크기가 변하는 기하 위에 그림의 재질을 입힙니다. 텃밭의 선택·성장 상태와 작업 위치는 게임 상태에서 계산하며, 배경 그림만 바꾸는 방식으로 동작을 대신하지 않습니다. 모든 그림과 글꼴은 APK에 포함됩니다.

UI는 크림색 패널, 금색 테두리와 초록색 강조를 사용합니다. 주요 행동에는 아이템 그림과 버튼 아래의 짧은 제목을 함께 표시합니다. 미세한 닫기·뒤로·설정 같은 보조 표시는 글자가 잘 읽히도록 단순한 금색 선으로 표현합니다.
