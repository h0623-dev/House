# 화면 자동 맞춤

v0.54는 기종명이나 물리 해상도 대신 실제 CSS 화면 크기와 안전 영역을 사용합니다. 폴드의 접기·펼치기, 창 크기·회전, 전체 화면 전환과 브라우저 주소창 변화에 맞춰 재배치합니다. 전체 게임을 확대하거나 축소하는 CSS zoom·회전 transform은 사용하지 않아 지도 터치 좌표를 유지합니다.

한글은 기존에 포함된 Noto Sans KR 글꼴을 우선합니다. 짧은 버튼 이름은 한 줄을 유지하고, 퀘스트 제목이 길면 말줄임으로 표시합니다. 퀘스트 전체 내용은 해당 카드를 눌러 볼 수 있습니다. 글자 크기와 버튼 간격은 화면의 짧은 변을 기준으로 제한된 범위에서 조정하며, 주요 터치 영역은 44~48 CSS 픽셀을 유지합니다. 충분히 넓은 가로 화면은 상단 정보를 한 줄에, 좁은 창에서는 두 줄에 배치합니다.

농사·시설·장식·동물·건설 패널은 사용 가능한 화면 높이 안에서 스크롤하고 닫기 버튼을 상단에 남깁니다. 생활·상점 등의 카드 열 수는 해당 창의 폭에 맞춰 바뀝니다. 이름 입력으로 키보드가 올라오면 게임의 기준 크기는 유지하고 입력 팝업에만 보이는 영역의 높이·위치를 적용합니다.

웹 UI 변경은 서명된 콘텐츠 패치로 기존 **로드헤이븐 가로** 앱에도 제공됩니다. v0.54 APK는 Android WebView의 독립적인 텍스트 확대를 100%로 맞추고 화면 밀도·시스템 글꼴 크기 변경을 같은 Activity에서 처리합니다. 이 네이티브 설정은 콘텐츠 파일만으로 바뀌지 않으므로 APK를 한 번 업데이트해야 적용됩니다.

구현은 `src/game-viewport.ts/css`, `src/adaptive-hud.css`, `src/adaptive-panels.css`, Android의 `MainActivity.java`와 `AndroidManifest.xml`에 있습니다. 기종별 실기기·브라우저 플레이 테스트 기록이 아니라 변경된 동작과 범위에 대한 안내입니다.
