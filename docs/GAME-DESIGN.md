# 로드헤이븐: 트럭 위의 우리집

## 게임 방향

2187년 대한민국의 좀비 도로에서 거대한 트럭을 이동식 마을로 키우는 모바일 생활·건설 게임이다. 귀여운 남녀 생존자와 반려견 보리가 농사와 탐색을 하고, 모은 재료로 데크를 확장해 생산 시설을 배치한다. 그림과 캐릭터는 기존의 원본 애니메이션 화풍을 유지한다.

사용자가 제시한 쿠키런 킹덤·아쿠아랜드·룰더스카이·클래시 오브 클랜에서 기대하는 공통 경험은 **공간을 넓히고 → 시설을 놓고 → 생산품을 받아 → 다음 시설을 만드는 성장**으로 해석한다. 특정 게임의 캐릭터·그림·맵·재화 체계를 복제하지 않는다.

## v0.8 구현 사양

- **건설과 배치:** 시설 목록에서 종류를 고른 뒤 트럭 위 빈 자리를 눌러 미리 본다. 건설을 확정할 때 목재·고철을 사용한다. 데크 레벨마다 시설 자리 2개를 열어 최대 12개까지 배치한다.
- **시설 성장:** 정수소·부엌부터 시작해 데크 확장으로 공방·보리 오두막·온실·감시소를 연다. 시설 레벨은 최대 3이며, 옮겨도 시설 ID·레벨·진행 중 생산을 유지한다.
- **생산과 수령:** 생산 시작 시 필요한 재료를 한 번 사용한다. 각 시설은 생산 중이거나 수령을 기다리는 한 묶음만 보유한다. 생산 완료 후 직접 수령하며, 같은 묶음의 보상을 다시 받을 수 없다. 레벨에 따라 투입량과 생산량이 함께 증가한다.
- **생활과 전투:** 기존의 6종 씨앗, 연속 심기·물 주기·수확, 벌목·탐색, 3개 사냥 스테이지를 마을 성장에 연결한다. 농사 중 건설 메뉴로 이동하면 대기 작업을 정리하고 현재 밭의 작업을 한 번 마친 뒤 이동한다.
- **시간과 저장:** 생산은 기존 게임의 `totalMinutes`를 따른다. 실제 1초가 게임 2분이며, 앱을 닫으면 시간이 멈춘다. 생산 상태와 시설 위치를 기존 저장에 함께 보관한다. 이전 저장에는 무료 시설이나 추가 재료를 소급 지급하지 않는다.
- **게임 콘텐츠 자동 업데이트:** v0.8 APK를 한 번 설치한 뒤 호환되는 새 게임 콘텐츠는 앱에서 내려받아 자동 적용한다. 고정 공개 키로 서명된 원본 업데이트 정보와 파일 해시를 확인하고, 현재 Android 엔진에서 사용할 수 있는 버전만 적용한다. 작업과 전투가 끝난 트럭 홈에서 저장한 뒤 적용하며, 적용 중에는 입력과 게임 시간을 잠시 멈춘다. 적용 전 버전을 보관해 새 화면이 정상 시작하지 못하면 되돌린다.
- **Android 엔진 업데이트:** 네이티브 기능을 바꾸는 APK는 앱 안에서 내려받아 설치 화면으로 연결한다. APK의 SHA-256·패키지 ID·서명·버전 코드를 검증한다. 일반 Android 앱에서는 설치 확인과 최초의 이 출처 설치 허용이 필요하다. 첫 v0.8 설치와 엔진 교체를 무인 설치로 표현하지 않는다.

배치·생산·수령의 최종 동작과 업데이트의 실제 검증 범위는 해당 버전의 테스트 결과 및 [Android 배포 문서](ANDROID.md)에 기록한다. 다른 이용자의 마을 방문, 길드·PvP, 서버 저장, 유료 재화는 이 버전의 구현 범위에 포함하지 않는다.
