# iPhone 플레이와 자동 패치

[로드헤이븐 열기](https://h0623-dev.github.io/House/?v=0.29.0)를 iPhone의 Safari에서 실행합니다. 공유 버튼을 누르고 **홈 화면에 추가**를 선택한 뒤, 생긴 로드헤이븐 아이콘으로 플레이하세요. 게임의 설정 → 홈 화면에 추가하는 방법에서도 순서를 확인할 수 있습니다. 처음 이름을 정할 때에도 설치 안내를 펼칠 수 있습니다.

v0.29은 기력 자동 회복과 기본 전체 보기, 트럭에 어울리는 통행로를 적용합니다. 기본 시점은 전체 보기입니다. 1층에서는 트럭과 지상 도로·채집 현장·동물길을 함께 보여 주고, 2·3층에서는 선택한 층의 데크·시설·밭을 화면에 맞춥니다. 이동이나 작업을 시작해도 주인공을 크게 따라 확대하지 않습니다. 직접 드래그·핀치·확대 버튼으로 정한 시점은 유지하며, 기본 보기로 위치와 배율을 초기화할 수 있습니다. 농사 도구·시설 상세·건설 배치를 직접 열면 해당 작업용 시점을 사용합니다.

기력은 실제 시간 20초마다 1씩, 1분에 3씩 자동으로 회복되며 최대 100입니다. 공통 2배 게임 속도와 별개로 전투·일시정지·오프라인 중에도 같은 실제 시간을 계산합니다. 다음 회복까지의 남은 초를 확인할 수 있으며 회복을 위해 식량이나 물을 쓰지 않습니다. 함께 쉬기는 생존자와 동물의 체력·기분을 돌보며 기력을 즉시 지급하지 않습니다. 처음 패치를 적용하는 옛 저장은 그 시각부터 회복을 시작하고 지난 부재 시간을 임의로 보상하지 않습니다.

동물 전용 길을 트럭 옆의 짧은 동선으로 줄이고, 동물길과 주인공 사다리를 트럭의 목재·금속 색상에 맞게 다시 그립니다. 주인공은 사다리, 동물은 전용 길로 트럭과 도로를 오갑니다. 전용 문은 주인공이 실제로 걸어가 조작한 뒤 열림·닫힘을 저장합니다. 문을 닫으면 새 통행을 멈추고 이미 건너는 동물은 안전하게 이동을 마칩니다. 이전 저장의 문 기록이 없으면 닫힌 상태로 이어갑니다.

넓어진 트럭 아래 도로를 걷고 작은 벌목장·고철 수거장·씨앗 풀밭·도로 샘터로 직접 이동해 물자를 모읍니다. 장소별 재채집 대기는 현재 속도에서 45·30·30·20초입니다. 수확물 보관함과 농산물 납품으로 여섯 작물의 씨앗 선택·물 주기·수확을 코인·경험치·다음 건설에 연결합니다. 자라는 밭에 식량 1·기력 2로 영양을 한 번 주면 수확량이 2 늘고 성장 시간은 바뀌지 않습니다. 종류별 수확물은 전체 식량 안에 포함되며 이전 식량은 임의의 작물로 바꾸지 않습니다. 기존 상점·동물·실제 남녀 의상과 무료 방향 변경·선택한 층만 표시하는 화면, 공통 2배 속도·기존 저장·실행 및 복귀 시 자동 패치는 이어갑니다. [공식 자료와 설계](research/v027-gameplay-design.md)를 참고하세요.

이 배포는 Safari의 홈 화면 웹 앱입니다. 앱스토어 등록이나 IPA 설치가 필요하지 않습니다. 최신 iOS를 권장하며 HTTPS·Service Worker·Cache API가 지원되어야 합니다. 설치 버튼이 없는 iPhone에서는 Safari의 공유 메뉴를 사용합니다.

## 업데이트와 저장

온라인으로 실행하거나 앱으로 돌아오면 새 패치를 자동 확인합니다. 변경된 파일을 준비하고 진행 상황을 저장한 뒤 새 화면을 불러옵니다. 농사·전투·건설 중이거나 창을 읽고 있으면 활동을 마치고 트럭 홈으로 돌아온 뒤 적용합니다. 여러 탭이 열려 있으면 다른 탭도 작업과 열린 창을 마쳐야 합니다. 닫힌 탭이 응답하지 않으면 현재 버전으로 계속 플레이하며 재시도합니다.

다운로드 실패·불완전한 파일·저장 공간 오류가 있으면 기존 버전을 유지합니다. 연결이 돌아오면 재시도합니다. 처음 온라인에서 모든 파일을 준비한 뒤에는 오프라인으로 다시 실행할 수 있습니다. 처음 파일 준비 후 한 번 다시 열면 오프라인 준비가 끝납니다. iOS가 웹 앱의 저장 공간을 정리하거나 사이트 데이터를 삭제하면 인터넷으로 파일을 다시 받아야 합니다.

진행 상황은 기기에 보관합니다. Safari 탭과 홈 화면 앱의 저장 영역은 iOS 버전·실행 방식에 따라 다를 수 있으며 Android 앱이나 다른 기기와 자동으로 공유되지 않습니다. 처음부터 홈 화면 아이콘으로 시작하는 것을 권장합니다. 홈 화면 아이콘 재설치는 일반 게임 패치에 필요하지 않습니다.

## 배포와 검증 범위

웹 배포의 `manifest.webmanifest`·`sw.js`·`web-update.json`·전체 정적 파일은 같은 릴리스로 게시합니다. 새 빌드의 worker가 파일별 크기·SHA-256을 검사하고 안전한 적용을 조율합니다. 구버전 탭이 참조하는 그림·폰트·해시된 JavaScript와 CSS는 서버에 유지합니다. 다른 주소·scope로 옮기면 기존 캐시와 저장이 이어지는 것을 보장하지 않습니다.

검증은 로컬 Chromium에서 실제 Service Worker와 iPhone 화면 크기·사용자 에이전트·홈 화면 실행 조건을 사용합니다. 설치 안내, 첫 설치, 오프라인 재실행, 실행 중 패치와 저장, 실패 복구, 여러 탭의 안전한 적용, Android와 단일 HTML 제외를 검사합니다. 실제 iPhone Safari와 iOS 홈 화면 설치는 이 환경에 기기와 WebKit이 없어 직접 검증하지 못했습니다. 세부 결과는 릴리스 검수 기록에 기록합니다.
