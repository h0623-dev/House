# iPhone 플레이와 자동 패치

[로드헤이븐 열기](https://h0623-dev.github.io/House/?v=0.18.0)를 iPhone의 Safari에서 실행합니다. 공유 버튼을 누르고 **홈 화면에 추가**를 선택한 뒤, 생긴 로드헤이븐 아이콘으로 플레이하세요. 게임의 설정 → 홈 화면에 추가하는 방법에서도 순서를 확인할 수 있습니다. 처음 이름을 정할 때에도 설치 안내를 펼칠 수 있습니다.

이 배포는 Safari의 홈 화면 웹 앱입니다. 앱스토어 등록이나 IPA 설치가 필요하지 않습니다. 최신 iOS를 권장하며 HTTPS·Service Worker·Cache API가 지원되어야 합니다. 설치 버튼이 없는 iPhone에서는 Safari의 공유 메뉴를 사용합니다.

## 업데이트와 저장

온라인으로 실행하거나 앱으로 돌아오면 새 패치를 자동 확인합니다. 변경된 파일을 준비하고 진행 상황을 저장한 뒤 새 화면을 불러옵니다. 농사·전투·건설 중이거나 창을 읽고 있으면 활동을 마치고 트럭 홈으로 돌아온 뒤 적용합니다. 여러 탭이 열려 있으면 다른 탭도 작업과 열린 창을 마쳐야 합니다. 닫힌 탭이 응답하지 않으면 현재 버전으로 계속 플레이하며 재시도합니다.

다운로드 실패·불완전한 파일·저장 공간 오류가 있으면 기존 버전을 유지합니다. 연결이 돌아오면 재시도합니다. 처음 온라인에서 모든 파일을 준비한 뒤에는 오프라인으로 다시 실행할 수 있습니다. 처음 파일 준비 후 한 번 다시 열면 오프라인 준비가 끝납니다. iOS가 웹 앱의 저장 공간을 정리하거나 사이트 데이터를 삭제하면 인터넷으로 파일을 다시 받아야 합니다.

진행 상황은 기기에 보관합니다. Safari 탭과 홈 화면 앱의 저장 영역은 iOS 버전·실행 방식에 따라 다를 수 있으며 Android 앱이나 다른 기기와 자동으로 공유되지 않습니다. 처음부터 홈 화면 아이콘으로 시작하는 것을 권장합니다. 홈 화면 아이콘 재설치는 일반 게임 패치에 필요하지 않습니다.

## 배포와 검증 범위

웹 배포의 `manifest.webmanifest`·`sw.js`·`web-update.json`·전체 정적 파일은 같은 릴리스로 게시합니다. 새 빌드의 worker가 파일별 크기·SHA-256을 검사하고 안전한 적용을 조율합니다. 구버전 탭이 참조하는 그림·폰트·해시된 JavaScript와 CSS는 서버에 유지합니다. 다른 주소·scope로 옮기면 기존 캐시와 저장이 이어지는 것을 보장하지 않습니다.

검증은 로컬 Chromium에서 실제 Service Worker와 iPhone 화면 크기·사용자 에이전트·홈 화면 실행 조건을 사용합니다. 설치 안내, 첫 설치, 오프라인 재실행, 실행 중 패치와 저장, 실패 복구, 여러 탭의 안전한 적용, Android와 단일 HTML 제외를 검사합니다. 실제 iPhone Safari와 iOS 홈 화면 설치는 이 환경에 기기와 WebKit이 없어 직접 검증하지 못했습니다. 세부 결과는 릴리스 검수 기록에 기록합니다.
