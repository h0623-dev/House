공식 Google Play가 제공한 이미지 **13장**을 내려받아 실제로 열었다. 모두 스토어 홍보 이미지이며 게임 화면을 포함하더라도 실제 플레이 동영상이나 영상에서 추출한 프레임은 아니다.

C3 원문에 포함된 `Build_Tab_1.png` 삽화를 정상 HTTPS로 요청했으나 **`clashofclans.inbox.supercell.com` CONNECT 403**이라 열지 못했다. 따라서 C3의 카메라·메뉴 동작 근거는 읽은 원문이며 이 삽화를 직접 봤다는 표현을 쓰지 않는다.

YouTube 검색은 정상 프록시/TLS 요청에서 **CONNECT 403**이었다. **이번에도 네 게임의 영상을 시청하거나 프레임을 추출하지 않았다.** 아쿠아랜드·룰더스카이의 첫 10분 플레이, 정확한 확장 비용·구획 수, 건설 시간과 자동화 조건은 미확인이다. 아쿠아랜드 스토어 이용자가 말한 레벨별 자동 생산이나 영웅 비용은 리뷰로만 읽었으며 공식 규칙으로 확정하지 않는다.

## 구현에 연결할 공개 개발 사례

D1의 핵심은 데이터와 실행 로직의 분리, 잘못된 필드·타입·값을 실행 전에 거부하는 검증이다. 로드헤이븐에는 동료 정의와 레벨·능력·기술 규칙을 한 곳에서 읽도록 하고, 편성 중복/해금/기술 소유자/HP 범위/참가자별 결과를 검증하는 방향이 적합하다. 이 때문에 JSON Schema 라이브러리를 반드시 새로 도입해야 하는 것은 아니다. 설명용 가상 쿠키 스킬과 데이터를 제품으로 가져오지 않는다.

D2는 아트·UI·모션·클라이언트가 같은 기획 의도를 확인하고 캡처·영상으로 피드백하는 과정을 직접 설명한다. 동료 네 종류를 늘리거나 데크를 넓힌 뒤 코드 검사만 통과시킬 것이 아니라, 작은 화면에서 크기·발 위치·동선·카드·시전 모션과 작업 중 화면을 함께 검수한다. 브라우저 자동화 검수와 실제 Android 기기 검수를 구별해 기록한다.

D3는 기기 프레임 속도에 따라 결과가 바뀌지 않도록 로직과 표현을 나누는 공개 원리다. 기존 3배 속도를 유지하면서 새 작업 시간·생산 시간·전투 기술이 실제 초로 일관되게 진행하는지 확인하는 근거로 사용한다. 글을 읽었다는 사실이 우리 게임에 결정론적 서버나 리플레이를 구현했다는 뜻은 아니다.

## 다음 검수의 통과 조건

- 편성에서 표시한 역할·HP·기술이 실제 전투와 같고, 쓰러진 동료가 기술을 쓰거나 비참가자가 보상·피해를 받지 않는다. 보상은 같은 전투에서 한 번만 지급한다.
- 기존 보리/나비의 HP/XP, 시설과 진행 중 생산, 씨앗·작물·재료·성장 보상을 그대로 이어간다. 새 한도를 옛 한도에 맞춰 자르거나 업데이트 보너스로 재화를 다시 지급하지 않는다.
- 건설은 이동/현장 작업/완료가 보이며 비용은 한 번만 사용한다. 취소·일시정지·앱 전환·농사 대기열과의 충돌을 확인한다.
- 시설 레벨 개선 전후 생산 시간과 산출량을 구별하고, 이미 진행 중인 생산의 시작/완료 시각을 근거 없이 다시 쓰지 않는다. 표시된 실제 초와 완료 시점이 일치한다.
- Lv.7/8에서 새 시설 13–16자리와 실제 추가한 밭 19–24칸을 보고 조작할 수 있다. 확장 설명만 늘고 바닥·배치 좌표가 그대로인 상태를 통과시키지 않는다.
- 360px 세로와 작은 가로에서 건설 목록·미리보기·확정 중에도 실제 트럭/선택 자리가 보인다. 드래그·핀치·목록 스크롤을 건설 확정이나 농사로 처리하지 않는다.

## 접근 기록과 남은 확인

원문 응답·정제 텍스트·이미지 원본·접근 URL/UTC/HTTP/SHA는 커밋하지 않는 `artifacts/research-v017/`에 보관했다. 참고 게임 이미지·코드는 제품 자산에 가져오지 않았다.

이번 런타임 상태는 running/current 관찰이며 HTTP 정책 적용 상태는 `unknown`으로 보고됐다. 실제 HTTPS 성공·실패를 따로 기록했다. 상속 프록시와 CA/TLS 검증을 유지했다. 쿠키런 공식 소개·YouTube·구 룰더스카이 사이트·현재 공식 `rts.joycity.com`·Clash 공식 삽화 호스트는 CONNECT 403이었다. 차단 목적지의 IP/다른 프록시/미러로 우회하거나 변화 없이 재요청하지 않았다. Supercell의 오래된 Village Edit URL은 도움말 홈으로 이동했으므로 해당 문서를 읽은 근거로 쓰지 않는다.

기존 환경 초안 목록을 읽어 보존한 뒤, 공식 출처가 명시한 **`rts.joycity.com`**과 **`clashofclans.inbox.supercell.com`**만 추가 저장했다. draft 저장은 runtime 정책 적용이나 publication 완료가 아니다. 새 영상 시청이나 공식 삽화 확인은 실제 접근 성공 후에만 기록할 수 있다. 이번 수정은 위에서 실제 확인한 원문·홍보 이미지와 자체 코드의 차이에 근거한다.
