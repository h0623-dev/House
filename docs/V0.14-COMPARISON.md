# v0.14 — 트럭 마을의 플레이 흐름 개편

사용자가 ‘각수’로 정한 쿠키런: 킹덤·아쿠아랜드: 크레이지 서바이벌·룰더스카이·클래시 오브 클랜과 로드헤이븐 v0.13의 차이를 조사하고, 화면과 마을 활동을 함께 고친다. 기능의 이름만 늘리면 생산품을 받아 다음 공간을 여는 재미와 조작의 명확성이 생기지 않는다.

## 실제 조사 범위

2026-10-09에 읽은 쿠키런: 킹덤 이용자 공략은 **생산→납품→재화→성장**의 목적을 설명한다. 같은 공략의 시설 개선 화면은 현재/다음 효과와 비용, 단일 확정 행동을 분명하게 나눈다. 클래시 오브 클랜의 2024-01-07 플레이어 연속 정지화면에는 생산시설 위 자원 말풍선, 가장자리 HUD, 건물에 연결된 새 기능 안내가 보인다.

공개 개발자료는 Devsisters의 일반 런타임 디버깅 메뉴와 저장소에 보관된 Unity UI/자산 도구 문서다. 특정 게임의 내부 설계서나 실제 사용된 구현이라는 증거로 표현하지 않는다. 아쿠아랜드·룰더스카이는 공개 앱 디렉터리에서 대상과 앱 식별자를 확인했으며 상세 공략·플레이는 확인하지 못했다.

현재 네트워크에서 YouTube·공식 소개·스토어의 정상 HTTPS 요청은 CONNECT 403으로 막혔다. **영상 시청·영상 프레임 분석·네 게임의 첫 10분 직접 플레이는 수행하지 못했다.** 실제 확인한 원문·정지화면·추론의 구분과 URL은 다음 문서에 기록한다.

- [쿠키런: 킹덤·클래시 오브 클랜 조사](research/kingdom-clash-v014.md)
- [아쿠아랜드·룰더스카이 조사](research/aqualand-rulesky-v014.md)

## v0.13에서 확인한 문제와 v0.14 변경

| 기존 동작·화면 | 플레이에 생기는 문제 | v0.14 변경 |
| --- | --- | --- |
| 상단 2줄과 지도 위 여러 도구, 큰 현재 목표 카드, 6개 하단 메뉴 | 마을보다 기능 선택이 먼저 보이고 같은 목적의 버튼이 반복됨 | 마을을 크게 보여 주고 5개 하단 메뉴·마을 메뉴·현재 목표 한 줄·선택 대상의 작은 조작으로 정리 |
| 완료 시설의 ‘받기’를 눌러도 먼저 시설 시트가 열림 | 수령 의도를 다시 입력해야 함 | 지도 자원 말풍선에서 바로 수령, 유휴 시설은 생산 시작에 바로 접근 |
| 시설 상태가 9px 텍스트와 얇은 막대에 집중 | 무엇을 생산하고 무엇을 받을 수 있는지 찾기 어려움 | 시설 위 생산·남은 초·완료 자원/수량을 표시하고 재료 부족은 생산 시 안내 |
| 생산품을 얻은 뒤 건설 외의 짧은 목적이 약함 | 농사·생산을 반복할 이유가 덜 보임 | 마을 의뢰에 보유/요구 물자와 보상을 함께 표시해 생산·납품·성장을 연결 |
| 장시간 왕복 작업 동안 시설·작물 시계도 멈춤 | 한 활동을 기다리는 동안 다른 마을의 성장이 정지 | 작업 중 작물·시설 시간을 진행하고 부재 시간을 최대 210초 반영. 수령은 직접 수행 |
| 확장 비용은 보이지만 다음 단계의 결과를 한 번에 비교하기 어려움 | 재료를 써서 무엇을 얻는지 판단하기 어려움 | 확장 창에 현재/다음 시설 자리·밭 수용량, 기본 밭 1칸과 새 시설 해금·자리 타일 표시 |

위 표는 조사에 따른 이번 변경이며, 참고 게임의 모든 동작을 복제했다는 뜻이 아니다. 최종 변경 동작은 [변경 기록](../CHANGELOG.md), 진행 규칙은 [게임 설계](GAME-DESIGN.md)에 기록한다. 실제 브라우저 검수와 공개 배포 검증은 생성된 해당 버전 검수 보고서로 확인한다.

지도상의 실제 확장 영역을 덧그리는 미리보기는 조사에서 권고한 후속 개선이다. 이를 이번에 구현했다고 주장하지 않는다. 시설·작물은 애니메이션 작업 중에 실제 마을 시간으로 진행하며, 완료 순간에 활동 시간을 다시 더하지 않는다. 일시정지 중 완료도 마을 시간을 진행하지 않는다.

## 유지할 제품 기준

배경은 미래 대한민국의 좀비 도로와 거대한 트럭 마을이다. 남녀 생존자·보리·6종 씨앗·연속 농사·실제 벌목·3개 전투 스테이지·24개 성장 목표·재료를 쓰는 밭/데크 확장을 이어간다. 기존 마을의 재료·씨앗·시설·작물·보상 기록을 업데이트만으로 새로 지급하지 않는다. 지도 드래그와 핀치는 물자 수령이나 농사 작업으로 오인하면 안 된다.

각 시설은 생산 중이거나 수령을 기다리는 한 묶음을 보유한다. 이번 범위에 다중 생산 대기열, 새 동료 편성, 서버 계정, PvP, 길드, 이용자 간 방문은 포함하지 않는다. 참고 게임 정지화면과 공략만으로 확인하지 못한 내부 시간·경제 규칙을 단정하지 않는다.

v0.14의 Android 버전 코드는 14이며, 콘텐츠 패치의 네이티브 호환 범위는 8–14다. 호환 앱은 게임 시작 때 서명된 콘텐츠를 적용하고 기존 저장을 이어간다. 별도 APK는 새 설치·오래된 엔진 전환에 사용한다. 실제 Android 기기의 자동 적용·설치·롤백은 브라우저의 모의 브리지 검사와 구별한다.
