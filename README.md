# 로드헤이븐: 트럭 위의 우리집

2187년 대한민국, 좀비로 가득한 도로에서 거대한 트럭을 집으로 가꾸는 모바일 생존·생활 게임입니다. 기존 게임의 자산이나 코드를 사용하지 않은 독자적인 모바일 플레이 버전입니다.

## 0.32.0에서 할 수 있는 일

도로와 숲의 낙엽길·야생화 초지·고철이 남은 자갈밭·바위 샘터가 하나의 손그림 풍경으로 이어집니다. 네 채집 구역의 굵은 둥근 도형과 같은 표지판을 없애고, 수집품을 서로 다른 지상 소품으로 표현합니다. 자원은 줄과 열에 맞추지 않고 흩어 놓으며 나무는 세 종류의 수관과 실제 발 위치를 사용합니다. 지상의 주인공·동물·자원은 발의 앞뒤 위치에 따라 겹쳐 보이고, 작업하는 주인공을 덮는 수관은 부드럽게 비쳐 보입니다. 좁은 가로 화면과 세로 전체 보기에서도 배경을 같은 세계 좌표로 이어 표시합니다.

트럭의 데크·차체·운전석·바퀴를 모두 포함한 지상 외곽을 이동 장애물로 적용합니다. 주인공과 동물은 차체 아래를 가로지르지 않고 트럭 바깥 도로로 돌아갑니다. 사다리와 동물 전용 경사로의 지상 출입구, 네 채집 장소는 확장한 데크에서도 차체 밖에 놓입니다. 트럭은 지상 이동 중에도 불투명하게 표시합니다.

지상 숲에는 독립된 나무 16그루와 두 동물이 나란히 지나갈 수 있는 숲속길이 있습니다. 고철·씨앗·샘물도 각 4곳에 놓이며 트럭을 확장해도 지상 위치는 바뀌지 않습니다. 채집 지도에서 구역을 크게 보고 원하는 대상을 누르거나 목록에서 하나씩 선택합니다. 베인 나무는 그루터기로 남고, 모든 채집물은 작업을 마친 시각부터 실제 180초 뒤 각각 재생됩니다. 일시정지·재실행·오프라인에서도 이 시간이 이어집니다.

이번 지상 아트와 화면의 구현·검증 범위는 [v0.32 검수 기록](docs/research/v032-playtest-results.md)에 기록합니다. 이전 숲길·개별 채집·독립 재생의 구현과 검증 범위는 [v0.31 검수 기록](docs/research/v031-playtest-results.md)에 기록합니다. 이전 지상 이동의 검증 범위는 [v0.30 검수 기록](docs/research/v030-playtest-results.md)에 보존합니다.

이전 v0.29의 기력 회복·전체 보기·트럭 통행로와 당시 검증 범위는 [v0.29 검수 기록](docs/research/v029-playtest-results.md)에 보존합니다. 이전 버전의 ‘트럭 아래 도로’ 설명은 당시 동작을 기록한 것입니다.

기본 시점은 전체 보기입니다. 1층에서는 트럭과 지상 도로·채집 현장·동물길을 함께 보여 주고, 2·3층에서는 선택한 층의 데크·시설·밭을 화면에 맞춥니다. 이동이나 작업을 시작해도 주인공을 크게 따라 확대하지 않습니다. 직접 드래그·핀치·확대 버튼으로 정한 시점은 유지하며, 기본 보기로 위치와 배율을 초기화할 수 있습니다. 농사 도구·시설 상세·건설 배치를 직접 열면 해당 작업용 시점을 사용합니다.

기력은 실제 시간 20초마다 1씩, 1분에 3씩 자동으로 회복되며 최대 100입니다. 공통 2배 게임 속도와 별개로 전투·일시정지·오프라인 중에도 같은 실제 시간을 계산합니다. 다음 회복까지의 남은 초를 확인할 수 있으며 회복을 위해 식량이나 물을 쓰지 않습니다. 함께 쉬기는 생존자와 동물의 체력·기분을 돌보며 기력을 즉시 지급하지 않습니다. 처음 패치를 적용하는 옛 저장은 그 시각부터 회복을 시작하고 지난 부재 시간을 임의로 보상하지 않습니다.

주인공은 실제 사다리, 동물은 전용 경사로로 트럭과 바깥 도로를 오갑니다. 동물길과 사다리의 목재·금속 화풍은 이어갑니다. 전용 문은 주인공이 실제로 걸어가 조작한 뒤 열림·닫힘을 저장합니다. 문을 닫으면 새 통행을 멈추고 이미 건너는 동물은 안전하게 이동을 마칩니다. 이전 저장의 문 기록이 없으면 닫힌 상태로 이어갑니다.

트럭 바깥 도로로 내려가 빈 공간을 자유롭게 걷습니다. 원하는 나무·고철 더미·씨앗 풀·샘물 웅덩이를 선택하면 주인공이 차체와 장애물을 피해 직접 이동하고 작업합니다. 한 대상에서 목재·고철·씨앗·물을 각각 18·9·3·12개 모으며, 채집 후에는 그 자리에 머물러 다음 대상을 고릅니다. 나무 하나를 베어도 다른 나무는 계속 채집할 수 있습니다. 작업을 마친 각 대상의 재생 시간은 게임의 2배 속도와 별개로 실제 180초입니다. 씨앗 풀마다 다른 품종을 모으고 이후 채집에서도 여섯 품종을 순환합니다.

직접 수확한 당근·감자·토마토·옥수수·딸기·호박은 전체 식량 안에서 종류별로 기록합니다. 농산물 납품에서 요청한 작물·보유량·코인·경험치·건설 재료를 보고, 씨앗 준비→심기→물 주기→수확→배달→다음 투자로 이어갑니다. 여섯 품종의 요청을 순서대로 반복하며 납품한 작물과 같은 양의 식량을 한 번 사용합니다. 수확물은 별도의 추가 식량이 아니며, 이전 저장의 식량은 임의의 작물로 바꾸지 않고 그대로 보관합니다.

자라는 밭에 영양을 한 번 주면 식량 1개·기력 2를 사용하고 그 심기의 수확량이 2개 늘어납니다. 물 주기와 영양을 구별하며 영양은 성장 시간을 앞당기거나 심은 시점을 바꾸지 않습니다. 휴식·판매·영양 주기로 식량을 쓸 때 일반 식량을 먼저 사용하고, 부족하면 보관함의 당근→감자→토마토→옥수수→딸기→호박 순서로 사용합니다. 같은 수확물을 여러 용도로 중복 지급하지 않습니다.

‘각수’ 네 게임과 레알팜의 공식 소개·발행자 화면에서 수집·농사·생산이 생활 공간의 성장으로 이어지는 흐름을 확인했습니다. 실제 확인한 자료와 이번 설계는 [v0.27 게임플레이 조사](docs/research/v027-gameplay-design.md)에 기록합니다. 게임 영상·직접 플레이·비공개 개발 문서를 조사한 결과로 표현하지 않습니다.

장식 상자와 별도 주택을 제거한 트럭 생활은 이어갑니다. 트럭 상점의 씨앗·애완동물·의상·판매 탭에서 식량·목재·고철을 팔아 게임 코인을 모으고 씨앗이나 동료·의상을 구매합니다. 상품 그림·보유량·가격과 거래 후 수량을 보고 확정합니다. 실제 돈을 받는 결제는 없습니다.

당근·감자·토마토·옥수수·딸기·호박 씨앗은 1·5·10개씩 구매하며, 씨앗 인벤토리와 연속 심기로 이어집니다. 강아지·고양이와 데크 성장으로 이미 만난 동료는 다시 구매하지 않습니다. 아직 해금하지 않은 토끼·여우·멧돼지·부엉이는 코인으로 먼저 만나 실제 동료 편성·전투에 사용할 수 있습니다. 기존 동물의 체력·경험치와 편성은 유지합니다.

‘텃밭 나들이’·‘도로 여행자’·‘숲속 탐험가’ 의상을 한 번 구매하면 남녀 캐릭터 모두 사용할 수 있습니다. 모자·앞치마·스카프·배낭은 캐릭터의 실제 이동·계단·농사·채집 모습과 초상화에 적용하며, 남녀의 착용 선택은 각각 저장합니다. 의상은 공통 2배 속도를 바꾸지 않습니다.

레알팜의 [공식 소개와 공개 화면](https://play.google.com/store/apps/details?id=kr.neogames.realfarm&hl=ko)에서 농사·펫·장비·꾸미기의 흐름을 참고했습니다. 실제로 확인한 자료와 상점 설계의 근거는 [v0.26 상점 설계](docs/research/v026-realfarm-shop-design.md)에 기록하며, 그림과 상품 가격은 이 게임의 독자적인 구상입니다.

트럭 자체를 집으로 삼도록 데크 위의 별도 주택과 집 배치 메뉴를 없앴습니다. 시설 위 말풍선에는 해당 시설이 만드는 물·식량·목재·고철·씨앗을 손그림 생산품으로 표시합니다. 생산 전·생산 중·수령 대기 상태에서도 같은 생산품 그림을 사용하며, 남은 초와 완성 수량으로 상태를 확인합니다. 시설을 막 지은 뒤에도 무엇을 만드는지 바로 볼 수 있습니다.

시설의 바닥 그림과 밭고랑은 트럭 데크의 두 축에 맞춥니다. 시설은 두 방향으로, 밭고랑은 직각으로 무료 변경하고 저장합니다. 방향을 바꿔도 건물의 자리와 충돌 범위, 밭의 작물·물 주기, 진행 중인 생산 시각은 그대로입니다.

층간 높이는 176에서 264로 50% 늘렸습니다. 1·2·3층 버튼으로 선택한 층만 표시하므로, 1층에서 작업할 때 2·3층 건물과 바닥이 화면을 가리지 않습니다. 다른 층의 건물과 생산은 저장한 상태로 이어가고, 캐릭터와 동물은 실제 연결 계단으로 이동합니다.

게임 시작 화면을 기존 트럭 마을의 손그림 자산으로 꾸몄습니다. 실제 콘텐츠 확인·다운로드·적용 진행을 표시하고, 느린 연결에서 현재 버전으로 시작하는 기능과 동작 줄이기 설정을 이어 갑니다.

생활 공간에 맞춘 마을 시점에서 지금 할 일과 다음 투자를 확인합니다. 마을 운영판은 완성된 생산품·진행 중 생산·투입 재료를 먼저 보여 주며, 명시적으로 선택한 “받고 다시 생산”은 한 묶음을 수령하고 다음 원가를 한 번 사용합니다. 납품 보상은 시설 개선·데크·층 증축으로 이어지고, 필요한 재료와 준비 행동을 현재 저장에서 안내합니다. 건물 Lv.2–5에는 설비·천막·화단과 완성 문장이 추가됩니다. 지도는 전체 보기를 기본으로 사용하며 직접 확대·축소하고 기본 보기로 되돌릴 수 있습니다.

완성된 시설을 선택해 무료로 재배치합니다. 건물 전체가 난간 안에 들어오는 자리만 선택할 수 있습니다. 동물이 지나는 자리도 설치를 확정할 수 있으며, 새 건물과 겹치는 동물만 안전한 빈 공간으로 순간이동합니다. 주인공이나 다른 건물과 겹치는 배치는 계속 제한합니다. 데크 4단계에서 목재 100·고철 50으로 2층, 7단계에서 160·80으로 3층 플랫폼을 추가합니다. 층 버튼으로 지도를 바꾸며 캐릭터와 반려동물은 연결 계단을 이용합니다. 시설을 옮겨도 레벨과 생산 완료 시점은 유지합니다. 하늘에는 여러 새가 각자 날갯짓하거나 활공합니다.

빈 바닥을 터치하면 캐릭터가 원하는 자리로 걸어갑니다. 이동 중 다른 자리를 누르면 방향을 바꾸고, 주인공은 트럭과 도로 사이를 사다리로 오갑니다. 동물은 열린 전용 경사로를 사용하며 강아지와 고양이는 발걸음에 맞춰 몸과 꼬리가 움직입니다. 공통 2배 속도와 기존 마을·생산의 저장 정보는 유지합니다.

- 강아지 보리·고양이 나비·토끼 루루·여우 루비·멧돼지 도도·부엉이 모모 중 최대 3마리 편성
- 방어·빠른 공격·치유·원거리·방패·범위 마법 역할과 고유 기술, 자동 공격·AUTO·3구역/3웨이브 전투
- 출전 동료별 체력·경험치·최대 10레벨 성장, 함께 쉬며 회복
- 시설 6종을 Lv.5까지 개선하며 생산량·생산 시간·필요 재료를 전후 비교
- 동료의 쉼터 레벨당 공격 +4%, 관측소 레벨당 받는 피해 −3%의 실제 전투 효과
- 시설 생산의 게임 시간은 원래 기간의 Lv.1 절반·Lv.5 ¼로 개선; 진행 중인 옛 생산은 완료 시점 유지
- 밭·시설을 피해 걷는 터치 이동, 실제 현재 위치에서 시작하고 돌아오는 농사·채집·시설 작업
- 마을을 가리지 않는 하단 건설 목록, 빈 자리 강조·시설 미리 보기·별도 확정·무료 자리 이동
- 맵 위에 새 데크 영역을 표시하고 확장 비용을 확인한 후 확정
- 데크 8단계·층마다 시설 16자리(총 48자리)·밭 최대 24칸으로 공간과 성장 확장
- 8챕터·32개 성장 목표, 생산→납품→건설→동료 성장으로 이어지는 보상
- 씨앗 6종 인벤토리와 연속 심기·물 주기·영양·수확, 품종별 보관·농산물 납품, 확대·축소·화면 이동
- 미래 대한민국의 좀비 도로와 거대한 트럭 마을, 같은 손그림 화풍의 남녀 생존자·동물
- 기존 마을·밭·동료·생산 작업·성장 보상 기록을 이어가는 기기 저장
- 네이티브 엔진 8–31에서 게임 실행 시 서명된 콘텐츠 자동 패치, 새 설치용 APK 제공

비교 게임의 공식 소개·홍보 화면·공략·공개 개발자료에서 확인한 차이와 설계 근거는 [v0.17 여섯 시스템 비교](docs/V0.17-SYSTEMS-COMPARISON.md)에 기록했습니다. 영상과 비공개 개발 문서는 확인하지 못했습니다.

마을 의뢰에서 물·식량·목재를 이웃 트럭에 보내고 목재·고철·경험치를 받습니다. 현재 보유량과 필요한 물자, 보상, 생산·농사·채집으로 물자를 모을 안내를 함께 확인합니다. 세 요청을 순서대로 반복하며 납품을 실제로 완료한 기록만 저장합니다. 같은 요청을 두 번 수령하거나 창을 열기만 해서 물자를 받지 않습니다.

처음 씨앗 심기를 누르면 6종의 보유량·성장 시간·수확량이 있는 인벤토리가 열립니다. 씨앗을 고른 뒤 원하는 빈 밭들을 연달아 누르거나 드래그하고, 모두 심기도 사용할 수 있습니다. 고른 씨앗은 기억하므로 다음에는 심기 이어하기로 돌아오고, 씨앗 바꾸기로 인벤토리를 다시 엽니다. 물 주기·수확 버튼은 가능한 밭을 순서대로 모두 돌보고 선택한 도구를 유지합니다. 작업 중 창고·건설 목록·마을 화면을 둘러봐도 예약한 농사는 이어집니다. 씨앗·도구를 바꾸거나 작업 종료를 누르면 대기 중인 작업을 취소하고 진행 중인 한 밭은 마저 끝냅니다. 기존 저장의 씨앗은 같은 수량의 당근 씨앗으로 이어지며 도로의 씨앗 풀밭에서 여섯 종류를 순서대로 3개씩 모을 수 있습니다.

마을 메뉴의 ‘밭 확장’을 누르면 한 칸을 더 만드는 데 필요한 재료와 현재 데크의 농사 공간을 확인합니다. 처음에는 3칸이며, 데크를 확장할 때 기존과 같이 밭 1칸이 함께 생깁니다. 추가 개간으로 데크 단계의 3배까지 늘릴 수 있어 8단계에서는 최대 24칸을 사용할 수 있습니다. 기존 작물·물 주기 상태·씨앗·시설·성장 목표는 이어집니다.

건설 메뉴에서 시설을 고르고 트럭 위 빈 자리를 눌러 미리 본 뒤 건설을 확정합니다. 시설 위 생산 말풍선을 눌러 바로 생산을 시작하고, 완료된 자원·수량 말풍선을 눌러 생산품을 바로 수령합니다. 시설 본체를 선택하면 작은 조작판에서 위치 이동·개선·교체를 할 수 있습니다. 빗물 정수소·트럭 부엌·재활용 공방·동료의 쉼터·작은 온실·도로 감시소는 서로 다른 물자를 생산합니다. 데크 확장마다 건설 자리 두 개가 더 열리고, 2·3단계에는 새 시설이 열립니다. 생산·수령 목표는 저장됩니다.

주인공이 농사·채집을 하는 동안 작물·시설 시간은 계속 흐르고 마을 메뉴를 읽거나 완료 생산품과 달성 목표 보상을 수령할 수 있습니다. 작업 완료 때 마을 시간을 한 번 더 더하지 않으며, 일시정지한 동안 완료되어도 생산 시계는 진행하지 않습니다. 이미 예약한 농사 물자를 다른 행동에서 소비하지 않도록 신규 생산·시설 개선·의뢰 납품은 현재 작업을 마친 뒤 실행합니다.

남은 생산 시간과 작물 성장 시간은 실제 플레이 속도에 맞춘 초 단위로 표시합니다. 예를 들어 기존 게임 시간 76분은 19초로 보입니다. 씨앗 인벤토리의 성장 시간과 사냥의 예상·경과 시간도 초로 확인할 수 있습니다. 공통 2배 속도를 적용하며 기존 저장의 게임 분과 완료 시점은 유지합니다.

홈의 현재 목표 한 줄을 누르면 필요한 활동으로 바로 이동하거나 달성 보상을 받습니다. 자세한 현재 목표와 전체 32개 목표는 마을 메뉴의 성장 목표에서 확인합니다. 미리 달성한 활동도 기록되며 보상은 순서대로 한 번씩 받습니다. 이전 저장의 농사·탐색·생산·시설·확장 실적은 유지합니다. 저장을 불러오거나 목표 목록을 여는 것만으로 새 보상을 지급하지 않습니다.

시설 교체에는 새 시설의 기본 건설 재료를 사용하며 이전 재료는 돌려받지 않습니다. 위치는 유지하고 새 시설은 Lv.1에서 시작합니다. 생산 중이거나 받을 물자가 남아 있으면 먼저 수령해야 합니다. 지금까지 건설한 시설 종류와 서로 다른 시설을 개선한 실적은 교체 후에도 남으므로, 기존 마을의 모든 자리가 차 있어도 성장 목표를 이어갈 수 있습니다. 마을 성장 방향과 네 비교 게임의 실제 참고 범위·확인하지 못한 자료는 [v0.14 비교 문서](docs/V0.14-COMPARISON.md)와 [게임 설계 문서](docs/GAME-DESIGN.md)에 기록했습니다.

캐릭터는 빈 바닥을 톡 눌러 이동합니다. 밭·건물은 해당 활동을 선택하며, 작업 중에는 작업을 마친 뒤 이동할 수 있습니다. 지도는 빈 공간을 한 손가락으로 끌어 이동합니다. 농사 중 밭에서 시작하는 쓸기는 연속 작업으로 유지하며, ‘지도 조작’을 펼쳐 ‘화면 이동’을 켜면 밭 위에서도 작업 없이 화면만 움직입니다. 이동 모드를 다시 누르거나 농사 도구를 고르면 작업으로 돌아옵니다. 수동으로 움직인 시점은 작업 중에도 유지되고, 지도 조작의 기본 보기 또는 하단 우리 트럭·농장 메뉴로 카메라를 되돌립니다. 두 손가락을 벌리거나 오므려 확대·축소하고, 100% 기본 보기 버튼으로 위치와 배율을 초기화합니다. 농사·벌목·채집 중에도 사용할 수 있고, 두 손가락 조작은 밭 작업을 새로 예약하지 않습니다. 캐릭터는 실제 경로 거리에 맞춰 걷고 사다리에서는 더 천천히 이동합니다. 도로의 장소를 누르면 해당 현장으로 이동해 채집·벌목 모션을 마친 뒤 한 번만 자원에 반영됩니다. 작업을 마치면 그 장소의 재채집 대기가 시작됩니다. 사냥은 별도 전투 화면에서 진행되며 승리 보상은 귀환할 때 한 번만 지급합니다. 앱을 종료한 원정은 재실행 시 보상 없이 복구됩니다. 자유 조이스틱 이동과 멀티플레이는 포함하지 않습니다. 앱을 잠시 닫았다 돌아오면 마지막 유효 저장 시점부터 최대 105초의 실제 경과 시간을 마을 시계에 반영합니다. 기력은 이 마을 성장 한도와 별개로 마지막 회복 저장부터 실제 경과 시간을 계산해 최대 100까지 회복하며, 남은 20초 미만의 시간도 이어갑니다. 성장한 작물과 완료 생산품은 직접 수령하며, 시간 진행 중 자정을 넘으면 기존 식량 소비와 좀비 피해도 적용됩니다. 게임과 글꼴은 APK에 포함되어 기본 플레이에 인터넷이 필요하지 않습니다. 업데이트 확인과 다운로드에는 인터넷이 필요합니다.

## iPhone에서 플레이

[게임 열기](https://h0623-dev.github.io/House/?v=0.32.0)를 iPhone의 Safari에서 엽니다. **공유 → 홈 화면에 추가** 후 생긴 로드헤이븐 아이콘으로 실행하세요. 설정의 ‘홈 화면에 추가하는 방법’에서도 안내를 볼 수 있습니다.

온라인으로 실행하거나 게임으로 돌아오면 새 패치를 자동 확인합니다. 필요한 파일을 모두 준비하고 진행 상황을 저장한 뒤 적용하므로, 일반적인 게임 업데이트마다 다시 설치할 필요가 없습니다. 농사·전투 중에는 활동을 마치고 트럭 홈으로 돌아온 뒤 적용합니다. 다운로드에 실패하면 기존 버전으로 계속 플레이하며 다시 연결되면 재시도합니다.

첫 실행에서 파일 준비가 끝난 뒤에는 오프라인으로도 다시 실행할 수 있습니다. iOS가 저장 공간을 정리하면 재다운로드가 필요합니다. 진행 상황은 기기에 보관되며 Safari 탭·홈 화면 앱·Android 사이에 자동 공유되지 않습니다. 처음부터 홈 화면 아이콘으로 시작하는 것을 권장합니다. [iPhone 안내와 검증 범위](docs/IOS.md)를 참고하세요.

## Android에서 플레이

새 설치 및 구형 앱 전환용 APK: `artifacts/road-haven-0.32.0-debug.apk` (Android 버전 코드 32). [APK 다운로드](https://raw.githubusercontent.com/h0623-dev/House/gh-pages/downloads/road-haven-0.32.0-debug.apk).

**v0.8 이상 앱은 이번 게임 업데이트를 받을 때 APK를 다시 설치할 필요가 없습니다.** 게임 실행 시 호환 콘텐츠를 자동으로 확인·적용합니다. v0.7 이전 앱에는 자동 콘텐츠 엔진이 없으므로 새 APK를 최초 한 번 설치해야 합니다. 같은 앱 ID·서명을 사용하므로 기존 앱을 삭제하지 않고 업데이트하면 마을을 유지합니다.

Android 6.0 이상과 최신 Android System WebView가 필요합니다. APK를 휴대폰에 옮겨 파일 앱에서 열고 설치를 승인합니다. 사용자가 해당 파일 앱/브라우저의 ‘알 수 없는 앱 설치’를 허용해야 할 수 있습니다. 테스트 버전은 개발용 서명이며 공개 스토어에 게시하지 않았습니다.

같은 서명 키로 설치하는 후속 APK는 게임 데이터를 유지합니다. 앱 삭제나 앱 데이터 초기화는 로컬 저장을 지웁니다. 현재 클라우드의 테스트 서명 키는 저장소 밖 `/workspace/.road-haven-signing/debug.keystore`에 보관됩니다. 정식 릴리스 서명으로 전환할 때는 테스트 APK와 서명이 다를 수 있습니다.

## 개발 실행

Node.js 22 이상을 사용합니다. 이 클라우드 작업은 이미 격리되어 있으므로 `/workspace/House`의 기존 체크아웃을 사용하며 별도 Git worktree를 만들 필요가 없습니다.

```bash
cd /workspace/House
npm ci
npm run dev
```

```bash
npm test              # 게임 로직·저장 데이터·업데이트 검증
npm run build         # TypeScript 검사 및 배포용 웹 빌드
npm run test:browser  # 개발 서버가 실행 중일 때 모바일 플레이 검사
npm run test:systems  # 여섯 시스템·모바일 배치·성장·속도 검사
npm run test:animals  # 동물별 체력·기술·성장·휴식·승리·패배·철수 검사
npm run test:mobile   # 실제 시간·모바일 터치로 벌목·회복·농사·사냥 검사
npm run test:seeds    # 씨앗 선택·연속 심기·작물별 저장 검사
npm run test:farm     # 연속 물 주기·수확·드래그·도구 변경 검사
npm run test:settlement # 건설·배치·생산·수령·시설 저장 검사
npm run test:growth   # 성장 목표·보상 수령·바로가기·이전 저장 검사
npm run test:startup  # 게임 시작 자동 패치·오프라인·기존 저장·연결 복구 검사
npm run test:pwa      # 실제 웹 자동 패치·오프라인 재실행·다중 탭 저장 검사
npm run test:scene    # 실제 핀치·줌·사다리·채집 동작과 완료 시 자원 반영 검사
npm run test:pan      # 한 손가락 화면 이동·밭 작업 분리·카메라 유지 검사
npm run test:farm-expand # 유료 밭 확장·비용·잠금·확장한 밭의 농사·저장 검사
npm run android:debug
```

브라우저 테스트는 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 변경할 수 있습니다. 서버 주소는 `TEST_BASE_URL`로 변경할 수 있습니다. 개발 중 HMR이 전체 플레이 검사를 중단할 수 있으므로 최종 검증에는 빌드된 정적 서버를 권장합니다. 전체 플레이 검사는 브라우저 시계를 제어하고, 터치·씨앗 검사는 실제 시간으로 작업을 진행합니다. 빌드 도구가 없는 클라우드에서는 먼저 `bash scripts/setup-android-cloud.sh`를 실행합니다. Android JDK/SDK 준비, 공식 아티팩트 검증, SDK 라이선스 수락을 수행합니다.

## APK 업데이트

`main` 푸시마다 GitHub Actions가 테스트와 APK 빌드를 실행하고 결과를 artifact로 제공합니다. 소스는 `h0623-dev/House`의 `main`, 웹 배포 파일은 `gh-pages`에 게시합니다. Pages 활성화와 공개 접속 확인은 별도입니다.

0.8.0 이상 APK를 한 번 설치하면 이후 **호환되는 게임 코드·그래픽은 APK 설치 없이 자동 적용**됩니다. 앱 시작·복귀 시 `gh-pages/game-update.json`의 서명된 콘텐츠 정보를 확인하고 앱 전용 공간에 내려받습니다. 서명·파일 해시·네이티브 호환 버전을 검증한 뒤 게임 시작 화면에서 저장 후 자동 적용합니다. 시작 확인이 느리면 현재 버전으로 플레이할 수 있으며, 플레이 중 도착한 콘텐츠는 현재 활동을 마치고 안전한 홈에서 적용합니다. 같은 로컬 주소에서 실행하므로 저장 데이터를 유지하며, 새 콘텐츠 시작을 확인하지 못하면 다음 앱 시작에 이전 콘텐츠로 복구합니다.

Android 엔진이나 네이티브 기능 변경은 APK 업데이트가 필요합니다. 앱이 새 APK를 내부에서 자동 다운로드하고 파일 해시·앱 ID·서명·버전을 검증한 뒤 ‘설치하기’를 제공합니다. **Android의 마지막 설치 확인은 사용자가 진행합니다.** Android 8 이상에서 필요한 이 앱의 설치 허용도 앱 내 안내에서 설정할 수 있습니다. 외부 브라우저에서 APK 링크를 찾는 과정은 없습니다.

0.3.0부터 네이티브 버전 확인 주소는 `https://raw.githubusercontent.com/h0623-dev/House/gh-pages/update.json`입니다. 0.8 이전 앱에는 콘텐츠 업데이트 엔진이 없으므로 현재 0.32 APK를 한 번 설치해야 합니다. [콘텐츠 배포 안내](docs/CONTENT-UPDATES.md)와 [Android 배포 안내](docs/ANDROID.md)에 검증·배포 절차를 기록했습니다.

- `VITE_UPDATE_MANIFEST_URL`: 공개 HTTPS 버전 파일 주소
- `release-version.json`: 기본 Android 버전 코드
- `APP_VERSION_CODE`: 필요할 때 기본값을 재정의하는 증가하는 Android 버전 코드
- `ANDROID_KEYSTORE_*`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`: 정식 빌드의 보안 서명 설정

서명 키나 비밀번호를 소스 코드 또는 `VITE_` 변수에 넣지 마세요. 자세한 내용은 [docs/ANDROID.md](docs/ANDROID.md)에 있습니다.
