# 로드헤이븐

로드헤이븐의 공개 배포 저장소입니다. 개발 소스와 기획 원본은 별도의 비공개 저장소에서 관리합니다.

- [게임 실행](https://h0623-dev.github.io/House/)
- [APK 및 앱 업데이트 채널](https://github.com/h0623-dev/House/tree/landscape-releases)

## 배포 파일

| 브랜치 | 용도 |
| --- | --- |
| `gh-pages` | 웹 게임 실행 페이지와 웹 업데이트 정보 |
| `web-assets` | 게임 실행에 필요한 빌드된 코드·이미지·폰트 |
| `landscape-releases` | 서명 APK·콘텐츠 업데이트·서버 연결 주소 |
| `meeting-release` | 만남 서버 배포에 사용하는 번들 결과물 |

기존 이용자의 게임 주소와 앱 업데이트 경로는 유지됩니다. 이 저장소에 배포 파일이 공개되어 있다는 사실이 재사용·재배포 권한을 부여하지는 않습니다.

공개로 배포되는 실행 코드와 이미지는 이용자가 다운로드할 수 있습니다. 과거 공개 자료의 외부 복사본이나 GitHub 캐시까지 회수하는 것은 보장되지 않습니다.
