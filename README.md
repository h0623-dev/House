# 로드헤이븐: 트럭 위의 우리집

2187년 대한민국, 좀비로 가득한 도로에서 거대한 트럭을 집으로 가꾸는 모바일 생존·생활 게임입니다. 기존 게임의 자산이나 코드를 사용하지 않은 독자적인 모바일 플레이 버전입니다.

## 0.18.0에서 할 수 있는 일

- 강아지 보리·고양이 나비·토끼 루루·여우 루비·멧돼지 도도·부엉이 모모 중 최대 3마리 편성
- 방어·빠른 공격·치유·원거리·방패·범위 마법 역할과 고유 기술, 자동 공격·AUTO·3구역/3웨이브 전투
- 출전 동료별 체력·경험치·최대 10레벨 성장, 함께 쉬며 회복
- 시설 6종을 Lv.5까지 개선하며 생산량·생산 시간·필요 재료를 전후 비교
- 동료의 쉼터 레벨당 공격 +4%, 관측소 레벨당 받는 피해 −3%의 실제 전투 효과
- Lv.1 생산은 이전의 절반 시간, Lv.5는 이전의 ¼ 시간; 진행 중인 옛 생산은 완료 시점 유지
- 기존보다 2배 빠른 보행·사다리 이동과 짧고 읽을 수 있는 농사·채집·시설 작업 동작
- 마을을 가리지 않는 하단 건설 목록, 빈 자리 강조·시설 미리 보기·별도 확정·무료 자리 이동
- 맵 위에 새 데크 영역을 표시하고 확장 비용을 확인한 후 확정
- 데크 8단계·시설 16자리·밭 최대 24칸으로 공간과 성장 확장
- 8챕터·32개 성장 목표, 생산→납품→건설→동료 성장으로 이어지는 보상
- 씨앗 6종 인벤토리와 연속 심기·물 주기·수확, 확대·축소·화면 이동
- 미래 대한민국의 좀비 도로와 거대한 트럭 마을, 같은 손그림 화풍의 남녀 생존자·동물
- 기존 마을·밭·동료·생산 작업·성장 보상 기록을 이어가는 기기 저장
- 네이티브 엔진 8–18에서 게임 실행 시 서명된 콘텐츠 자동 패치, 새 설치용 APK 제공

비교 게임의 공식 소개·홍보 화면·공략·공개 개발자료에서 확인한 차이와 설계 근거는 [v0.17 여섯 시스템 비교](docs/V0.17-SYSTEMS-COMPARISON.md)에 기록했습니다. 영상과 비공개 개발 문서는 확인하지 못했습니다.

마을 의뢰에서 물·식량·목재를 이웃 트럭에 보내고 목재·고철·경험치를 받습니다. 현재 보유량과 필요한 물자, 보상, 생산·농사·채집으로 물자를 모을 안내를 함께 확인합니다. 세 요청을 순서대로 반복하며 납품을 실제로 완료한 기록만 저장합니다. 같은 요청을 두 번 수령하거나 창을 열기만 해서 물자를 받지 않습니다.

처음 씨앗 심기를 누르면 6종의 보유량·성장 시간·수확량이 있는 인벤토리가 열립니다. 씨앗을 고른 뒤 원하는 빈 밭들을 연달아 누르거나 드래그하고, 모두 심기도 사용할 수 있습니다. 고른 씨앗은 기억하므로 다음에는 심기 이어하기로 돌아오고, 씨앗 바꾸기로 인벤토리를 다시 엽니다. 물 주기·수확 버튼은 가능한 밭을 순서대로 모두 돌보고 선택한 도구를 유지합니다. 작업 중 창고·건설 목록·마을 화면을 둘러봐도 예약한 농사는 이어집니다. 씨앗·도구를 바꾸거나 작업 종료를 누르면 대기 중인 작업을 취소하고 진행 중인 한 밭은 마저 끝냅니다. 기존 저장의 씨앗은 같은 수량의 당근 씨앗으로 이어지며 탐색·벌목으로 다른 종류를 3개 묶음으로 모을 수 있습니다.

마을 메뉴의 ‘밭 확장’을 누르면 한 칸을 더 만드는 데 필요한 재료와 현재 데크의 농사 공간을 확인합니다. 처음에는 3칸이며, 데크를 확장할 때 기존과 같이 밭 1칸이 함께 생깁니다. 추가 개간으로 데크 단계의 3배까지 늘릴 수 있어 8단계에서는 최대 24칸을 사용할 수 있습니다. 기존 작물·물 주기 상태·씨앗·시설·성장 목표는 이어집니다.

건설 메뉴에서 시설을 고르고 트럭 위 빈 자리를 눌러 미리 본 뒤 건설을 확정합니다. 시설 위 생산 말풍선을 눌러 바로 생산을 시작하고, 완료된 자원·수량 말풍선을 눌러 생산품을 바로 수령합니다. 시설 본체를 선택하면 작은 조작판에서 위치 이동·개선·교체를 할 수 있습니다. 빗물 정수소·트럭 부엌·재활용 공방·동료의 쉼터·작은 온실·도로 감시소는 서로 다른 물자를 생산합니다. 데크 확장마다 건설 자리 두 개가 더 열리고, 2·3단계에는 새 시설이 열립니다. 생산·수령 목표는 저장됩니다.

주인공이 농사·채집을 하는 동안 작물·시설 시간은 계속 흐르고 마을 메뉴를 읽거나 완료 생산품과 달성 목표 보상을 수령할 수 있습니다. 작업 완료 때 마을 시간을 한 번 더 더하지 않으며, 일시정지한 동안 완료되어도 생산 시계는 진행하지 않습니다. 이미 예약한 농사 물자를 다른 행동에서 소비하지 않도록 신규 생산·시설 개선·의뢰 납품은 현재 작업을 마친 뒤 실행합니다.

남은 생산 시간과 작물 성장 시간은 실제 플레이 속도에 맞춘 초 단위로 표시합니다. 예를 들어 기존 게임 시간 76분은 약 13초로 보입니다. 씨앗 인벤토리의 성장 시간과 사냥의 예상·경과 시간도 초로 확인할 수 있습니다. 공통 3배 속도를 적용하며 기존 저장의 게임 분과 완료 시점은 유지합니다.

홈의 현재 목표 한 줄을 누르면 필요한 활동으로 바로 이동하거나 달성 보상을 받습니다. 자세한 현재 목표와 전체 32개 목표는 마을 메뉴의 성장 목표에서 확인합니다. 미리 달성한 활동도 기록되며 보상은 순서대로 한 번씩 받습니다. 이전 저장의 농사·탐색·생산·시설·확장 실적은 유지합니다. 저장을 불러오거나 목표 목록을 여는 것만으로 새 보상을 지급하지 않습니다.

시설 교체에는 새 시설의 기본 건설 재료를 사용하며 이전 재료는 돌려받지 않습니다. 위치는 유지하고 새 시설은 Lv.1에서 시작합니다. 생산 중이거나 받을 물자가 남아 있으면 먼저 수령해야 합니다. 지금까지 건설한 시설 종류와 서로 다른 시설을 개선한 실적은 교체 후에도 남으므로, 기존 마을의 모든 자리가 차 있어도 성장 목표를 이어갈 수 있습니다. 마을 성장 방향과 네 비교 게임의 실제 참고 범위·확인하지 못한 자료는 [v0.14 비교 문서](docs/V0.14-COMPARISON.md)와 [게임 설계 문서](docs/GAME-DESIGN.md)에 기록했습니다.

지도는 빈 공간을 한 손가락으로 끌어 이동합니다. 농사 중 밭에서 시작하는 쓸기는 연속 작업으로 유지하며, ‘지도 조작’을 펼쳐 ‘화면 이동’을 켜면 밭 위에서도 작업 없이 화면만 움직입니다. 이동 모드를 다시 누르거나 농사 도구를 고르면 작업으로 돌아옵니다. 수동으로 움직인 시점은 작업 중에도 유지되고, 지도 조작의 기본 보기 또는 하단 우리 트럭·농장 메뉴로 카메라를 되돌립니다. 두 손가락을 벌리거나 오므려 확대·축소하고, 100% 기본 보기 버튼으로 위치와 배율을 초기화합니다. 농사·벌목·채집 중에도 사용할 수 있고, 두 손가락 조작은 밭 작업을 새로 예약하지 않습니다. 캐릭터는 실제 경로 거리에 맞춰 걷고 사다리에서는 더 천천히 이동합니다. 채집은 현장에서 약 0.80초, 벌목은 약 0.85초 동안 작업하며 왕복 이동을 포함한 행동을 모두 마친 뒤 한 번만 자원에 반영됩니다. 사냥은 별도 전투 화면에서 진행되며 승리 보상은 귀환할 때 한 번만 지급합니다. 앱을 종료한 원정은 재실행 시 보상 없이 복구됩니다. 자유 조이스틱 이동과 멀티플레이는 포함하지 않습니다. 앱을 잠시 닫았다 돌아오면 마지막 유효 저장 시점부터 최대 70초의 실제 경과 시간을 마을 시계에 반영합니다. 성장한 작물과 완료 생산품은 직접 수령하며, 시간 진행 중 자정을 넘으면 기존 식량 소비와 좀비 피해도 적용됩니다. 게임과 글꼴은 APK에 포함되어 기본 플레이에 인터넷이 필요하지 않습니다. 업데이트 확인과 다운로드에는 인터넷이 필요합니다.

## iPhone에서 플레이

[게임 열기](https://h0623-dev.github.io/House/?v=0.18.0)를 iPhone의 Safari에서 엽니다. **공유 → 홈 화면에 추가** 후 생긴 로드헤이븐 아이콘으로 실행하세요. 설정의 ‘홈 화면에 추가하는 방법’에서도 안내를 볼 수 있습니다.

온라인으로 실행하거나 게임으로 돌아오면 새 패치를 자동 확인합니다. 필요한 파일을 모두 준비하고 진행 상황을 저장한 뒤 적용하므로, 일반적인 게임 업데이트마다 다시 설치할 필요가 없습니다. 농사·전투 중에는 활동을 마치고 트럭 홈으로 돌아온 뒤 적용합니다. 다운로드에 실패하면 기존 버전으로 계속 플레이하며 다시 연결되면 재시도합니다.

첫 실행에서 파일 준비가 끝난 뒤에는 오프라인으로도 다시 실행할 수 있습니다. iOS가 저장 공간을 정리하면 재다운로드가 필요합니다. 진행 상황은 기기에 보관되며 Safari 탭·홈 화면 앱·Android 사이에 자동 공유되지 않습니다. 처음부터 홈 화면 아이콘으로 시작하는 것을 권장합니다. [iPhone 안내와 검증 범위](docs/IOS.md)를 참고하세요.

## Android에서 플레이

새 설치 및 구형 앱 전환용 APK: `artifacts/road-haven-0.18.0-debug.apk` (Android 버전 코드 18).

**v0.8 이상 앱은 이번 게임 업데이트를 받을 때 APK를 다시 설치할 필요가 없습니다.** 게임 실행 시 호환 콘텐츠를 자동으로 확인·적용합니다. v0.7 이전 앱에는 자동 콘텐츠 엔진이 없으므로 새 APK를 최초 한 번 설치해야 합니다. 같은 앱 ID·서명을 사용하므로 기존 앱을 삭제하지 않고 업데이트하면 마을을 유지합니다.

Android 6.0 이상과 최신 Android System WebView가 필요합니다. APK를 휴대폰에 옮겨 파일 앱에서 열고 설치를 승인합니다. 사용자가 해당 파일 앱/브라우저의 ‘알 수 없는 앱 설치’를 허용해야 할 수 있습니다. 테스트 버전은 개발용 서명이며 공개 스토어에 게시하지 않았습니다.

같은 서명 키로 설치하는 후속 APK는 게임 데이터를 유지합니다. 앱 삭제나 앱 데이터 초기화는 로컬 저장을 지웁니다. 현재 클라우드의 테스트 서명 키는 저장소 밖 `/workspace/.road-haven-signing/debug.keystore`에 보관됩니다. 정식 릴리스 서명으로 전환할 때는 테스트 APK와 서명이 다를 수 있습니다.

## 개발 실행

Node.js 22 이상을 사용합니다. 이 클라우드 작업은 이미 격리되어 있으므로 `/workspace/House`의 기존 체크아웃을 사용하며 별도 Git worktree를 만들 필요가 없습니다.

```bash
cd /workspace/House
npm ci
npm run dev
```

```bash
npm test              # 게임 로직·저장 데이터·업데이트 검증
npm run build         # TypeScript 검사 및 배포용 웹 빌드
npm run test:browser  # 개발 서버가 실행 중일 때 모바일 플레이 검사
npm run test:systems  # 여섯 시스템·모바일 배치·성장·속도 검사
npm run test:animals  # 동물별 체력·기술·성장·휴식·승리·패배·철수 검사
npm run test:mobile   # 실제 시간·모바일 터치로 벌목·회복·농사·사냥 검사
npm run test:seeds    # 씨앗 선택·연속 심기·작물별 저장 검사
npm run test:farm     # 연속 물 주기·수확·드래그·도구 변경 검사
npm run test:settlement # 건설·배치·생산·수령·시설 저장 검사
npm run test:growth   # 성장 목표·보상 수령·바로가기·이전 저장 검사
npm run test:startup  # 게임 시작 자동 패치·오프라인·기존 저장·연결 복구 검사
npm run test:pwa      # 실제 웹 자동 패치·오프라인 재실행·다중 탭 저장 검사
npm run test:scene    # 실제 핀치·줌·사다리·채집 동작과 완료 시 자원 반영 검사
npm run test:pan      # 한 손가락 화면 이동·밭 작업 분리·카메라 유지 검사
npm run test:farm-expand # 유료 밭 확장·비용·잠금·확장한 밭의 농사·저장 검사
npm run android:debug
```

브라우저 테스트는 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`로 변경할 수 있습니다. 서버 주소는 `TEST_BASE_URL`로 변경할 수 있습니다. 개발 중 HMR이 전체 플레이 검사를 중단할 수 있으므로 최종 검증에는 빌드된 정적 서버를 권장합니다. 전체 플레이 검사는 브라우저 시계를 제어하고, 터치·씨앗 검사는 실제 시간으로 작업을 진행합니다. 빌드 도구가 없는 클라우드에서는 먼저 `bash scripts/setup-android-cloud.sh`를 실행합니다. Android JDK/SDK 준비, 공식 아티팩트 검증, SDK 라이선스 수락을 수행합니다.

## APK 업데이트

`main` 푸시마다 GitHub Actions가 테스트와 APK 빌드를 실행하고 결과를 artifact로 제공합니다. 소스는 `h0623-dev/House`의 `main`, 웹 배포 파일은 `gh-pages`에 게시합니다. Pages 활성화와 공개 접속 확인은 별도입니다.

0.8.0 이상 APK를 한 번 설치하면 이후 **호환되는 게임 코드·그래픽은 APK 설치 없이 자동 적용**됩니다. 앱 시작·복귀 시 `gh-pages/game-update.json`의 서명된 콘텐츠 정보를 확인하고 앱 전용 공간에 내려받습니다. 서명·파일 해시·네이티브 호환 버전을 검증한 뒤 게임 시작 화면에서 저장 후 자동 적용합니다. 시작 확인이 느리면 현재 버전으로 플레이할 수 있으며, 플레이 중 도착한 콘텐츠는 현재 활동을 마치고 안전한 홈에서 적용합니다. 같은 로컬 주소에서 실행하므로 저장 데이터를 유지하며, 새 콘텐츠 시작을 확인하지 못하면 다음 앱 시작에 이전 콘텐츠로 복구합니다.

Android 엔진이나 네이티브 기능 변경은 APK 업데이트가 필요합니다. 앱이 새 APK를 내부에서 자동 다운로드하고 파일 해시·앱 ID·서명·버전을 검증한 뒤 ‘설치하기’를 제공합니다. **Android의 마지막 설치 확인은 사용자가 진행합니다.** Android 8 이상에서 필요한 이 앱의 설치 허용도 앱 내 안내에서 설정할 수 있습니다. 외부 브라우저에서 APK 링크를 찾는 과정은 없습니다.

0.3.0부터 네이티브 버전 확인 주소는 `https://raw.githubusercontent.com/h0623-dev/House/gh-pages/update.json`입니다. 0.8 이전 앱에는 콘텐츠 업데이트 엔진이 없으므로 현재 0.18 APK를 한 번 설치해야 합니다. [콘텐츠 배포 안내](docs/CONTENT-UPDATES.md)와 [Android 배포 안내](docs/ANDROID.md)에 검증·배포 절차를 기록했습니다.

- `VITE_UPDATE_MANIFEST_URL`: 공개 HTTPS 버전 파일 주소
- `release-version.json`: 기본 Android 버전 코드
- `APP_VERSION_CODE`: 필요할 때 기본값을 재정의하는 증가하는 Android 버전 코드
- `ANDROID_KEYSTORE_*`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`: 정식 빌드의 보안 서명 설정

서명 키나 비밀번호를 소스 코드 또는 `VITE_` 변수에 넣지 마세요. 자세한 내용은 [docs/ANDROID.md](docs/ANDROID.md)에 있습니다.
